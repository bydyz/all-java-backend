# Java 基本数据类型、包装类与字符串间的转换详解

下面按“基本类型 ↔ 包装类 ↔ 字符串”六个方向说明，并给出代码。先记住总览：

```text
基本类型 --Integer.valueOf()/自动装箱--> 包装类
包装类 --intValue()/自动拆箱----------> 基本类型
基本类型 --String.valueOf()/Xxx.toString()--> String
包装类 --String.valueOf()/toString()-------> String
String --Xxx.parseXxx()---------------> 基本类型
String --Xxx.valueOf()----------------> 包装类
```

> `String` 不是基本数据类型，是引用类型。八种基本类型及其包装类：
> `byte/Byte`、`short/Short`、`int/Integer`、`long/Long`、`float/Float`、`double/Double`、`char/Character`、`boolean/Boolean`。

---

## 1. 基本类型 ↔ 包装类

### 1.1 基本类型 → 包装类：装箱

推荐使用 `包装类.valueOf(基本值)`，也可以用自动装箱。

```java
int a = 10;

Integer i1 = Integer.valueOf(a); // 推荐：显式装箱
Integer i2 = a;                  // 自动装箱，编译器会插入 Integer.valueOf(a)

double d = 3.14;
Double d1 = Double.valueOf(d);
Double d2 = d; // 自动装箱

char ch = 'A';
Character c1 = Character.valueOf(ch);
Character c2 = ch; // 自动装箱
```

不推荐：

```java
// Integer i = new Integer(10); // 构造器已过时，不推荐
```

### 1.2 包装类 → 基本类型：拆箱

使用 `xxxValue()`，也可以自动拆箱。

```java
Integer i = Integer.valueOf(100);

int a1 = i.intValue(); // 显式拆箱
int a2 = i;            // 自动拆箱，编译器会插入 i.intValue()

Double d = Double.valueOf(3.14);
double x = d.doubleValue();

Boolean b = Boolean.valueOf(true);
boolean flag = b.booleanValue();
```

注意：包装类为 `null` 时自动拆箱会抛 `NullPointerException`。

```java
Integer n = null;
// int x = n; // NullPointerException
```

---

## 2. 基本类型/包装类 → 字符串

### 2.1 基本类型 → 字符串

常用方式：

```java
int a = 123;

//String str = a;//错误的

String s1 = String.valueOf(a);   // 推荐："123"
String s2 = Integer.toString(a); // "123"
String s3 = a + "";              // "123"，简单场景可用，但大量拼接不推荐
String s4 = String.format("%d", a); // "123"

double d = 3.14;
String s5 = String.valueOf(d); // "3.14"
String s6 = Double.toString(d); // "3.14"

char ch = 'A';
String s7 = String.valueOf(ch);     // "A"
String s8 = Character.toString(ch); // "A"

boolean b = true;
String s9 = String.valueOf(b);   // "true"
String s10 = Boolean.toString(b); // "true"
```

### 2.2 包装类 → 字符串

```java
Integer i = Integer.valueOf(123);

String s1 = i.toString();          // "123"
String s2 = String.valueOf(i);     // "123"
String s3 = Integer.toString(i);   // "123"，会自动拆箱
String s4 = "" + i;                // "123"
```

区别：

```java
Integer n = null;

String s1 = String.valueOf(n); // "null"
// String s2 = n.toString();   // NullPointerException
String s3 = "" + n;            // "null"
```

所以包装类转字符串时，`String.valueOf(wrapper)` 对 `null` 更安全；`wrapper.toString()` 在 `wrapper == null` 时会 NPE。

## 3. 字符串 → 基本类型/包装类

### 3.1 字符串 → 基本类型：`parseXxx`

除了 Character 类之外，其他所有包装类都具有 parseXxx 静态方法可以将字符串参数转换为对应的基本类型

```java
int a = Integer.parseInt("123");          // 123
long b = Long.parseLong("123456");        // 123456
double c = Double.parseDouble("3.14");    // 3.14
float d = Float.parseFloat("2.5");        // 2.5
byte e = Byte.parseByte("12");            // 12
short f = Short.parseShort("100");        // 100
boolean g = Boolean.parseBoolean("TRUE"); // true
```

`char` 没有 `parseChar`，通常用 `charAt`：

```java
char ch = "A".charAt(0); // 'A'
```

### 3.2 字符串 → 包装类：`valueOf`

注意:如果字符串参数的内容无法正确转换为对应的基本类型，则会抛出java.lang.NumberFormatException 异常。

```java
Integer i = Integer.valueOf("123");       // Integer 123
Long l = Long.valueOf("123456");          // Long 123456
Double d = Double.valueOf("3.14");        // Double 3.14
Float f = Float.valueOf("2.5");           // Float 2.5
Byte b = Byte.valueOf("12");              // Byte 12
Short s = Short.valueOf("100");           // Short 100
Boolean bool = Boolean.valueOf("true");   // Boolean true
Character ch = Character.valueOf("A".charAt(0)); // Character 'A'


// 利用包装类的  valueOf  方法将字符串转换为包装类，然后自动拆箱为基本数据类型
int a = Integer.valueOf("整数的字符串");
double d = Double.valueOf("小数的字符串");
boolean b = Boolean.valueOf("true 或 false");

```

区别：

```java
int a = Integer.parseInt("123");     // 返回基本类型 int
Integer b = Integer.valueOf("123");  // 返回包装类 Integer
```

`Integer.valueOf("123")` 内部也会解析字符串并装箱。

## 4. 按类型汇总常用方法

| 基本类型      | 包装类         | String → 基本类型             | String → 包装类                     | 基本类型 → String                                 |
|-----------|-------------|---------------------------|----------------------------------|-----------------------------------------------|
| `byte`    | `Byte`      | `Byte.parseByte(s)`       | `Byte.valueOf(s)`                | `Byte.toString(b)` / `String.valueOf(b)`      |
| `short`   | `Short`     | `Short.parseShort(s)`     | `Short.valueOf(s)`               | `Short.toString(s)` / `String.valueOf(s)`     |
| `int`     | `Integer`   | `Integer.parseInt(s)`     | `Integer.valueOf(s)`             | `Integer.toString(i)` / `String.valueOf(i)`   |
| `long`    | `Long`      | `Long.parseLong(s)`       | `Long.valueOf(s)`                | `Long.toString(l)` / `String.valueOf(l)`      |
| `float`   | `Float`     | `Float.parseFloat(s)`     | `Float.valueOf(s)`               | `Float.toString(f)` / `String.valueOf(f)`     |
| `double`  | `Double`    | `Double.parseDouble(s)`   | `Double.valueOf(s)`              | `Double.toString(d)` / `String.valueOf(d)`    |
| `char`    | `Character` | `s.charAt(0)`             | `Character.valueOf(s.charAt(0))` | `Character.toString(c)` / `String.valueOf(c)` |
| `boolean` | `Boolean`   | `Boolean.parseBoolean(s)` | `Boolean.valueOf(s)`             | `Boolean.toString(b)` / `String.valueOf(b)`   |

## 5. 综合示例

```java
public class ConversionDemo {
    public static void main(String[] args) {
        // 1. 基本类型 -> 包装类
        int a = 10;
        Integer wa1 = Integer.valueOf(a); // 推荐
        Integer wa2 = a;                  // 自动装箱

        // 2. 包装类 -> 基本类型
        int b1 = wa1.intValue(); // 显式拆箱
        int b2 = wa1;            // 自动拆箱

        // 3. 基本类型 -> 字符串
        String s1 = String.valueOf(a);   // "10"
        String s2 = Integer.toString(a); // "10"
        String s3 = a + "";              // "10"

        // 4. 包装类 -> 字符串
        String s4 = wa1.toString();      // "10"
        String s5 = String.valueOf(wa1); // "10"

        // 5. 字符串 -> 基本类型
        int c1 = Integer.parseInt("123");          // 123
        double c2 = Double.parseDouble("3.14");    // 3.14
        boolean c3 = Boolean.parseBoolean("TRUE"); // true
        char c4 = "A".charAt(0);                   // 'A'

        // 6. 字符串 -> 包装类
        Integer d1 = Integer.valueOf("123");       // Integer 123
        Double d2 = Double.valueOf("3.14");        // Double 3.14
        Boolean d3 = Boolean.valueOf("yes");       // false
        Character d4 = Character.valueOf("A".charAt(0)); // Character 'A'

        // 7. char / boolean 特殊处理
        char ch = 'A';
        String e1 = String.valueOf(ch);     // "A"
        String e2 = Character.toString(ch); // "A"

        boolean flag = true;
        String e3 = Boolean.toString(flag); // "true"

        // 8. null 与异常
        Integer nil = null;
        String n1 = String.valueOf(nil); // "null"
        // String n2 = nil.toString();   // NullPointerException
        // int n3 = nil;                 // 自动拆箱 NullPointerException

        // int bad = Integer.parseInt("12a"); // NumberFormatException
    }
}
```

## 6. 重要注意事项

1. **字符串转数值可能抛 `NumberFormatException`**
   ```java
   int a = Integer.parseInt("123"); // 正常
   // int b = Integer.parseInt("12a"); // NumberFormatException
   // int c = Integer.parseInt("1.0"); // NumberFormatException
   ```
   字符串前后有空格也不会自动去除，例如 `Integer.parseInt(" 1")` 会抛异常，需要先 `trim()`。

2. **`Boolean.parseBoolean` 规则特殊**
   只有忽略大小写等于 `"true"` 时才返回 `true`，其他字符串都返回 `false`：
   ```java
   Boolean.parseBoolean("true");  // true
   Boolean.parseBoolean("TRUE");  // true
   Boolean.parseBoolean("yes");   // false
   Boolean.parseBoolean("1");     // false
   ```

3. **`Character` 没有 `parseCharacter` / `parseChar`**
   字符串转字符用：
   ```java
   char ch = "A".charAt(0);
   Character c = Character.valueOf("A".charAt(0));
   ```

4. **自动装箱/拆箱是编译器语法糖**
   ```java
   Integer i = 100; // 等价于 Integer.valueOf(100)
   int x = i;       // 等价于 i.intValue()
   ```

5. **包装类对象比较不要随便用 `==`**
   `Integer` 默认缓存 `-128 ~ 127`：
   ```java
   Integer a = 127;
   Integer b = 127;
   System.out.println(a == b); // true，缓存同一对象

   Integer c = 128;
   Integer d = 128;
   System.out.println(c == d);      // false
   System.out.println(c.equals(d)); // true
   ```
   包装类比较值推荐 `equals()`，或者先转基本类型再比较。

6. **包装类可能为 `null`**
   拆箱、调用实例方法前要注意 NPE：
   ```java
   Integer n = null;
   // int x = n;            // NPE
   // String s = n.toString(); // NPE
   String s = String.valueOf(n); // "null"
   ```

---

## 7. 总结

总结：

- 基本类型和包装类之间用 `valueOf()` / `xxxValue()`，自动装箱拆箱本质也是它们。
- 基本类型/包装类转字符串推荐 `String.valueOf()` 或对应包装类的 `toString()`。
- 字符串转基本类型用 `parseXxx()`，转包装类用 `valueOf()`。
- `char` 和 `boolean` 的转换规则较特殊，需要单独注意。
