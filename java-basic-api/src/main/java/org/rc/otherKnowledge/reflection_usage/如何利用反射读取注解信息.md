# Java 中利用反射读取注解信息详解

通过反射读取注解，核心前提是注解必须声明为 `@Retention(RetentionPolicy.RUNTIME)`。满足这个前提后，你可以利用 `Class`、`Method`、`Field` 等对象提供的通用方法，在运行时获取注解的存在性、实例及属性值。

## 核心前提：@Retention(RetentionPolicy.RUNTIME)

Java 注解有三种保留策略。只有 `RUNTIME` 策略的注解会被保留到运行期，并能通过反射读取。

```java
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;

@Retention(RetentionPolicy.RUNTIME) // 关键：必须是 RUNTIME
public @interface MyAnnotation {
    String value() default "";
}
```

如果注解被声明为 `SOURCE`（如 `@Override`）或 `CLASS`（默认行为），反射 API 在运行时将**无法**获取到它。

## 核心 API：所有元素共享的读取方法

`Class`、`Method`、`Field`、`Constructor` 等类都实现了 `AnnotatedElement` 接口，因此共享以下核心方法：

| 方法 | 作用 |
|---|---|
| `isAnnotationPresent(Class)` | 判断是否存在**指定类型**的注解 |
| `getAnnotation(Class<T>)` | 获取**指定类型**的注解实例，不存在返回 `null` |
| `getAnnotations()` | 获取**所有**注解（包含继承的，适用于类） |
| `getDeclaredAnnotations()` | 获取**直接声明**在该元素上的注解（不含继承） |

## 分场景读取代码示例

### 场景一：读取类上的注解

```java
@MyAnnotation("类上的注解")
class DemoClass {}

// 读取
Class<?> clazz = DemoClass.class;
if (clazz.isAnnotationPresent(MyAnnotation.class)) {
    MyAnnotation anno = clazz.getAnnotation(MyAnnotation.class);
    System.out.println(anno.value()); // 输出: 类上的注解
}
```

### 场景二：读取方法上的注解

```java
class DemoClass {
    @MyAnnotation("方法上的注解")
    public void doSomething() {}
}

Method method = DemoClass.class.getMethod("doSomething");
MyAnnotation anno = method.getAnnotation(MyAnnotation.class);
System.out.println(anno.value()); // 输出: 方法上的注解
```

### 场景三：读取字段上的注解

读取字段时，通常先通过 `getDeclaredFields()` 遍历，再用 `isAnnotationPresent` 判断并取值。

```java
class User {
    @MyAnnotation("用户名")
    private String name;
}

for (Field field : User.class.getDeclaredFields()) {
    if (field.isAnnotationPresent(MyAnnotation.class)) {
        MyAnnotation anno = field.getAnnotation(MyAnnotation.class);
        System.out.println(field.getName() + " -> " + anno.value()); // name -> 用户名
    }
}
```

### 场景四：读取方法参数上的注解

参数的注解通过二维数组返回，`paramAnnotations[i]` 表示第 `i` 个参数上的所有注解。

```java
class DemoClass {
    public void process(@MyAnnotation("参数注解") String input) {}
}

Method method = DemoClass.class.getMethod("process", String.class);
Annotation[][] paramAnnos = method.getParameterAnnotations();
for (Annotation anno : paramAnnos[0]) {
    if (anno instanceof MyAnnotation) {
        System.out.println(((MyAnnotation) anno).value()); // 参数注解
    }
}
```

## 关键细节：继承与 getAnnotations / getDeclaredAnnotations

这两个方法的区别**仅在处理类级别的继承时才有意义**。

**对于类**：`getAnnotations()` 会包含从父类继承来的注解，但前提是注解本身标记了 `@Inherited`，且父类使用了该注解。`getDeclaredAnnotations()` 始终只返回直接写在当前类上的注解。

```java
import java.lang.annotation.Inherited;

@Inherited
@Retention(RetentionPolicy.RUNTIME)
@interface InheritedAnno {}

@InheritedAnno
class Parent {}

class Child extends Parent {}

// Child 自身没有写 @InheritedAnno
Child.class.getAnnotations().length;        // 1（获取到继承的）
Child.class.getDeclaredAnnotations().length; // 0（没有直接声明）
```

**对于方法和字段**：注解**永远不会**从父类继承，即使标记了 `@Inherited` 也无效。因此，在字段和方法上，`getAnnotations()` 与 `getDeclaredAnnotations()` 的结果**完全相同**。如果需要获取父类方法或字段上的注解，必须手动沿继承链向上遍历查找。

## 补充注意事项

- **`@Target` 约束**：读取前应确保注解被允许放在对应位置（如 `ElementType.FIELD`），但这不影响读取逻辑，仅影响注解能否通过编译。
- **接口注解不继承**：实现类不会自动获得接口上声明的注解，反射的 `getAnnotation()` 不会检查接口。
- **框架封装**：Spring 的 `AnnotationUtils.findAnnotation()` 或 `AnnotatedElementUtils` 已封装了复杂的继承、接口查找逻辑，在 Spring 项目中可以直接使用，无需手动遍历。
