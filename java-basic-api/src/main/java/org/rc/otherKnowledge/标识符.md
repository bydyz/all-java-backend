# 标识符

## 1. 什么是标识符

标识符（Identifier）是程序员在编写程序时，为**类、接口、方法、变量、常量、包、枚举、泛型参数**等元素起的名字。

简单来说：**凡是你自己起的名字，都是标识符。**

Java 程序中的标识符主要出现在以下位置：

```java
package com.example.demo;          // demo 是包名（标识符的一部分）

public class Student {              // Student 是类名
    private static final int MAX_AGE = 150;  // MAX_AGE 是常量名

    private String name;            // name 是成员变量名

    public void study(int hours) {  // study 是方法名，hours 是参数名
        int total = 0;              // total 是局部变量名
    }
}
```

> 注意：`class`、`public`、`int` 这些是 Java 关键字，**不是标识符**，因为它们是语言本身保留的，不能拿来当名字。

## 2. 命名规则

命名规则是**语法硬性规定**，不遵守就会**编译报错**，程序无法运行。

### 2.1 组成字符

标识符只能由以下字符组成：

- 字母（`A-Z`、`a-z`）
- 数字（`0-9`）
- 下划线（`_`）
- 美元符号（`$`）
- Unicode 字符（中文、日文等，合法但不推荐使用）

```java
int age = 18;        // 合法
int _count = 0;      // 合法
int $price = 9;      // 合法
int age2 = 20;       // 合法
int 年龄 = 18;       // 合法，但强烈不推荐（不符合国际规范）
```

### 2.2 不能以数字开头

```java
int 1age = 18;   // 编译错误
int age1 = 18;   // 正确
```

### 2.3 不能包含空格和特殊符号

```java
int my age = 18;   // 错误：有空格
int my-age = 18;   // 错误：有减号（会被当成减号运算）
int my.age = 18;   // 错误：有点号
int my@age = 18;   // 错误：有 @ 符号
```

### 2.4 不能是关键字和保留字

Java 关键字（全部小写）不能作为标识符：

```
abstract  assert    boolean   break      byte       case
catch     char      class     const      continue   default
do        double    else      enum       extends    final
finally   float     for       goto       if         implements
import    instanceof int      interface  long       native
new       package   private   protected  public     return
short     static    strictfp  super      switch     synchronized
this      throw     throws    transient  try        void
volatile  while
```

另外，`true`、`false`、`null` 是字面量，也不能作为标识符：

```java
int true = 1;    // 错误
int null = 0;    // 错误
```

### 2.5 严格区分大小写

```java
int age = 18;
int Age = 20;     // 这是两个不同的变量
int AGE = 30;     // 这又是另一个变量
```

### 2.6 长度没有限制

标识符可以无限长，但名字过长会影响可读性，应适度。

### 2.7 规则小结

| 规则 | 示例（合法） | 示例（非法） |
| --- | --- | --- |
| 字母、数字、`_`、`$` 组成 | `userName`、`_temp`、`$val` | `user-name`、`user@name` |
| 不能以数字开头 | `age1` | `1age` |
| 不能含空格 | `userName` | `user name` |
| 不能是关键字 | `value` | `class`、`int` |
| 区分大小写 | `name` 与 `Name` 不同 | — |

## 3. 命名规范

命名规范（约定）**不是语法强制**，不遵守也能编译通过，但它决定了代码是否易读、是否专业、是否方便团队协作。业界主要遵循 **阿里巴巴 Java 开发手册** 和 **Oracle 官方 Java 命名约定**。

### 3.1 包名（package）

- 全部**小写**
- 采用**公司域名倒写** + 项目名 + 模块名
- 多级包用 `.` 分隔，不使用下划线、连字符
- 建议使用单数名词

```java
package com.example.order;
package com.example.order.service;
package com.example.order.service.impl;
```

反例：

```java
package com.Example.Order;      // 不应有大写
package com_example_order;      // 不应使用下划线
package com.example.my-project; // 连字符不合法
```

### 3.2 类名、接口名

- 使用**大驼峰命名法（PascalCase）**，即每个单词首字母大写
- 类名通常是**名词**，见名知意
- 接口名可以是名词，也可以是**形容词**（表示能力，如 `Comparable`、`Runnable`）
- 抽象类常以 `Abstract` 或 `Base` 开头
- 异常类以 `Exception` 结尾
- 测试类以 `Test` 结尾

```java
public class UserAccount { }
public class OrderService { }
public interface Serializable { }
public interface Flyable { }
public abstract class AbstractShape { }
public class NullPointerException extends RuntimeException { }
public class UserServiceTest { }
```

反例：

```java
public class useraccount { }   // 未使用大驼峰
public class User_account { }  // 不应使用下划线
public class A { }             // 无意义
public class UserManagerUtilHelper { } // 过度堆砌，职责不清
```

### 3.3 变量名

#### 3.3.1 普通变量（局部变量、成员变量、参数）

- 使用**小驼峰命名法（camelCase）**
- 第一个单词小写，后续单词首字母大写
- 名词或名词短语，见名知意
- 局部变量名可简短，成员变量名应更完整
- **不要**使用 `m_`、`m`、`str`、`i1` 之类的无意义前缀

```java
String userName;
int orderCount;
double totalPrice;
List<String> studentList;
```

反例：

```java
String userName_;   // 不规范
String user_name;   // 不规范
String name1;       // 无意义编号
String a;           // 无意义
```

> 循环变量 `i`、`j`、`k`，以及坐标 `x`、`y`，属于约定俗成的例外，可以使用。

#### 3.3.2 布尔类型变量

- 推荐以 `is`、`has`、`can`、`should`、`enable` 等开头，表达"是不是"的含义

```java
boolean isDeleted;
boolean hasPermission;
boolean canExecute;
boolean shouldRetry;
```

#### 3.3.3 常量名（`static final`）

- 使用**全大写 + 下划线分隔（UPPER_SNAKE_CASE）**
- 单词之间用 `_` 连接
- 必须是 `static final` 修饰

```java
public static final int MAX_RETRY_COUNT = 3;
public static final String DEFAULT_ENCODING = "UTF-8";
public static final double PI = 3.1415926;
```

反例：

```java
public static final int maxRetryCount = 3;  // 未全大写
public static final int MAXRETRYCOUNT = 3;  // 缺少下划线分隔
```

### 3.4 方法名

- 使用**小驼峰命名法（camelCase）**
- 通常是**动词 + 名词**结构，表达"做什么"
- getter / setter 遵循 JavaBean 规范：

| 场景 | 命名示例 |
| --- | --- |
| 获取属性 | `getName()`、`getAge()` |
| 设置属性 | `setName(String name)` |
| 布尔属性获取 | `isEnabled()`、`hasNext()` |
| 判断校验 | `isValid()`、`checkPassword()` |
| 增删改查 | `createUser()`、`deleteUser()`、`updateUser()`、`findUserById()` |
| 转换 | `toString()`、`toJson()` |
| 计算 | `calculateTotal()` |

```java
public String getUserName() { ... }
public void setUserName(String userName) { ... }
public boolean isAdult() { ... }
public List<Order> findOrdersByUserId(Long userId) { ... }
```

反例：

```java
public void GetUserName() { ... }   // 方法名不应大写开头
public void get_user_name() { ... } // 不应使用下划线
public void doIt() { ... }          // 含义不明
```

### 3.5 其他常见元素命名

| 元素 | 规范 | 示例 |
| --- | --- | --- |
| 枚举类 | 大驼峰 | `OrderStatus` |
| 枚举常量 | 全大写 + 下划线 | `OrderStatus.PAID`、`OrderStatus.UN_PAID` |
| 泛型参数 | 单个大写字母 | `T`（类型）、`E`（元素）、`K`（键）、`V`（值）、`N`（数字） |
| 注解 | 大驼峰 | `Override`、`Deprecated` |
| 测试方法 | 小驼峰，建议 `方法名_场景_预期结果` 或 `should_Xxx_when_Yyy` | `findById_notFound_throwsException()` |

```java
public enum OrderStatus {
    UN_PAID, PAID, SHIPPED, FINISHED
}

public class Result<T> {
    private T data;
    public <E> List<E> convert(Collection<E> source) { ... }
}
```

### 3.6 通用规范补充

- **禁止使用拼音**：`yonghu`, `dingdan` 不推荐，除非是专有业务名词且全团队统一。
- **禁止使用无意义命名**：`a`、`b`、`temp1`、`test`、`data2`。
- **禁止使用中文、日文等非 ASCII 字符**作为标识符。
- **避免使用 `$` 和 `_` 开头**：`$` 通常由编译器/框架生成，`_` 在 Java 9 之后是关键字（不能单独作为标识符）。
- **命名要表达意图**：变量名回答"是什么"，方法名回答"做什么"。
- **保持团队统一**：同一项目内不要混用风格。

## 4. 综合示例

```java
package com.example.library;

/**
 * 图书实体类
 */
public class Book {

    /** 最大借阅天数 */
    public static final int MAX_BORROW_DAYS = 30;

    private Long bookId;
    private String bookName;
    private String authorName;
    private boolean isBorrowed;

    public Book(String bookName, String authorName) {
        this.bookName = bookName;
        this.authorName = authorName;
    }

    public String getBookName() {
        return bookName;
    }

    public void setBookName(String bookName) {
        this.bookName = bookName;
    }

    public boolean isBorrowed() {
        return isBorrowed;
    }

    public void borrow() {
        if (isBorrowed) {
            throw new IllegalStateException("图书已被借出");
        }
        isBorrowed = true;
    }

    public void returnBook() {
        isBorrowed = false;
    }
}
```

## 5. 总结

| 分类 | 规则/规范 | 示例 |
| --- | --- | --- |
| 包 | 全小写，域名倒写 | `com.example.order.service` |
| 类 / 接口 | 大驼峰，名词 | `UserService`、`Runnable` |
| 变量 | 小驼峰，名词 | `userName`、`orderCount` |
| 方法 | 小驼峰，动词开头 | `findUserById()` |
| 常量 | 全大写 + 下划线 | `MAX_RETRY_COUNT` |
| 枚举常量 | 全大写 + 下划线 | `OrderStatus.PAID` |
| 泛型 | 单个大写字母 | `T`、`E`、`K`、`V` |

**记住一句话：规则让你能编译，规范让你像一名专业 Java 程序员。**
