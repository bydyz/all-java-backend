`Arrays.toString()` 和 `Arrays.deepToString()` 的核心区别在于**处理嵌套（多维）数组时的行为**。`toString()`
只“看”一层，遇到内部数组时打印的是它的内存地址；而 `deepToString()` 会“钻进去”，递归地打印所有层级的内容。

### 🎯 核心区别：处理嵌套数组的方式

这是两者最根本的不同，决定了各自的适用场景。

**`Arrays.toString()`：仅适用于一维数组**
它的设计目标是处理一维数组。当它遇到一个元素本身也是数组时，它会调用这个内部数组从 `Object` 类继承来的 `toString()`
方法。这个方法返回的是**类名 + `@` + 哈希码**的格式，也就是我们常说的“内存地址”。

**`Arrays.deepToString()`：专为多维数组设计**
它的设计目标就是处理嵌套数组。当它遇到内部数组时，会**递归地**调用自身（或对应基本类型的 `toString` 重载），从而完整地展开所有层级的内容。

### 📊 输出效果直观对比

以二维数组 `int[][] matrix = {{1, 2, 3}, {4, 5, 6}};` 为例，对比两者的输出：

| 方法                            | 输出结果                        | 说明                                        |
|:------------------------------|:----------------------------|:------------------------------------------|
| `Arrays.toString(matrix)`     | `[[I@14ae5a5, [I@7f31245a]` | `[I` 代表 `int` 数组，`@` 后面是哈希码，**无法看到实际数字**。 |
| `Arrays.deepToString(matrix)` | `[[1, 2, 3], [4, 5, 6]]`    | 完整地呈现了所有层级的元素值。                           |

如果是`String[][]`类型的二维数组，`toString()` 的输出会类似 `[[Ljava.lang.String;@...`，同样只是地址标识。

### ⚠️ 关键注意事项

1. **`deepToString` 的参数是 `Object[]`**：这意味着它**不能直接用于一维基本类型数组**（如 `int[]`, `double[]`
   ）。如果你尝试 `Arrays.deepToString(new int[]{1,2,3})`，会因为 `int[]` 无法转换为 `Object[]`
   而编译报错。一维基本类型数组，只能使用对应的 `Arrays.toString(int[])` 等方法。
2. **循环引用的安全处理**：`deepToString()`
   考虑了数组包含自身引用（或间接循环引用）的情况。为避免无限递归，它会将这种自引用转换为 `[...]` 来表示。
3. **`null` 的处理**：两者在传入 `null` 数组时，都会返回字符串 `"null"`，行为一致。

### 💎 总结与选用建议

可以这样记忆：**“一维用 `toString`，多维用 `deepToString`”**。

- **当你确定数组是一维时**（例如 `int[]`, `String[]`），使用 `Arrays.toString()` 是直接且高效的选择。
- **当你处理的是多维数组时**（例如 `int[][]`, `String[][][]`），**必须**使用 `Arrays.deepToString()`
  ，否则你看到的将是内部数组的地址标识，而不是数据本身。
