## 一、Lambda 表达式的定义

Lambda 表达式是 Java 8 引入的一种语法，用来简洁地表示**可传递的匿名函数**。它本身不是一个独立类型，必须依附于**函数式接口**使用：Lambda 表达式的目标类型必须是函数式接口。

**函数式接口**：只有一个抽象方法的接口。可以有默认方法、静态方法，也可以有 `Object` 中 public 方法的重写声明，但这些都不算“唯一抽象方法”。通常用 `@FunctionalInterface` 标注。

```java
@FunctionalInterface
interface Calculator {
    int calculate(int a, int b); // 唯一抽象方法
}
```

Lambda 表达式可以看作该抽象方法的实现：

```java
Calculator add = (a, b) -> a + b;
System.out.println(add.calculate(2, 3)); // 5
```

等价于匿名内部类：

```java
Calculator add = new Calculator() {
    @Override
    public int calculate(int a, int b) {
        return a + b;
    }
};
```

但 Lambda 更简洁。

## 二、Lambda 表达式的基本语法

通用形式：

```java
(参数列表) -> 表达式
(参数列表) -> { 语句块; return 返回值; }
```

其中 `->` 是 Lambda 操作符。

### 1. 无参数

```java
Runnable r = () -> System.out.println("Hello Lambda");
r.run();
```

### 2. 一个参数

只有一个参数且不写参数类型时，可以省略括号：

```java
Consumer<String> printer = s -> System.out.println(s);
printer.accept("hello");
```

也可以写括号和类型：

```java
Consumer<String> printer2 = (String s) -> System.out.println(s);
```

### 3. 多个参数

```java
Calculator add = (a, b) -> a + b;
Calculator mul = (int a, int b) -> a * b;
```

注意：参数类型要么全部省略，要么全部写出；不能混写，例如 `(a, int b) -> ...` 不合法。

### 4. 表达式体与语句块体

表达式体：不需要写 `return` 和分号。

```java
Function<Integer, Integer> square = x -> x * x;
```

语句块体：有多条语句时必须用 `{}`，有返回值时要写 `return`。

```java
Function<Integer, Integer> square2 = x -> {
    int result = x * x;
    return result;
};
```

无返回值时：

```java
Consumer<String> c = s -> {
    String msg = "Msg: " + s;
    System.out.println(msg);
};
```

### 5. 语法小结

| 场景 | 示例 |
|---|---|
| 无参 | `() -> 42` |
| 单参省略括号 | `x -> x + 1` |
| 多参 | `(x, y) -> x + y` |
| 显式参数类型 | `(int x, int y) -> x + y` |
| 表达式体 | `x -> x * 2` |
| 语句块体 | `x -> { return x * 2; }` |

## 三、类型推断

Lambda 表达式自身通常不写参数类型，编译器会根据**目标类型上下文**推断。

目标类型上下文包括：

1. 变量赋值；
2. 方法实参；
3. `return` 语句；
4. 三元表达式；
5. 强制类型转换。

### 1. 根据目标函数式接口推断参数类型

```java
Comparator<String> cmp = (a, b) -> a.compareTo(b);
```

`Comparator<String>` 的抽象方法是：

```java
int compare(String o1, String o2);
```

因此编译器推断 `a`、`b` 都是 `String`，可以调用 `compareTo`。

再看：

```java
List<String> names = List.of("Tom", "Jerry", "Alice");
names.sort((a, b) -> a.length() - b.length());
```

`List.sort` 接收 `Comparator<? super String>`，因此 `a`、`b` 被推断为 `String`。

### 2. 根据上下文推断返回类型

```java
Function<String, Integer> length = s -> s.length();
```

目标类型是 `Function<String, Integer>`，抽象方法为：

```java
Integer apply(String t);
```

因此参数 `s` 是 `String`，表达式 `s.length()` 的结果作为 `Integer` 返回。

### 3. 泛型方法中的推断

```java
static <T, R> R apply(T value, Function<T, R> f) {
    return f.apply(value);
}

String result = apply("abc", s -> s.toUpperCase());
```

从第一个参数 `"abc"` 推断 `T` 为 `String`，从 Lambda 体推断 `R` 为 `String`。

### 4. 重载方法可能产生歧义

如果多个重载方法的函数式接口都能匹配 Lambda，编译器可能无法选择：

```java
void run(Supplier<String> s) {}
void run(Callable<String> c) {}
```

调用：

```java
// run(() -> "hello"); // 可能产生重载歧义
```

此时可以强制转换明确目标类型：

```java
run((Supplier<String>) () -> "hello");
```

类型推断的前提是：**Lambda 必须有明确的目标类型**。因此下面写法不合法：

```java
// var f = x -> x + 1; // 无法确定函数式接口
```

## 四、常见使用示例

### 1. `Runnable`

```java
Runnable task = () -> System.out.println("run in thread");
new Thread(task).start();
```

### 2. `Comparator` 排序

```java
List<String> list = new ArrayList<>(List.of("banana", "apple", "pear"));

list.sort((s1, s2) -> s1.length() - s2.length());
System.out.println(list); // [pear, apple, banana]
```

按字典序：

```java
list.sort(String::compareTo); // 方法引用形式
```

### 3. 自定义函数式接口

```java
@FunctionalInterface
interface StringProcessor {
    String process(String s);
}

public class Demo {
    public static void main(String[] args) {
        StringProcessor upper = s -> s.toUpperCase();
        StringProcessor trimUpper = s -> {
            String t = s.trim();
            return t.toUpperCase();
        };

        System.out.println(upper.process("hello"));     // HELLO
        System.out.println(trimUpper.process("  hi ")); // HI
    }
}
```

### 4. `java.util.function` 内置接口

Java 提供了常用函数式接口：

| 接口 | 抽象方法 | 含义 |
|---|---|---|
| `Function<T,R>` | `R apply(T t)` | 输入 T，返回 R |
| `BiFunction<T,U,R>` | `R apply(T t, U u)` | 两个输入，返回 R |
| `Predicate<T>` | `boolean test(T t)` | 判断 |
| `Consumer<T>` | `void accept(T t)` | 消费 |
| `Supplier<T>` | `T get()` | 提供 |
| `UnaryOperator<T>` | `T apply(T t)` | 一元运算 |
| `BinaryOperator<T>` | `T apply(T t1, T t2)` | 二元运算 |

示例：

```java
import java.util.function.*;

Function<Integer, String> f = i -> "Number: " + i;
Predicate<String> empty = s -> s.isEmpty();
Consumer<String> print = s -> System.out.println(s);
Supplier<String> supplier = () -> "hello";
BiFunction<Integer, Integer, Integer> add = (a, b) -> a + b;

System.out.println(f.apply(10));       // Number: 10
System.out.println(empty.test(""));    // true
print.accept("abc");                   // abc
System.out.println(supplier.get());    // hello
System.out.println(add.apply(3, 4));   // 7
```

### 5. Stream 中的 Lambda

```java
List<String> names = List.of("Tom", "Jerry", "Alice", "Bob");

List<String> result = names.stream()
        .filter(name -> name.length() > 3)
        .map(String::toUpperCase)
        .sorted()
        .toList();

System.out.println(result); // [ALICE, JERRY]
```

这里的 `filter` 接收 `Predicate<String>`，`map` 接收 `Function<String, String>`。

### 6. 变量捕获

Lambda 可以访问外围局部变量，但该变量必须是 `final` 或“事实上的 final”，即初始化后不再修改。

```java
int base = 10;
IntBinaryOperator op = (a, b) -> a + b + base;
System.out.println(op.applyAsInt(1, 2)); // 13
```

不能修改被捕获的局部变量：

```java
int x = 1;
// x = 2; // 如果 Lambda 中使用了 x，则 x 不能再被修改
Runnable r = () -> System.out.println(x);
```

## 五、注意事项

1. **Lambda 必须对应函数式接口**，不能单独声明为某个“函数类型”。
2. **参数类型可省略**，由目标类型推断；但省略和显式类型不能混用。
3. **表达式体自动返回值**；语句块体需要显式 `return`。
4. **Lambda 中的 `this` 指向外围对象**，而匿名内部类中的 `this` 指向匿名内部类实例。
5. **局部变量捕获要求 effectively final**。
6. **Lambda 不能访问非 final 局部变量并修改它**。
7. **方法引用**是 Lambda 的简化形式，例如 `String::toUpperCase`、`System.out::println`。
8. 如果重载导致目标类型不明确，可通过强制转换或显式参数类型解决。

---

## 六、总结

Lambda 表达式本质上是**函数式接口的简洁实现**，语法为：

```java
(参数) -> 表达式
(参数) -> { 语句块 }
```

它的类型由上下文决定，参数类型通常可省略并由函数式接口的抽象方法签名推断。常见用途包括线程任务、比较器、集合排序、Stream 处理、事件回调等。掌握 Lambda 的关键是理解：**目标类型是函数式接口，Lambda 实现其唯一抽象方法**。
