下面按你列的 5 点逐条给代码和解释。核心先记住：**方法引用是“目标类型驱动”的语法糖**，同一个 `X::method` 在不同目标函数式接口下可能对应不同签名。

---

## 1. `类名::实例方法`：未绑定实例方法引用，不是静态方法引用

`String::length` 不是调用静态方法，而是表示“给我一个 `String`，我对它调用 `length()`”。

```java
import java.util.function.*;

public class Demo1 {
    public static void main(String[] args) {
        // String::length 等价于 s -> s.length()
        Function<String, Integer> len1 = String::length;
        ToIntFunction<String> len2 = String::length;
        Function<String, Integer> len3 = s -> s.length();

        System.out.println(len1.apply("hello"));    // 5
        System.out.println(len2.applyAsInt("hello")); // 5
        System.out.println(len3.apply("hello"));    // 5

        // 实例方法有参数时：第一个参数是接收者，后面的参数是方法实参
        // String::compareTo 等价于 (a, b) -> a.compareTo(b)
        BiFunction<String, String, Integer> cmp1 = String::compareTo;
        ToIntBiFunction<String, String> cmp2 = String::compareTo;

        System.out.println(cmp1.apply("a", "b"));     // -1
        System.out.println(cmp2.applyAsInt("a", "b")); // -1
    }
}
```

解释：

```java
Function<String, Integer> f = String::length;
```

等价于：

```java
Function<String, Integer> f = s -> s.length();
```

这里 `String::length` 的方法签名可以理解为：

```java
int length(String this)
```

所以目标接口 `Function<String, Integer>` 需要一个参数 `String`，返回 `Integer`，正好匹配。

再看一个带两个实参的实例方法：

```java
@FunctionalInterface
interface TriFunction<A, B, C, R> {
    R apply(A a, B b, C c);
}

TriFunction<String, Integer, Integer, String> sub = String::substring;
```

等价于：

```java
TriFunction<String, Integer, Integer, String> sub =
        (s, begin, end) -> s.substring(begin, end);
```

因为 `String.substring(int, int)` 是实例方法，所以方法引用需要：

- 第 1 个参数：接收者 `String s`
- 第 2 个参数：`begin`
- 第 3 个参数：`end`

对比静态方法引用：

```java
Function<String, Integer> p = Integer::parseInt;
// 等价于 s -> Integer.parseInt(s)
```

`Integer::parseInt` 才是静态方法引用。

## 2. `对象::实例方法`：接收者对象固定

`System.out::println` 中，接收者 `System.out` 是固定的，参数才是 `println` 的实参。

```java
import java.util.function.*;

public class Demo2 {
    public static void main(String[] args) {
        // System.out::println 等价于 s -> System.out.println(s)
        Consumer<String> p1 = System.out::println;
        p1.accept("hello"); // hello

        // 目标类型决定选择哪个 println 重载
        Consumer<Object> p2 = System.out::println;
        p2.accept(123); // 123

        IntConsumer p3 = System.out::println;
        p3.accept(456); // 456

        // 普通对象也可以作为固定接收者
        StringBuilder sb = new StringBuilder("abc");
        Supplier<String> sup = sb::toString; // 等价于 () -> sb.toString()
        System.out.println(sup.get()); // abc
    }
}
```

解释：

```java
Consumer<String> p1 = System.out::println;
```

等价于：

```java
Consumer<String> p1 = s -> System.out.println(s);
```

这里 `System.out` 是固定接收者，`s` 是传给 `println` 的参数。

```java
Consumer<Object> p2 = System.out::println;
```

目标类型是 `Consumer<Object>`，所以会选择 `println(Object)`。

```java
IntConsumer p3 = System.out::println;
```

目标类型是 `IntConsumer`，所以会选择 `println(int)`。

注意：固定的是“接收者对象”，不是对象状态的快照。例如：

```java
StringBuilder sb = new StringBuilder("abc");
Supplier<String> sup = sb::toString;
sb.append("def");
System.out.println(sup.get()); // abcdef
```

`sb` 这个对象固定，但对象内部状态后续变化仍然可见。

## 3. 构造器引用 `类名::new`：根据目标函数式接口选择构造器

```java
import java.util.function.*;

public class Demo3 {
    static class Person {
        String name;
        int age;

        Person() {
            this("未知", 0);
        }

        Person(String name) {
            this(name, 0);
        }

        Person(String name, int age) {
            this.name = name;
            this.age = age;
        }

        @Override
        public String toString() {
            return name + "," + age;
        }
    }

    public static void main(String[] args) {
        // 目标接口无参数，选择无参构造器
        Supplier<Person> c0 = Person::new;
        // 等价于 () -> new Person()
        System.out.println(c0.get()); // 未知,0

        // 目标接口一个 String 参数，选择 Person(String)
        Function<String, Person> c1 = Person::new;
        // 等价于 name -> new Person(name)
        System.out.println(c1.apply("张三")); // 张三,0

        // 目标接口两个参数，选择 Person(String, int)
        BiFunction<String, Integer, Person> c2 = Person::new;
        // 等价于 (name, age) -> new Person(name, age)
        System.out.println(c2.apply("李四", 20)); // 李四,20
    }
}
```

解释：

```java
Supplier<Person> c0 = Person::new;
```

目标接口：

```java
Supplier<Person>
```

它需要：

```java
Person get()
```

所以匹配无参构造器：

```java
Person()
```

---

```java
Function<String, Person> c1 = Person::new;
```

目标接口需要：

```java
Person apply(String s)
```

所以匹配：

```java
Person(String name)
```

---

```java
BiFunction<String, Integer, Person> c2 = Person::new;
```

目标接口需要：

```java
Person apply(String s, Integer i)
```

所以匹配：

```java
Person(String name, int age)
```

其中 `Integer` 会自动拆箱成 `int`。

如果目标接口参数和任何构造器都不匹配，就编译失败。

## 4. 数组构造器引用 `int[]::new`

```java
import java.util.function.*;

public class Demo4 {
    public static void main(String[] args) {
        // int[]::new 等价于 n -> new int[n]
        IntFunction<int[]> f1 = int[]::new;
        int[] a = f1.apply(3);
        System.out.println(a.length); // 3

        // String[]::new 等价于 n -> new String[n]
        IntFunction<String[]> f2 = String[]::new;
        String[] b = f2.apply(2);
        System.out.println(b.length); // 2

        // 二维数组构造器引用：只分配第一维
        IntFunction<int[][]> f3 = int[][]::new;
        int[][] c = f3.apply(2);
        // 等价于 n -> new int[n][]
        System.out.println(c.length); // 2
        System.out.println(c[0]);     // null

        // 如果要一次性分配矩形二维数组，用显式 Lambda
        BiFunction<Integer, Integer, int[][]> rect =
                (n, m) -> new int[n][m];
        int[][] d = rect.apply(2, 3);
        System.out.println(d.length + "x" + d[0].length); // 2x3
    }
}
```

解释：

```java
IntFunction<int[]> f1 = int[]::new;
int[] a = f1.apply(3);
```

等价于：

```java
IntFunction<int[]> f1 = n -> new int[n];
int[] a = f1.apply(3); // new int[3]
```

`int[]::new` 接收一个 `int` 长度参数，返回 `int[]`。

对于二维数组：

```java
IntFunction<int[][]> f3 = int[][]::new;
int[][] c = f3.apply(2);
```

等价于：

```java
n -> new int[n][]
```

它只分配外层数组，内层数组还是 `null`。如果要分配完整的二维数组：

```java
BiFunction<Integer, Integer, int[][]> rect =
        (n, m) -> new int[n][m];
```

## 5. 方法引用必须有目标类型；重载歧义时改用显式 Lambda 或强转

方法引用本身不能单独存在，它必须放在一个需要函数式接口的上下文中，例如：

- 赋值给函数式接口变量
- 作为方法参数
- 强制类型转换

```java
import java.io.Serializable;
import java.util.function.*;

public class Demo5 {
    static void use(Function<String, Integer> f) {
        System.out.println(f.apply("abcd"));
    }

    static class Overload {
        void accept(CharSequence cs) {
            System.out.println("CharSequence");
        }

        void accept(Serializable s) {
            System.out.println("Serializable");
        }
    }

    public static void main(String[] args) {
        // 1. 赋值上下文提供目标类型
        Function<String, Integer> f = String::length;
        System.out.println(f.apply("abc")); // 3

        // 2. 方法调用实参提供目标类型
        use(String::length); // 4

        // 3. 强制类型转换提供目标类型
        Object o = (Function<String, Integer>) String::length;
        System.out.println(((Function<String, Integer>) o).apply("hello")); // 5

        // 4. 没有目标类型：编译错误
        // var ref = String::length;
        // 错误：无法推断方法引用的目标类型

        // 5. 重载歧义示例
        Overload ov = new Overload();

        // 编译错误：CharSequence 和 Serializable 都能匹配 String，
        // 且二者没有子类型关系，无法选出更具体的方法
        // Consumer<String> c = ov::accept;

        // 改用显式 Lambda + 强转，消除歧义
        Consumer<String> c = s -> ov.accept((CharSequence) s);
        c.accept("hello"); // CharSequence
    }
}
```

关键解释：

```java
Function<String, Integer> f = String::length;
```

这里赋值语句左边提供了目标类型：

```java
Function<String, Integer>
```

所以编译器知道要把 `String::length` 解释成：

```java
s -> s.length()
```

下面这种不行：

```java
// var ref = String::length;
```

因为 `var` 无法给方法引用提供目标类型，编译器不知道 `String::length` 应该匹配哪个函数式接口。

重载歧义示例：

```java
class Overload {
    void accept(CharSequence cs) {}
    void accept(Serializable s) {}
}
```

因为 `String` 同时实现了 `CharSequence` 和 `Serializable`，而这两个参数类型之间没有子类型关系，所以：

```java
Consumer<String> c = ov::accept;
```

会产生歧义。

可以改成显式 Lambda，并在 Lambda 内强转：

```java
Consumer<String> c = s -> ov.accept((CharSequence) s);
```

或者选择另一个重载：

```java
Consumer<String> c = s -> ov.accept((Serializable) s);
```

## 总结对照表

| 写法 | 含义 | 示例等价 Lambda |
|---|---|---|
| `类名::实例方法` | 未绑定实例方法引用，第一个参数是接收者 | `String::length` 等价 `s -> s.length()` |
| `对象::实例方法` | 绑定实例方法引用，接收者固定 | `System.out::println` 等价 `s -> System.out.println(s)` |
| `类名::new` | 构造器引用，由目标接口选择构造器 | `Person::new` 可等价 `() -> new Person()` 或 `name -> new Person(name)` |
| `数组类型::new` | 数组构造器引用 | `int[]::new` 等价 `n -> new int[n]` |
| 方法引用单独使用 | 不允许，必须有目标类型 | `var f = String::length;` 编译错误 |
