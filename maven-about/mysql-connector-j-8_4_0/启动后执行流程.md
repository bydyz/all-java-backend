# Spring Boot 启动后执行流程

## 总览

```
mvn spring-boot:run
│
├─ 1. Spring Boot 初始化
├─ 2. DatabaseDemoRunner（数据库连接示例）
├─ 3. CrudDemoRunner（CRUD 操作示例）
└─ 4. Tomcat 就绪，监听 8080 端口
```

---

## 1. Spring Boot 初始化

| 步骤 | 说明 |
|------|------|
| 加载配置 | 读取 `application.properties`（数据库 URL、用户名、密码） |
| 创建连接池 | HikariCP 初始化，创建数据库连接 |
| 连接数据库 | 通过 `com.mysql.cj.jdbc.Driver` 连接 MySQL |

---

## 2. DatabaseDemoRunner（数据库连接示例）

实现 `CommandLineRunner` 接口，Spring Boot 启动后自动执行。

```
DatabaseDemoRunner.run()
│
├─ testConnection()
│   ├─ 获取数据库元信息（DatabaseMetaData）
│   ├─ 输出：数据库产品名称 MySQL
│   ├─ 输出：数据库产品版本 8.4.0
│   ├─ 输出：驱动程序版本 mysql-connector-j-9.7.0
│   ├─ 输出：连接 URL
│   └─ 输出：用户名
│
├─ executeSimpleQuery()
│   ├─ SELECT VERSION() → MySQL 8.4.0
│   └─ SELECT DATABASE() → my_test_database
│
└─ createExampleTable()
    ├─ DROP TABLE IF EXISTS users
    └─ CREATE TABLE users (id, username, email, created_at)
```

---

## 3. CrudDemoRunner（CRUD 操作示例）

实现 `CommandLineRunner` 接口，在 DatabaseDemoRunner 之后执行。

```
CrudDemoRunner.run()
│
├─ 创建用户（INSERT）
│   ├─ zhangsan@example.com → id=1
│   ├─ lisi@example.com     → id=2
│   └─ wangwu@example.com   → id=3
│
├─ 查询所有用户（SELECT *）
│   └─ 返回 3 条记录
│
├─ 按 ID 查询（SELECT WHERE id=1）
│   └─ 找到 zhangsan
│
├─ 按用户名查询（SELECT WHERE username='zhangsan'）
│   └─ 找到 zhangsan
│
├─ 更新用户（UPDATE WHERE id=1）
│   └─ zhangsan → zhangsan_updated
│
├─ 获取总数（SELECT COUNT(*)）
│   └─ 3
│
├─ 删除用户（DELETE WHERE id=3）
│   └─ 删除 wangwu
│
└─ 再次查总数（SELECT COUNT(*)）
    └─ 2
```

---

## 4. Tomcat 就绪

| 项目 | 值 |
|------|-----|
| 端口 | 8080 |
| 上下文路径 | `/` |
| 就绪状态 | 等待 HTTP 请求 |

### 可用 REST API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/users` | 获取所有用户 |
| GET | `/api/users/{id}` | 根据 ID 获取用户 |
| POST | `/api/users` | 创建用户 |
| PUT | `/api/users/{id}` | 更新用户 |
| DELETE | `/api/users/{id}` | 删除用户 |
| GET | `/api/users/count` | 获取用户数量 |
