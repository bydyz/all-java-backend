# Java 堆与栈存放数据全解

## 一、先厘清 JVM 运行时数据区

| 区域                              | 线程私有 | 存什么                        | 生命周期     |
|---------------------------------|------|----------------------------|----------|
| **虚拟机栈**（本文"栈"）                 | 私有   | 栈帧：局部变量表、操作数栈、动态链接、返回地址    | 随方法调用/返回 |
| **堆**                           | 共享   | 对象实例、数组、实例变量、字符串常量池（JDK7+） | 由 GC 管理  |
| **方法区 / 元空间**（JDK8 后 Metaspace） | 共享   | 类元数据、静态变量、运行时常量池、JIT 代码    | 随类卸载     |
| **程序计数器**                       | 私有   | 当前字节码行号                    | 随线程      |
| **本地方法栈**                       | 私有   | native 方法调用                | 随线程      |

> 日常所说的"栈放基本类型、堆放对象"是**简化说法**，准确说法见下。

---

## 二、栈（虚拟机栈）能放什么

栈帧的**局部变量表**中每个 slot 可存：

1. **8 种基本类型的值**：`boolean、byte、char、short、int、float、long、double`

- `long / double` 占 2 个连续 slot

2. **对象引用 reference**（指针/句柄），指向堆或方法区中的对象
3. **returnAddress**（方法返回地址，字节码层面）

**操作数栈**中还放：表达式计算过程中的中间值（如 `a + b` 的中间结果）。

**不能放**：对象实例本身、数组内容。

> 关键：栈上放的是**基本类型的"值"本身**和**引用类型的"地址"**，**从不放对象本体**。

---

## 三、堆能放什么

- **所有 `new` 出来的对象实例**（包括匿名内部类、Lambda 生成的对象）
- **所有数组**：基本类型数组 `int[]`、引用类型数组 `String[]`、对象数组 `Object[]`
- **对象的实例变量（成员变量）**：基本类型成员直接嵌在对象内存中；引用成员存的是引用
- **包装类对象**：`Integer/Long/Double...`（注意 `-128~127` 的 Integer 缓存复用）
- **String 对象**及 **字符串常量池**（JDK 7 起从永久代移到堆）
- **TLAB**：线程本地分配缓冲（堆内优化）

**不放**：类元数据、静态变量（在 Metaspace）、编译期常量（常量池）。

## 四、完整代码 + 逐行分析

### 示例一：各种数据落在哪

```java
public class MemoryLayoutDemo {

    /* ============ 1. 静态变量（类变量） ============ */
    static int     staticInt  = 10;           // 值随类信息在 Metaspace
    static Integer staticInte = 100;          // 引用在 Metaspace，Integer 对象在堆
    static String  staticStr  = "static";     // 引用在 Metaspace，"static" 字面量在字符串常量池（堆）
    static int[]   staticArr  = {1, 2, 3};    // 引用在 Metaspace，数组对象在堆
    static final int CONST    = 999;          // 编译期常量，进 class 常量池 → 运行时常量池

    /* ============ 2. 实例变量（成员变量） ============ */
    int     instanceInt    = 1;               // 值直接嵌在堆中的对象里
    long    instanceLong   = 2L;
    double  instanceDouble = 3.0;
    boolean instanceBool   = true;
    char    instanceChar   = 'a';
    byte    instanceByte   = 1;
    short   instanceShort  = 2;
    float   instanceFloat  = 1.5f;

    String  instanceStr = "hello";            // 引用嵌在对象里，指向常量池
    Object  instanceObj = new Object();       // 引用嵌在对象里，指向堆另一对象
    int[]   instanceArr = new int[10];        // 引用嵌在对象里，指向堆中数组

    /* ============ 3. 方法：局部变量 ============ */
    public void localVariables(int paramInt, String paramStr, Object paramObj) {
        // paramInt  : 基本类型值 → 栈帧局部变量表
        // paramStr  : 引用在栈，指向堆中的 String
        // paramObj  : 引用在栈，指向堆中的对象

        // ---- 基本类型局部变量：值在栈 ----
        byte    b    = 1;
        short   s    = 2;
        int     i    = 3;
        long    l    = 4L;      // 占 2 个 slot
        float   f    = 5.0f;
        double  d    = 6.0;     // 占 2 个 slot
        char    c    = 'x';
        boolean bool = true;

        // ---- 引用类型局部变量：引用在栈，对象在堆 ----
        String s1 = "abc";                       // 引用在栈；"abc" 在字符串常量池（堆）
        String s2 = "abc";                       // 复用同一常量池对象 → s1 == s2
        String s3 = new String("abc");           // new 出的对象在堆（另有一份 "abc" 在常量池）
        String s4 = new String(new char[]{'a','b','c'}); // 完全在堆

        Object o1 = new Object();                // 引用在栈，对象在堆
        int[]    arr1 = {1, 2, 3};               // 引用在栈，数组对象在堆，元素是基本类型值
        String[] arr2 = {"a", "b"};              // 引用在栈，数组对象在堆，元素是引用
        Object[] arr3 = new Object[2];           // 引用在栈，数组对象在堆

        // ---- 包装类与缓存 ----
        Integer i1 = 127;                        // Integer.valueOf(127)，命中 IntegerCache → 复用堆中缓存对象
        Integer i2 = 127;
        Integer i3 = 128;                        // 超缓存，new Integer(128)，新对象在堆
        Integer i4 = 128;
        // i1 == i2 → true ; i3 == i4 → false

        // ---- 匿名内部类：捕获变量拷贝进堆上对象 ----
        final int captured = 10;                 // 值在栈
        Runnable r = new Runnable() {
            @Override public void run() { System.out.println(captured); }
        };
        // r 引用在栈，匿名类对象在堆；captured 被拷贝为内部类字段（也在堆）

        // ---- Lambda ----
        Runnable r2 = () -> System.out.println(i); // lambda 对象由 invokedynamic 生成，在堆

        // ---- 中间结果：在操作数栈计算，结果回写局部变量表 ----
        int sum = i + s;
    }

    /* ============ 4. main 方法 ============ */
    public static void main(String[] args) {
        MemoryLayoutDemo demo = new MemoryLayoutDemo();
        // demo 引用在 main 栈帧，实例在堆；实例变量全部随实例在堆

        demo.localVariables(1, "p", new Object());

        // 对比验证：
        String a = "abc";
        String b = "abc";
        String c = new String("abc");
        System.out.println(a == b);              // true（同一常量池对象）
        System.out.println(a == c);              // false（c 是堆上新对象）
        System.out.println(a == c.intern());     // true（intern 返回常量池引用）
    }
}
```

### 示例二：逃逸分析与"栈上分配"（JIT 优化，非语言规范）

```java
class Point {
    int x, y;
    Point(int x, int y) { this.x = x; this.y = y; }
}

public class EscapeDemo {

    // p 不逃逸方法外，JIT 可能做"标量替换"：
    // 把对象拆成基本类型局部变量，实际不分配在堆
    public int noEscape() {
        Point p = new Point(1, 2);
        return p.x + p.y;
    }

    // 返回引用 → 逃逸，必须在堆分配
    public Point escape() {
        return new Point(1, 2);
    }
}
```

> 说明：Java 语言规范要求 `new` 的对象语义上在堆；HotSpot 的"栈上分配"实质是**逃逸分析 + 标量替换**把对象打散成基本类型局部变量，
**不是真的在栈上放对象**。可以通过 `-XX:+DoEscapeAnalysis -XX:+EliminateAllocations` 控制（默认开启）。

## 五、常见误区

| 误区                                         | 正解                                                                    |
|--------------------------------------------|-----------------------------------------------------------------------|
| "基本类型都放栈"                                  | 只有**局部**基本类型在栈。**实例变量**中的基本类型嵌在**堆对象**里；**静态变量**中的基本类型在 **Metaspace** |
| "对象都在堆"                                    | 语义上成立；JIT 逃逸分析可能标量替换，物理上不分配                                           |
| "字符串常量池在方法区"                               | JDK 6 及之前在永久代；**JDK 7 起移到堆中**，JDK 8 仍在堆                               |
| "栈里存对象"                                    | 栈里只存**引用**和**基本类型值**，对象本体永远在堆                                         |
| "String s = new String(\"abc\") 只创建 1 个对象" | 若常量池无 "abc" 则创建 2 个：常量池 1 个 + 堆上 1 个                                  |
| "Integer i = 100 一定 new"                   | 命中 `-128~127` 缓存则复用 `IntegerCache` 中的对象                               |

## 六、总结表

| 数据种类                                | 存放位置                    |
|-------------------------------------|-------------------------|
| 局部基本类型变量 / 方法参数（基本类型）               | **栈**（局部变量表）            |
| 局部引用变量 / 方法参数（引用）                   | **栈**存引用，对象在**堆**       |
| 实例变量（成员变量）— 基本类型                    | **堆**（嵌在对象内存中）          |
| 实例变量 — 引用类型                         | **堆**（对象里存引用），指向对象也在堆   |
| 静态变量                                | **方法区/元空间**（引用所指对象在堆）   |
| `static final` 编译期常量                | 运行时常量池（方法区/元空间）         |
| `new` 的对象（含匿名类、Lambda）              | **堆**（JIT 标量替换为例外优化）    |
| 数组（`int[]`、`String[]`、`Object[]` 等） | **堆**                   |
| 字符串字面量 `"abc"`                      | 字符串常量池（JDK7+ 在**堆**）    |
| `new String(...)` 对象                | **堆**                   |
| 包装类对象（`Integer` 等）                  | **堆**（`Integer` 缓存范围复用） |
| 方法返回地址 / 操作数栈中间值                    | **栈**                   |
| 类元数据、方法字节码                          | 方法区 / 元空间               |

一句话记忆：**栈存"值"和"地址"（基本类型值 + 引用），堆存"对象本体"（实例、数组、实例变量），Metaspace 存"类相关"
（类元数据、静态变量、运行时常量池）。**
