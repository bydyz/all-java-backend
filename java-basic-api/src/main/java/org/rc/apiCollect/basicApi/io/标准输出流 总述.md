# Java 标准输出流详解

`System.out` 是 Java 标准输出流的核心，它本质上是一个**预定义的 `PrintStream` 实例**。我们日常使用的 `System.out.println("Hello")`，可以拆解为“获取静态对象 `System.out`”和“调用其 `println` 方法”两个步骤。

---

## 📌 它是什么？—— 从源码看本质

在 `java.lang.System` 类中，`out` 被声明为一个静态常量：

```java
public static final PrintStream out = null;
```

这说明：

1. **`out` 是 `System` 类的静态成员**：因此无需创建 `System` 对象，直接通过 `System.out` 即可访问。
2. **它的类型是 `java.io.PrintStream`**：`PrintStream` 是 Java I/O 中的一个**字节打印流**，它继承自 `FilterOutputStream`，专门设计用于方便地输出各种数据的文本表示形式。

`System.out` 的初始化是一个由 JVM 在启动时完成的底层过程，大致链路为：

```text
FileDescriptor.out (标准输出设备的文件描述符)
    → FileOutputStream (字节文件流)
    → BufferedOutputStream (带缓冲的字节流)
    → PrintStream (打印流)
```

---

## 🎯 它的作用是什么？

标准输出流的核心作用是**向“标准输出”目标（通常是控制台/终端）打印程序的运行结果或提示信息**。

它与**标准错误流 `System.err`** 在职责上有明确分工：

- `System.out` 用于正常的程序输出；
- `System.err` 专门用于输出错误消息。

这种分离使得在 Shell 中可以将它们重定向到不同的位置，比如正常结果存入文件，错误信息仍显示在屏幕上。

---

## 🗂️ 如何分类？—— 不止 `System.out`

如果广义地理解“Java 中用于标准输出的流”，可以从两个维度来看：

### 1. 按流的数据单位分：字节流 vs. 字符流

`System.out` 本身是**字节流**（`PrintStream` 继承自 `OutputStream`）。Java I/O 中还存在对应的**字符流**体系，用于直接处理文本（字符）数据。

| 维度 | 字节流 | 字符流 |
| :--- | :--- | :--- |
| **核心抽象类** | `OutputStream` | `Writer` |
| **“打印”实现** | **`PrintStream`** | **`PrintWriter`** |
| **`System.out` 类型** | **是**（`PrintStream`） | 否 |
| **数据单位** | 字节（byte） | 字符（char） |
| **典型用途** | 原始字节数据、`System.out`/`System.err` | 文本文件读写、网络文本传输 |

`PrintStream` 和 `PrintWriter` 都提供了方便的 `print()` / `println()` 方法，但 `PrintStream` 在底层会将字符按照平台默认编码转换为字节后输出。

### 2. 按使用方式分：标准流 vs. 可包装的自定义输出流

`System.out` 是一个**预定义的标准流**。我们也可以自行创建指向其他目标（如文件、字节数组）的**自定义输出流**，并套用相同的“打印”接口。

- **标准输出流**：`System.out`（预定义，指向控制台）。
- **自定义打印流**：可以通过 `new PrintStream(目标OutputStream)` 的方式，将打印功能赋予任何输出目标。

## 💻 代码示例

### 示例 1：`System.out` 的基本使用与数据类型重载

`PrintStream` 的 `println` 方法通过**重载**支持多种数据类型，它会自动调用对象的 `toString()` 方法（如果有）将其转为字符串输出。

```java
public class StandardOutputDemo {
    public static void main(String[] args) {
        // print 与 println 的区别：println 会追加换行符
        System.out.print("Hello, ");
        System.out.println("World!"); // 输出后换行

        // println 的方法重载，支持多种类型
        System.out.println(42);                // int
        System.out.println(3.14159);           // double
        System.out.println(true);              // boolean
        System.out.println('A');               // char
        System.out.println(new Object());      // 对象，会调用其 toString()

        // 无参 println 仅输出一个换行
        System.out.println();
    }
}
```

### 示例 2：创建自定义的 `PrintStream`（输出到文件）

`System.out` 只是一个绑定到控制台的 `PrintStream`。我们可以用同样的方式，将打印流绑定到文件。

```java
import java.io.*;

public class CustomPrintStreamDemo {
    public static void main(String[] args) {
        // 使用 try-with-resources 确保流被自动关闭
        try (PrintStream fileOut = new PrintStream(
                new BufferedOutputStream(new FileOutputStream("output.txt")))) {

            // 像使用 System.out 一样使用 fileOut
            fileOut.println("这一行被写入文件，而不是控制台。");
            fileOut.printf("格式化输出：PI = %.2f%n", Math.PI);

        } catch (FileNotFoundException e) {
            // 注意：PrintStream 默认不抛出 IOException，
            // 但 FileOutputStream 构造时可能抛出
            System.err.println("文件创建失败: " + e.getMessage());
        }
    }
}
```

### 示例 3：`PrintWriter`（字符流版本的“打印”接口）

`PrintWriter` 是 `Writer` 体系的“打印”实现，用法与 `PrintStream` 非常相似，但底层是字符流，更适合纯文本处理。

```java
import java.io.*;

public class PrintWriterDemo {
    public static void main(String[] args) {
        try (PrintWriter writer = new PrintWriter("chars.txt")) {
            writer.println("使用 PrintWriter 写入文本。");
            writer.printf("支持格式化: %d + %d = %d%n", 1, 2, 3);
        } catch (FileNotFoundException e) {
            System.err.println(e);
        }
    }
}
```

## 💎 补充要点

- **`write()` 方法**：`PrintStream` 也继承了 `write(int b)` 和 `write(byte[] buf)` 方法，用于直接写入字节，而不是字符的文本表示。
- **关于顺序的“Bug”**：由于 `System.out` 和 `System.err` 是**两个独立的流**，在某些环境下（特别是当它们都指向控制台时），由于缓冲和刷新时机的差异，它们的输出顺序可能与代码中的顺序不一致。这不是 Bug，而是两个独立 I/O 通道并行工作的正常现象。
- **重定向**：`System` 类提供了 `setOut(PrintStream out)` 方法，可以在运行时**动态替换**标准输出流的目标。例如，可以将 `System.out` 重定向到一个文件，之后所有 `System.out.println` 的内容都会写入该文件，这在日志记录或测试中非常有用。
