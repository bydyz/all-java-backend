Java 中“有限制的通配符”（bounded wildcard）主要有两种：

1. **上界通配符**：`<? extends T>`
   表示未知类型是 `T` 或 `T` 的子类型。
2. **下界通配符**：`<? super T>`
   表示未知类型是 `T` 或 `T` 的父类型。

无界通配符 `<?>` 不属于“有限制通配符”，但常一起比较。

---

## 1. 上界通配符 `<? extends T>`

适合“读取/生产”数据，常称 **Producer Extends**。
可以安全读出为 `T`，但通常不能写入具体元素，因为实际类型可能是 `T` 的某个子类。

```java
import java.util.*;

public class ExtendsDemo {
    static double sum(List<? extends Number> list) {
        double s = 0;
        for (Number n : list) {   // OK：可以按 Number 读取
            s += n.doubleValue();
        }
        return s;
    }

    public static void main(String[] args) {
        List<Integer> ints = Arrays.asList(1, 2, 3);
        List<Double> doubles = Arrays.asList(1.5, 2.5);

        System.out.println(sum(ints));    // 6.0
        System.out.println(sum(doubles)); // 4.0

        List<? extends Number> nums = new ArrayList<Integer>();
        Number n = nums.get(0); // OK，读取为 Number
        // nums.add(1);        // 编译错误：不能安全写入具体 Number
        nums.add(null);        // 可以，但通常无实际意义
    }
}
```

---

## 2. 下界通配符 `<? super T>`

适合“写入/消费”数据，常称 **Consumer Super**。
可以安全写入 `T` 或其子类型，但读取时只能保证是 `Object`。

```java
import java.util.*;

public class SuperDemo {
    static void addOne(List<? super Integer> list) {
        list.add(1);       // OK：可以写入 Integer
        // Integer x = list.get(0); // 编译错误：读取只能保证是 Object
        Object o = list.get(0);     // OK
    }

    public static void main(String[] args) {
        List<Number> numbers = new ArrayList<>();
        List<Object> objects = new ArrayList<>();
        List<Integer> ints = new ArrayList<>();

        addOne(numbers); // OK，Number 是 Integer 的父类
        addOne(objects); // OK，Object 是 Integer 的父类
        addOne(ints);    // OK，Integer 自身也可以

        // addOne(new ArrayList<String>()); // 编译错误
    }
}
```

## 3. PECS 原则

`Collections.copy` 是典型例子：

```java
static <T> void copy(List<? super T> dest, List<? extends T> src) {
    for (T e : src) {
        dest.add(e);
    }
}
```

- `src` 是生产者：用 `? extends T`，只读。
- `dest` 是消费者：用 `? super T`，只写。

调用示例：

```java
List<Number> dest = new ArrayList<>();
List<Integer> src = Arrays.asList(1, 2, 3);
copy(dest, src);
System.out.println(dest); // [1, 2, 3]
```

## 4. 常见限制

```java
// 1. 通配符不能有多个上界
// List<? extends Number & Comparable<Number>> x; // 编译错误

// 2. 不能同时 extends 和 super
// List<? extends Number super Integer> y; // 编译错误

// 3. 不能用通配符实例化对象
// List<? extends Number> z = new ArrayList<? extends Number>(); // 编译错误

// 4. 泛型类声明中不能用通配符，应该用类型参数
// class Box<? extends Number> { } // 编译错误

class Box<T extends Number & Comparable<T>> { } // 合法：类型参数可以有多个上界
```

总结：

| 通配符形式 | 含义 | 读取 | 写入 | 典型用途 |
|---|---|---|---|---|
| `<? extends T>` | `T` 或 `T` 的子类 | 可读为 `T` | 通常不能写具体值 | 生产者、只读 |
| `<? super T>` | `T` 或 `T` 的父类 | 只能读为 `Object` | 可写 `T` 及其子类 | 消费者、只写 |

因此，Java 中有限制通配符就是 `<? extends T>` 和 `<? super T>` 两种。
