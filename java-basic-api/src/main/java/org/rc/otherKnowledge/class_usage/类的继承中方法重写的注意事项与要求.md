# Java 方法重写的注意事项与要求

方法重写（Override）是子类对父类**可访问**实例方法的重新实现。下面按“硬性规则 → 不可重写的情况 → 实践要点”三部分，配合代码逐条说明。

---

## 一、重写的核心硬性规则

| 规则         | 要求                         | 违反后果            |
|------------|----------------------------|-----------------|
| 方法签名       | 方法名 + 参数列表（类型、顺序、个数）必须完全相同 | 编译错误（变成重载或无关方法） |
| 返回类型       | 相同，或为父类返回类型的**子类型**（协变返回）  | 编译错误            |
| 访问权限       | 不能比父类**更严格**（可相同或更宽）       | 编译错误            |
| 检查异常       | 不能抛出比父类**更宽**的检查异常；可不抛     | 编译错误            |
| final 方法   | 不能重写                       | 编译错误            |
| static 方法  | 不能重写（只能“隐藏”）               | 编译错误或变成隐藏       |
| private 方法 | 不能重写（不可见）                  | 不算重写，是新方法       |
| 构造方法       | 不能重写                       | 编译错误            |

---

## 二、逐条代码详解

### 1. 方法签名必须一致

```java
class Parent {
    public void hello(String name) {
        System.out.println("Parent: " + name);
    }
}

class Child extends Parent {
    @Override
    public void hello(String name) {   // 签名一致 → 合法重写
        System.out.println("Child: " + name);
    }

    // public void hello(String name, int age) {} // 不是重写，是重载
    // public void hello(Object name) {}          // 不是重写，是重载
}
```

> 参数**名字**可以不同，不影响重写；只认类型、顺序、个数。

### 2. 返回类型：相同或协变

Java 5 起支持**协变返回类型**：子类返回类型可以是父类返回类型的子类型。

```java
class Parent {
    public Object create() { return new Object(); }
}

class Child extends Parent {
    @Override
    public String create() {   // String 是 Object 子类型 → 合法
        return "hello";
    }
}
```

基本类型**没有协变**，必须完全相同：

```java
class Parent {
    public int num() { return 1; }
}
class Child extends Parent {
    // public long num() { return 1L; } // 编译错误：返回类型不兼容
}
```

> 进阶：协变返回 + 泛型擦除时，编译器会生成**桥接方法**（bridge method）。例如 `Parent<T>` 的 `T get()`
> 被擦除为 `Object get()`，子类 `String get()` 编译后会产生一个合成的 `Object get()` 桥接方法转发调用。可用 `javap -c` 观察。

### 3. 访问权限不能更严格

访问权限顺序：`private < 默认(package) < protected < public`

```java
class Parent {
    protected void work() {}
}

class Child extends Parent {
    @Override
    public void work() {}        // 合法：更宽

    // @Override
    // private void work() {}    // 编译错误：访问权限更严格
}
```

### 4. 检查异常不能更宽泛

子类重写方法抛出的**检查异常**必须是父类异常类型的子类型，或不抛；**非检查异常（RuntimeException 系）不受限制**。

```java
import java.io.*;
import java.sql.SQLException;

class Parent {
    public void read() throws IOException {}
}

class Child extends Parent {
    @Override
    public void read() {}                                  // 合法：不抛

    // public void read() throws Exception {}              // 错误：比 IOException 宽
    // public void read() throws SQLException {}           // 错误：不相关的检查异常

    @Override
    public void read() throws FileNotFoundException {}     // 合法：IOException 子类
}

class Child2 extends Parent {
    @Override
    public void read() throws RuntimeException {}          // 合法：非检查异常不限
}
```

### 5. 不能重写 final 方法

```java
class Parent {
    public final void locked() {}
}

class Child extends Parent {
    // public void locked() {} // 编译错误：被覆盖的方法为 final
}
```

### 6. 不能重写 static 方法（是“隐藏”）

static 方法属于类，编译期绑定，**不存在多态重写**。子类定义同名 static 方法叫**隐藏（hiding）**。

```java
class Parent {
    public static void s() { System.out.println("Parent static"); }
    public void i() { System.out.println("Parent instance"); }
}

class Child extends Parent {
    public static void s() { System.out.println("Child static"); }  // 合法：隐藏

    // public void i() { }        // 编译错误：不能重写静态方法（若父类 i 是 static）
    // public static void i() {}  // 编译错误：不能用静态方法隐藏实例方法
}
```

> 静态方法调用看**编译时类型**：
> ```java
> Parent p = new Child();
> p.s(); // 输出 Parent static（编译期绑定）
> ```

### 7. 不能重写 private 方法

private 方法对子类不可见，子类写同名方法**只是新方法**，不构成重写。

```java
class Parent {
    private void secret() { System.out.println("Parent private"); }
    public void call() { secret(); }   // 父类内部调用自己的 private
}

class Child extends Parent {
    public void secret() { System.out.println("Child method"); } // 不是重写！
}

public class Demo {
    public static void main(String[] args) {
        new Child().call(); // 输出 Parent private（父类内部编译期绑定）
    }
}
```

### 8. 构造方法不能被重写

构造方法名必须与类名相同，且不被继承。子类构造方法只能通过 `super(...)` **调用**父类构造方法。

```java
class Parent {
    public Parent() {}
    public Parent(int x) {}
}

class Child extends Parent {
    public Child() {
        super(10); // 调用父类构造方法，不是重写
    }
}
```

### 9. 父类方法在子类包中不可见时，无法重写

```java
// 包 com.a
package com.a;
public class Parent {
    void packageMethod() {}   // 默认访问权限
}

// 包 com.b
package com.b;
import com.a.Parent;
public class Child extends Parent {
    // @Override  // 编译错误：父类方法在 com.a 包中不可见，不是重写
    public void packageMethod() {} // 这是新方法，不是重写
}
```

> 若子类与父类**同包**，则 package-private 方法可以正常重写。

## 三、实践要点

### 10. 始终使用 `@Override`

让编译器帮你检查“是否真的构成重写”，避免误写成重载。

```java
class Parent {
    public void run(int speed) {}
}
class Child extends Parent {
    @Override
    public void run(int speed) {}   // OK

    // @Override
    // public void run(long speed) {} // 编译错误：参数不同，不是重写
}
```

### 11. 用 `super` 调用父类实现

```java
class Parent {
    public void log(String msg) { System.out.println("[Parent] " + msg); }
}
class Child extends Parent {
    @Override
    public void log(String msg) {
        super.log(msg);                  // 复用父类逻辑
        System.out.println("[Child] " + msg);
    }
}
```

### 12. 多态：重写方法运行时动态绑定

```java
Parent p = new Child();
p.log("hi");  // 调用的是 Child 的 log()，编译看左边，运行看右边
```

### 13. 接口默认方法的重写

多个接口有同名默认方法时，实现类**必须重写**，否则编译错误；可用 `接口名.super.方法()` 指定调用。

```java
interface A { default void hello() { System.out.println("A"); } }
interface B { default void hello() { System.out.println("B"); } }

class C implements A, B {
    @Override
    public void hello() {
        A.super.hello();   // 明确调用 A 的默认实现
        B.super.hello();
    }
}
```

### 14. 重写 vs 重载（易混淆）

|      | 重写 Override | 重载 Overload  |
|------|-------------|--------------|
| 位置   | 父子类之间       | 同一个类（或父子类）   |
| 签名   | 必须相同        | 方法名相同、参数列表不同 |
| 返回类型 | 相同或协变       | 可任意          |
| 绑定   | 运行时动态绑定     | 编译期静态绑定      |

```java
class Parent {
    public void m(int x) {}
}
class Child extends Parent {
    @Override public void m(int x) {}       // 重写
    public void m(String s) {}              // 重载
    public void m(int x, int y) {}          // 重载
}
```

### 15. 其他小注意点

- 重写方法可以加 `synchronized`、`native`、`strictfp` 等修饰符，**不影响重写规则**（它们不属于方法签名）。
- 子类重写方法可以声明为 `final`，防止孙类继续重写（合法）。
- 泛型方法重写时要考虑**类型擦除**：父类 `void m(List<String>)` 与子类 `void m(List<Integer>)` 擦除后签名冲突，会编译报错。
- 若父类方法是 `abstract`，子类（非抽象）**必须重写**，否则子类也必须是 `abstract`。

## 四、常见编译错误速查

| 写法                                                           | 报错原因         |
|--------------------------------------------------------------|--------------|
| `private void m()` 重写 `protected void m()`                   | 访问权限更严格      |
| `long m()` 重写 `int m()`                                      | 基本类型返回不兼容    |
| `void m() throws Exception` 重写 `void m() throws IOException` | 检查异常更宽       |
| `static void m()` 重写父类实例方法 `void m()`                        | 静态方法不能隐藏实例方法 |
| `void m()` 重写父类 `static void m()`                            | 实例方法不能重写静态方法 |
| 重写 `final` 方法                                                | 方法为 final    |
| 子类同名同参但父类方法跨包不可见 + `@Override`                               | 不构成重写        |

---

**总结一句话**：重写要求“**签名相同、返回协变、权限不降、异常不宽、父方法可访问且非 final/static/private**
”；实践中坚持写 `@Override`，需要复用父类逻辑时用 `super`，并理解多态是运行时动态绑定。
