# Java 可变个数的形参（可变参数 varargs）

## 一、概念

可变参数允许调用方法时传入**数量不固定**的实参（0 个、1 个或多个），本质上是**数组**的语法糖。

- 出现版本：JDK 5
- 关键字：`类型... 变量名`
- 编译后会被翻译成 `类型[] 变量名`

## 二、语法

```java
返回值类型 方法名(参数类型... 参数名) {
    // 方法体
}
```

**注意**：`...` 在类型和变量名之间，两边可以有空格，但推荐 `int... nums` 这种写法。

## 三、基础示例

```java
public class VarargsDemo {

    // 计算任意个整数的和
    public static int sum(int... nums) {
        int total = 0;
        for (int n : nums) {
            total += n;
        }
        return total;
    }

    // 拼接任意个字符串
    public static String join(String separator, String... words) {
        return String.join(separator, words);
    }

    public static void main(String[] args) {
        // 0 个参数
        System.out.println(sum());          // 0

        // 1 个参数
        System.out.println(sum(10));        // 10

        // 多个参数
        System.out.println(sum(1, 2, 3));   // 6

        // 直接传数组也合法
        System.out.println(sum(new int[]{1, 2, 3, 4})); // 10

        System.out.println(join("-", "a", "b", "c"));   // a-b-c
        System.out.println(join(",", new String[]{"x", "y"})); // x,y
    }
}
```

## 四、可变参数的本质：数组

在方法内部，`nums` 就是一个普通数组，可以用 `length`、`for-each`、索引访问。

```java
public static void printAll(String... items) {
    System.out.println("个数：" + items.length);
    for (int i = 0; i < items.length; i++) {
        System.out.println("[" + i + "] " + items[i]);
    }
    // items == null 时能进到这里，但调用方若显式传 (String[]) null 会 NPE
}
```

调用方式有两种等价写法：

```java
printAll("a", "b", "c");              // 编译器自动包装成 new String[]{"a","b","c"}
printAll(new String[]{"a", "b", "c"}); // 手动传数组
```

## 五、使用规则（重点）

1. **一个方法最多只能有一个可变参数**
   ```java
   // 编译错误
   // public void foo(int... a, String... b) {}
   ```

2. **可变参数必须是参数列表的最后一个**
   ```java
   // 正确
   public void foo(String name, int... scores) {}

   // 编译错误
   // public void foo(int... scores, String name) {}
   ```

3. **可变参数可以为空**，此时对应一个长度为 0 的数组，而不是 `null`（除非显式传 `null`）。

4. **不能与对应数组类型的方法重载**：`foo(int... a)` 与 `foo(int[] a)` 是同一个方法签名，无法共存。
   ```java
   public void foo(int... a) {}
   // public void foo(int[] a) {}  // 编译错误：方法重复定义
   ```

5. **传 `null` 会引发 NPE 风险**
   ```java
   // 警告：显式转型传 null，nums 内部为 null
   sum((int[]) null);  // 方法体中 nums.length 会抛 NullPointerException
   ```

## 六、与重载的优先级

当存在“固定参数版本”和“可变参数版本”时，**固定参数优先被调用**。

```java
public class OverloadDemo {

    public static void show(int a, int b) {
        System.out.println("固定参数：两个 int");
    }

    public static void show(int... nums) {
        System.out.println("可变参数：int... 个数=" + nums.length);
    }

    public static void main(String[] args) {
        show(1, 2);        // 输出：固定参数：两个 int
        show(1, 2, 3);     // 输出：可变参数：int... 个数=3
        show();            // 输出：可变参数：int... 个数=0
    }
}
```

## 七、典型应用场景

### 1. 工具类/日志方法

```java
public static void log(String level, Object... args) {
    StringBuilder sb = new StringBuilder("[" + level + "] ");
    for (Object a : args) {
        sb.append(a).append(" ");
    }
    System.out.println(sb.toString().trim());
}

// log("INFO", "user", 123, "login");
```

### 2. `String.format` 风格

```java
public static String format(String pattern, Object... args) {
    return String.format(pattern, args);
}
```

### 3. `main` 方法本身就是可变参数的“近亲”

```java
public static void main(String[] args) { }  // 数组形式
// 等价于 public static void main(String... args)
```

### 4. 集合工厂方法（JDK 9+）

```java
List<String> list = List.of("a", "b", "c");   // List.of(E... elements)
Set<Integer> set = Set.of(1, 2, 3);
```

## 八、完整综合示例

```java
import java.util.Arrays;

public class VarargsFullDemo {

    /** 固定前缀 + 任意个后缀 */
    public static String concat(String prefix, String... suffixes) {
        StringBuilder sb = new StringBuilder(prefix);
        for (String s : suffixes) {
            sb.append(s);
        }
        return sb.toString();
    }

    /** 求最大值，至少传 1 个参数 */
    public static int max(int first, int... rest) {
        int m = first;
        for (int n : rest) {
            if (n > m) m = n;
        }
        return m;
    }

    /** 泛型可变参数（注意会有一个 unchecked 警告） */
    @SafeVarargs
    public static <T> void printArray(T... items) {
        System.out.println(Arrays.toString(items));
    }

    public static void main(String[] args) {
        System.out.println(concat("Hello", ", ", "World", "!")); // Hello, World!
        System.out.println(max(3));                              // 3
        System.out.println(max(3, 9, 1, 7));                     // 9
        printArray("a", "b", "c");                               // [a, b, c]
    }
}
```

## 九、注意事项小结

| 事项   | 说明                               |
|------|----------------------------------|
| 位置   | 必须是参数列表最后一个                      |
| 数量   | 一个方法只能有一个                        |
| 本质   | 编译为数组，方法内按数组操作                   |
| 空参   | 默认得到长度为 0 的数组                    |
| null | 显式传 `null` 可能在方法内 NPE            |
| 重载   | 不能与同类型数组参数方法共存                   |
| 优先级  | 固定参数方法优先于可变参数方法被匹配               |
| 泛型   | 泛型 + 可变参数建议加 `@SafeVarargs` 消除警告 |
| 性能   | 每次调用若未直接传数组，会创建新数组，有轻微开销         |

## 十、最佳实践

1. 可变参数用于**参数个数确实不确定**的场景，不要滥用。
2. 若业务上至少需要 1 个参数，采用 `max(int first, int... rest)` 形式强制校验。
3. 泛型可变参数方法加 `@SafeVarargs`（需为 `final`、`static` 或 `private` 方法）。
4. 方法内部先判空或避免外部显式传 `null` 数组。
5. 有固定参数重载时，优先提供固定参数版本以提升可读性与性能。
