## 1. 概述

Java 是强类型语言，每个变量都必须声明其数据类型。Java 数据类型分为两大类：

```
┌─────────────────────────────────────────────────────────┐
│                    Java 数据类型                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  基本数据类型（Primitive Types）                          │
│  ├── 整数类型：byte, short, int, long                    │
│  ├── 浮点类型：float, double                             │
│  ├── 字符类型：char                                      │
│  └── 布尔类型：boolean                                   │
│                                                         │
│  引用数据类型（Reference Types）                          │
│  ├── 类（Class）                                         │
│  ├── 接口（Interface）                                   │
│  ├── 数组（Array）                                       │
│  └── 枚举（Enum）                                        │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 2. 基本数据类型

Java 有 8 种基本数据类型，存储在栈内存中，直接存储值。

### 2.1 整数类型

| 类型 | 字节数 | 范围 | 默认值 | 示例 |
|------|--------|------|--------|------|
| `byte` | 1 | -128 ~ 127 | 0 | `byte b = 100;` |
| `short` | 2 | -32768 ~ 32767 | 0 | `short s = 1000;` |
| `int` | 4 | -2^31 ~ 2^31-1（约±21亿） | 0 | `int i = 100000;` |
| `long` | 8 | -2^63 ~ 2^63-1 | 0L | `long l = 100000L;` |

```java
public class IntegerTypesDemo {
    public static void main(String[] args) {
        // byte：占 1 字节，适合存储小整数
        byte temperature = 35;
        System.out.println("温度: " + temperature + "°C");

        // short：占 2 字节，适合存储中等整数
        short population = 30000;
        System.out.println("人口: " + population);

        // int：占 4 字节，最常用的整数类型
        int distance = 150000000;  // 1.5亿公里
        System.out.println("距离: " + distance + " km");

        // long：占 8 字节，适合存储大整数，后缀 L
        long worldPopulation = 8000000000L;
        System.out.println("世界人口: " + worldPopulation);

        // 不同进制表示
        int decimal = 100;       // 十进制
        int octal = 0144;        // 八进制（0前缀）
        int hexadecimal = 0x64;  // 十六进制（0x前缀）
        int binary = 0b1100100;  // 二进制（0b前缀）

        System.out.println("十进制: " + decimal);    // 100
        System.out.println("八进制: " + octal);      // 100
        System.out.println("十六进制: " + hexadecimal); // 100
        System.out.println("二进制: " + binary);     // 100

        // 数字下划线（Java 7+），提高可读性
        int creditCard = 1234_5678_9012_3456L;
        int piDigits = 3_14159_2653;
    }
}
```

### 2.2 浮点类型

| 类型 | 字节数 | 精度 | 默认值 | 示例 |
|------|--------|------|--------|------|
| `float` | 4 | 约6-7位有效数字 | 0.0f | `float f = 3.14f;` |
| `double` | 8 | 约15位有效数字 | 0.0 | `double d = 3.14159;` |

```java
public class FloatingPointDemo {
    public static void main(String[] args) {
        // float：单精度，后缀 f 或 F
        float price = 19.99f;
        float discount = 0.85f;
        System.out.println("价格: " + price);
        System.out.println("折扣: " + discount);

        // double：双精度，Java 默认浮点类型
        double pi = 3.141592653589793;
        double e = 2.718281828459045;
        System.out.println("π = " + pi);
        System.out.println("e = " + e);

        // 科学计数法
        double lightSpeed = 3.0e8;    // 3 × 10^8 m/s
        double micro = 1.5e-6;        // 1.5 × 10^-6
        System.out.println("光速: " + lightSpeed + " m/s");
        System.out.println("微米: " + micro);

        // ⚠️ 浮点数精度问题
        System.out.println(0.1 + 0.2);  // 0.30000000000000004（不是0.3）

        // ✅ 精确计算使用 BigDecimal
        import java.math.BigDecimal;
        BigDecimal a = new BigDecimal("0.1");
        BigDecimal b = new BigDecimal("0.2");
        BigDecimal sum = a.add(b);
        System.out.println("BigDecimal: " + sum);  // 0.3

        // 特殊值
        double infinity = Double.POSITIVE_INFINITY;
        double negInfinity = Double.NEGATIVE_INFINITY;
        double nan = Double.NaN;

        System.out.println(1.0 / 0.0);      // Infinity
        System.out.println(-1.0 / 0.0);     // -Infinity
        System.out.println(0.0 / 0.0);      // NaN
        System.out.println(Double.isNaN(nan)); // true
    }
}
```

### 2.3 字符类型

| 类型 | 字节数 | 范围 | 默认值 | 示例 |
|------|--------|------|--------|------|
| `char` | 2 | 0 ~ 65535（Unicode） | '\u0000' | `char c = 'A';` |

```java
public class CharacterDemo {
    public static void main(String[] args) {
        // char：占 2 字节，存储 Unicode 字符
        char letter = 'A';
        char chinese = '中';
        char emoji = '😊';

        System.out.println("字母: " + letter);
        System.out.println("中文: " + chinese);
        System.out.println("表情: " + emoji);

        // Unicode 转义序列
        char copyright = '\u00A9';  // ©
        char euro = '\u20AC';       // €
        char heart = '\u2764';      // ❤

        System.out.println("版权符号: " + copyright);
        System.out.println("欧元符号: " + euro);
        System.out.println("心形: " + heart);

        // ASCII 码操作
        char nextLetter = (char) (letter + 1);  // 'B'
        int asciiValue = letter;                  // 65

        System.out.println("下一个字母: " + nextLetter);
        System.out.println("ASCII 值: " + asciiValue);

        // 常用 Character 方法
        char upper = 'a';
        char lower = 'B';

        System.out.println(Character.toUpperCase(upper));  // 'A'
        System.out.println(Character.toLowerCase(lower));  // 'b'
        System.out.println(Character.isLetter('A'));       // true
        System.out.println(Character.isDigit('9'));        // true
        System.out.println(Character.isWhitespace(' '));   // true
    }
}
```

### 2.4 布尔类型

| 类型 | 字节数 | 值 | 默认值 | 示例 |
|------|--------|-----|--------|------|
| `boolean` | 1（JVM 实现相关） | true / false | false | `boolean flag = true;` |

```java
public class BooleanDemo {
    public static void main(String[] args) {
        // boolean：只有两个值 true 和 false
        boolean isActive = true;
        boolean isDeleted = false;

        System.out.println("是否激活: " + isActive);
        System.out.println("是否删除: " + isDeleted);

        // 条件表达式的结果是 boolean
        int age = 18;
        boolean isAdult = age >= 18;
        System.out.println("是否成年: " + isAdult);

        // 逻辑运算
        boolean a = true;
        boolean b = false;

        System.out.println("与运算: " + (a && b));   // false
        System.out.println("或运算: " + (a || b));   // true
        System.out.println("非运算: " + (!a));        // false

        // 实际应用：方法返回值
        if (isAdult) {
            System.out.println("可以进入");
        } else {
            System.out.println("禁止进入");
        }
    }
}
```

## 3. 基本数据类型转换

### 自动类型转换（隐式转换）

小范围类型可以自动转换为大范围类型。

```java
public class AutoConversionDemo {
    public static void main(String[] args) {
        // 自动类型转换（小 → 大）
        byte b = 100;
        int i = b;           // byte → int（自动）
        long l = i;          // int → long（自动）
        float f = l;         // long → float（自动）
        double d = f;        // float → double（自动）

        System.out.println("byte: " + b);
        System.out.println("int: " + i);
        System.out.println("long: " + l);
        System.out.println("float: " + f);
        System.out.println("double: " + d);

        // char 可以自动转换为 int
        char c = 'A';
        int charToInt = c;   // char → int（自动）
        System.out.println("char 转 int: " + charToInt);  // 65
    }
}
```

**自动转换规则：**

```
byte → short → int → long → float → double
char → int → long → float → double
```

### 强制类型转换（显式转换）

大范围类型转换为小范围类型需要强制转换，可能丢失精度。

```java
public class ExplicitConversionDemo {
    public static void main(String[] args) {
        // 强制类型转换（大 → 小）
        double d = 3.99;
        int i = (int) d;     // double → int（截断小数部分）
        System.out.println("double 转 int: " + i);  // 3（不是4）

        long l = 1000;
        byte b = (byte) l;   // long → byte（可能溢出）
        System.out.println("long 转 byte: " + b);   // 1000 % 256 = 232（溢出）

        // ⚠️ 注意精度丢失
        float price = 19.99f;
        int intPrice = (int) price;
        System.out.println("float 转 int: " + intPrice);  // 19

        // ✅ 推荐使用 Math.round() 四舍五入
        int rounded = (int) Math.round(price);
        System.out.println("四舍五入: " + rounded);  // 20

        // int 转 char
        int ascii = 65;
        char letter = (char) ascii;
        System.out.println("int 转 char: " + letter);  // 'A'

        // 溢出演示
        int bigNumber = 130;
        byte smallByte = (byte) bigNumber;
        System.out.println("溢出结果: " + smallByte);  // -126
    }
}
```

## 4. 包装类

每种基本数据类型都有对应的包装类，用于将基本类型转换为对象。

| 基本类型 | 包装类 | 字节数 | 默认值 |
|----------|--------|--------|--------|
| `byte` | `Byte` | 1 | 0 |
| `short` | `Short` | 2 | 0 |
| `int` | `Integer` | 4 | 0 |
| `long` | `Long` | 8 | 0L |
| `float` | `Float` | 4 | 0.0f |
| `double` | `Double` | 8 | 0.0 |
| `char` | `Character` | 2 | '\u0000' |
| `boolean` | `Boolean` | 1 | false |

```java
public class WrapperClassDemo {
    public static void main(String[] args) {
        // ========== 装箱（基本类型 → 包装类）==========
        // 方式1：自动装箱（Java 5+）
        Integer intObj1 = 100;         // 自动装箱
        Double doubleObj1 = 3.14;      // 自动装箱
        Boolean boolObj1 = true;       // 自动装箱

        // 方式2：手动装箱
        Integer intObj2 = Integer.valueOf(100);
        Double doubleObj2 = Double.valueOf(3.14);

        // ========== 拆箱（包装类 → 基本类型）==========
        // 方式1：自动拆箱
        int a = intObj1;              // 自动拆箱
        double d = doubleObj1;        // 自动拆箱

        // 方式2：手动拆箱
        int b = intObj2.intValue();
        double d2 = doubleObj2.doubleValue();

        // ========== 常用方法 ==========

        // 字符串转基本类型
        int num = Integer.parseInt("123");
        double pi = Double.parseDouble("3.14159");
        boolean flag = Boolean.parseBoolean("true");

        System.out.println("字符串转 int: " + num);
        System.out.println("字符串转 double: " + pi);
        System.out.println("字符串转 boolean: " + flag);

        // 基本类型转字符串
        String numStr = String.valueOf(123);
        String numStr2 = Integer.toString(123);
        String numStr3 = 123 + "";  // 拼接空字符串

        // Integer 常量
        System.out.println("最大值: " + Integer.MAX_VALUE);  // 2147483647
        System.out.println("最小值: " + Integer.MIN_VALUE);  // -2147483648

        // 进制转换
        String binary = Integer.toBinaryString(100);    // "1100100"
        String octal = Integer.toOctalString(100);      // "144"
        String hex = Integer.toHexString(100);          // "64"

        System.out.println("二进制: " + binary);
        System.out.println("八进制: " + octal);
        System.out.println("十六进制: " + hex);

        // ⚠️ 包装类比较
        Integer x = 127;
        Integer y = 127;
        System.out.println(x == y);  // true（缓存 -128~127）

        Integer m = 128;
        Integer n = 128;
        System.out.println(m == n);     // false（不同对象）
        System.out.println(m.equals(n)); // true（值相等）
    }
}
```

## 5. 引用数据类型

引用数据类型存储对象的引用（地址），存储在堆内存中。

### 5.1 类（Class）

```java
public class ClassDemo {
    public static void main(String[] args) {
        // 使用系统类
        String name = "Java";
        Integer number = 100;
        Double price = 99.99;

        System.out.println("字符串长度: " + name.length());
        System.out.println("字符串转大写: " + name.toUpperCase());

        // 使用自定义类
        Student student = new Student("张三", 20, 95.5);
        student.display();

        // 创建对象
        Dog dog = new Dog("旺财", 3);
        dog.bark();

        // 对象数组
        Student[] students = {
            new Student("李四", 21, 88.0),
            new Student("王五", 19, 92.5),
            new Student("赵六", 22, 78.5)
        };

        for (Student s : students) {
            s.display();
        }
    }
}

class Student {
    String name;
    int age;
    double score;

    public Student(String name, int age, double score) {
        this.name = name;
        this.age = age;
        this.score = score;
    }

    public void display() {
        System.out.println("姓名: " + name + ", 年龄: " + age + ", 成绩: " + score);
    }
}

class Dog {
    String name;
    int age;

    public Dog(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void bark() {
        System.out.println(name + "汪汪叫！");
    }
}
```

### 5.2 接口（Interface）

```java
// 定义接口
interface Drawable {
    void draw();  // 抽象方法

    default void fill(String color) {  // 默认方法（Java 8+）
        System.out.println("用 " + color + " 填充");
    }

    static void info() {  // 静态方法
        System.out.println("这是一个可绘制的接口");
    }
}

interface Resizable {
    void resize(double factor);
}

// 实现接口
class Circle implements Drawable {
    double radius;

    public Circle(double radius) {
        this.radius = radius;
    }

    @Override
    public void draw() {
        System.out.println("绘制半径为 " + radius + " 的圆");
    }
}

class Rectangle implements Drawable, Resizable {
    double width, height;

    public Rectangle(double width, double height) {
        this.width = width;
        this.height = height;
    }

    @Override
    public void draw() {
        System.out.println("绘制 " + width + "x" + height + " 的矩形");
    }

    @Override
    public void resize(double factor) {
        width *= factor;
        height *= factor;
        System.out.println("缩放后: " + width + "x" + height);
    }
}

public class InterfaceDemo {
    public static void main(String[] args) {
        Drawable circle = new Circle(5.0);
        circle.draw();
        circle.fill("红色");

        Drawable.info();  // 调用静态方法

        Rectangle rect = new Rectangle(10, 5);
        rect.draw();
        rect.resize(2.0);
    }
}
```

### 5.3 数组（Array）

```java
public class ArrayDemo {
    public static void main(String[] args) {
        // ========== 基本类型数组 ==========

        // 声明和初始化
        int[] numbers1 = new int[5];      // 创建长度为5的数组，默认值0
        int[] numbers2 = {1, 2, 3, 4, 5}; // 字面量初始化
        int[] numbers3 = new int[]{10, 20, 30}; // 另一种初始化方式

        // 访问和修改
        numbers1[0] = 100;
        numbers1[1] = 200;

        System.out.println("第一个元素: " + numbers1[0]);  // 100
        System.out.println("数组长度: " + numbers2.length);  // 5

        // 遍历数组
        for (int i = 0; i < numbers2.length; i++) {
            System.out.print(numbers2[i] + " ");
        }
        System.out.println();

        // 增强 for 循环
        for (int num : numbers2) {
            System.out.print(num + " ");
        }
        System.out.println();

        // ========== 对象数组 ==========

        String[] names = {"Alice", "Bob", "Charlie", "David"};

        // 排序
        java.util.Arrays.sort(names);
        System.out.println("排序后: " + java.util.Arrays.toString(names));

        // 搜索（二分查找，需先排序）
        int index = java.util.Arrays.binarySearch(names, "Charlie");
        System.out.println("Charlie 的索引: " + index);

        // 填充
        int[] filled = new int[5];
        java.util.Arrays.fill(filled, 99);
        System.out.println("填充后: " + java.util.Arrays.toString(filled));

        // 复制
        int[] copied = java.util.Arrays.copyOf(numbers2, 3);
        System.out.println("复制: " + java.util.Arrays.toString(copied));

        int[] copiedRange = java.util.Arrays.copyOfRange(numbers2, 1, 4);
        System.out.println("范围复制: " + java.util.Arrays.toString(copiedRange));

        // 多维数组
        int[][] matrix = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };

        // 遍历二维数组
        for (int[] row : matrix) {
            for (int cell : row) {
                System.out.print(cell + " ");
            }
            System.out.println();
        }

        // ========== 动态数组 ==========

        // 使用 ArrayList（推荐）
        java.util.ArrayList<String> list = new java.util.ArrayList<>();
        list.add("Java");
        list.add("Python");
        list.add("Go");

        System.out.println("ArrayList: " + list);
        System.out.println("大小: " + list.size());

        list.remove(1);  // 删除 "Python"
        System.out.println("删除后: " + list);
    }
}
```

## 6. String 字符串

String 是引用类型，不是基本类型，但使用非常频繁。

```java
public class StringDemo {
    public static void main(String[] args) {
        // ========== 创建字符串 ==========

        // 方式1：字面量（推荐，存储在常量池）
        String s1 = "Hello";

        // 方式2：new 对象（存储在堆内存）
        String s2 = new String("Hello");

        System.out.println(s1 == s2);       // false（不同对象）
        System.out.println(s1.equals(s2));   // true（值相等）

        // ========== 常用方法 ==========

        String text = "Hello, World!";

        // 长度
        System.out.println("长度: " + text.length());  // 13

        // 索引访问
        System.out.println("第一个字符: " + text.charAt(0));  // 'H'

        // 查找
        System.out.println("第一次出现 'o': " + text.indexOf('o'));  // 4
        System.out.println("最后一次出现 'o': " + text.lastIndexOf('o'));  // 8
        System.out.println("包含 'World': " + text.contains("World"));  // true

        // 截取
        System.out.println("子串: " + text.substring(7));  // "World!"
        System.out.println("子串: " + text.substring(0, 5));  // "Hello"

        // 转换大小写
        System.out.println("转大写: " + text.toUpperCase());
        System.out.println("转小写: " + text.toLowerCase());

        // 去除空格
        String padded = "  Hello  ";
        System.out.println("去除首尾空格: '" + padded.trim() + "'");

        // 替换
        System.out.println("替换: " + text.replace('o', '0'));
        System.out.println("替换: " + text.replace("World", "Java"));

        // 分割
        String csv = "apple,banana,cherry";
        String[] fruits = csv.split(",");
        for (String fruit : fruits) {
            System.out.println(fruit);
        }

        // 连接
        String joined = String.join(" - ", "A", "B", "C");
        System.out.println("连接: " + joined);

        // 格式化
        String name = "张三";
        int age = 25;
        String formatted = String.format("姓名: %s, 年龄: %d", name, age);
        System.out.println(formatted);

        // ========== StringBuilder（可变字符串）==========

        StringBuilder sb = new StringBuilder("Hello");

        sb.append(" World");      // 追加
        sb.insert(5, ",");         // 插入
        sb.replace(6, 11, "Java"); // 替换
        sb.delete(5, 6);           // 删除

        String result = sb.toString();
        System.out.println("StringBuilder: " + result);

        // ========== 字符串比较 ==========

        String a = "Hello";
        String b = "Hello";
        String c = new String("Hello");

        System.out.println("== 比较: " + (a == b));      // true（常量池）
        System.out.println("== 比较: " + (a == c));      // false
        System.out.println("equals 比较: " + a.equals(c)); // true

        // 忽略大小写比较
        System.out.println("忽略大小写: " + a.equalsIgnoreCase("hello"));

        // 字典序比较
        System.out.println("比较: " + "apple".compareTo("banana"));  // 负数
        System.out.println("比较: " + "apple".compareTo("apple"));   // 0
    }
}
```

### 常见使用示例

```java
public class DataTypeUsageExamples {
    public static void main(String[] args) {
        // ========== 示例1：用户信息管理 ==========
        String username = "张三";       // String：姓名
        int age = 25;                  // int：年龄
        double height = 175.5;         // double：身高
        char gender = '男';            // char：性别
        boolean isStudent = true;      // boolean：是否学生

        System.out.printf("用户信息: %s, %d岁, %.1fcm, %c, 学生: %b%n",
            username, age, height, gender, isStudent);

        // ========== 示例2：商品价格计算 ==========
        String productName = "iPhone 15";  // String：商品名
        double price = 7999.99;            // double：价格
        int quantity = 2;                  // int：数量
        boolean hasDiscount = true;        // boolean：是否有折扣
        double discountRate = 0.9;        // double：折扣率

        double total = price * quantity;
        if (hasDiscount) {
            total *= discountRate;
        }

        System.out.printf("商品: %s, 单价: %.2f, 数量: %d, 总价: %.2f%n",
            productName, price, quantity, total);

        // ========== 示例3：数组统计 ==========
        int[] scores = {85, 92, 78, 95, 88, 76, 91};

        int sum = 0;
        int max = scores[0];
        int min = scores[0];

        for (int score : scores) {
            sum += score;
            if (score > max) max = score;
            if (score < min) min = score;
        }

        double average = (double) sum / scores.length;

        System.out.println("成绩统计:");
        System.out.println("总分: " + sum);
        System.out.printf("平均分: %.2f%n", average);
        System.out.println("最高分: " + max);
        System.out.println("最低分: " + min);

        // ========== 示例4：字符串处理 ==========
        String email = "user@example.com";

        // 验证邮箱格式
        boolean hasAt = email.contains("@");
        boolean hasDot = email.contains(".");
        boolean isValid = hasAt && hasDot && email.length() > 5;

        System.out.println("邮箱: " + email);
        System.out.println("是否有效: " + isValid);

        // 提取用户名
        String username2 = email.substring(0, email.indexOf("@"));
        String domain = email.substring(email.indexOf("@") + 1);

        System.out.println("用户名: " + username2);
        System.out.println("域名: " + domain);

        // ========== 示例5：集合操作 ==========
        java.util.List<String> fruits = new java.util.ArrayList<>();
        fruits.add("苹果");
        fruits.add("香蕉");
        fruits.add("橙子");
        fruits.add("苹果");  // 重复元素

        // 去重
        java.util.Set<String> uniqueFruits = new java.util.HashSet<>(fruits);
        System.out.println("去重后: " + uniqueFruits);

        // 排序
        java.util.List<String> sortedFruits = new java.util.ArrayList<>(uniqueFruits);
        java.util.Collections.sort(sortedFruits);
        System.out.println("排序后: " + sortedFruits);
    }
}
```

## 总结

| 类型 | 用途 | 特点 |
|------|------|------|
| `byte` | 小整数、文件IO | 1字节，节省内存 |
| `short` | 中等整数 | 2字节 |
| `int` | 一般整数 | 4字节，最常用 |
| `long` | 大整数 | 8字节，后缀L |
| `float` | 单精度浮点 | 4字节，后缀f |
| `double` | 双精度浮点 | 8字节，最常用 |
| `char` | 单个字符 | 2字节，Unicode |
| `boolean` | 布尔值 | true/false |
| `String` | 文本 | 不可变，引用类型 |
| `包装类` | 集合存储、泛型 | 对象形式 |
| `数组` | 固定长度集合 | 同类型元素 |
| `类/接口` | 面向对象编程 | 引用类型 |
