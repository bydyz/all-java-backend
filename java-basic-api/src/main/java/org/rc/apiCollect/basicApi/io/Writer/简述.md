`java.io.Writer` 是 Java I/O 体系中**所有字符输出流的抽象超类**。它的核心职责是将内存中的字符（`char`，16位 Unicode）按照指定的编码规则转换为字节，并输出到各种目的地（文件、内存、字节流等）。由于 `Writer` 本身是抽象类，无法直接实例化，实际使用中总是通过它的具体子类（如 `FileWriter`、`BufferedWriter`、`StringWriter`）来完成操作。

---

### 🏛️ 类定义与继承关系

`Writer` 的类声明如下：

```java
public abstract class Writer implements Appendable, Closeable, Flushable
```

它实现了三个关键接口：

- **`Appendable`**：提供 `append` 系列方法，支持链式调用风格的字符追加。
- **`Closeable`**：提供 `close()` 方法，用于释放资源。
- **`Flushable`**：提供 `flush()` 方法，用于强制输出缓冲区中的数据。

`Writer` 的直接子类包括 `BufferedWriter`、`CharArrayWriter`、`FilterWriter`、`OutputStreamWriter`、`PipedWriter`、`PrintWriter`、`StringWriter` 等；`FileWriter` 是 `OutputStreamWriter` 的子类，因此也是 `Writer` 的间接子类。

---

### 🔨 构造器：为什么是 `protected`？

`Writer` 提供了 **两个 `protected` 构造器**，它们仅供子类在实例化时调用，这也是 `Writer` 不能直接 `new` 的根本原因。

#### `protected Writer()`

创建一个字符输出流，其**临界区（critical sections）以 `Writer` 自身（`this`）作为同步锁**。大多数子类使用这个无参构造器。

#### `protected Writer(Object lock)`

创建一个字符输出流，其**临界区以指定的 `lock` 对象作为同步锁**。

`Writer` 内部有一个 `protected Object lock` 字段，用于对写入操作进行同步。使用外部 `lock` 对象，可以让多个 `Writer` 实例共享同一把锁，或者在更细粒度上控制并发。子类在实现 `write`、`flush`、`close` 等方法时，应当对这个 `lock` 字段加锁，而不是对 `this` 加锁。

### 📚 核心 API 方法详解

`Writer` 中的方法可分为几类：**必须由子类实现的抽象方法**、**基于抽象方法构建的便捷方法**，以及**接口方法**。

#### 必须由子类实现的抽象方法

| 方法签名 | 说明 |
|---|---|
| `abstract void write(char[] cbuf, int off, int len)` | 将字符数组 `cbuf` 从 `off` 开始的 `len` 个字符写入流 |
| `abstract void flush()` | 刷新流，将缓冲区中的数据强制输出到目标 |
| `abstract void close()` | 关闭流，**在关闭前会自动调用 `flush()`** |

这三个方法是 `Writer` 体系的基石，任何自定义的 `Writer` 子类都必须实现它们。

#### `write` 系列的便捷重载

`Writer` 已经基于 `write(char[], int, int)` 提供了多个便捷重载，子类通常无需重写：

| 方法 | 行为 |
|---|---|
| `void write(int c)` | 写入单个字符（低 16 位有效） |
| `void write(char[] cbuf)` | 等价于 `write(cbuf, 0, cbuf.length)` |
| `void write(String str)` | 将字符串写入流 |
| `void write(String str, int off, int len)` | 写入字符串的一部分 |

#### `append` 系列方法（来自 `Appendable`）

`append` 方法的行为与对应的 `write` 方法一致，但**返回 `Writer` 自身**，从而支持链式调用：

| 方法 | 行为 |
|---|---|
| `Writer append(char c)` | 等价于 `write(c)`，返回 `this` |
| `Writer append(CharSequence csq)` | 追加字符序列（如 `String`、`StringBuilder`） |
| `Writer append(CharSequence csq, int start, int end)` | 追加字符序列的子序列 |

例如，`out.append("A").append("B").append("C")` 可以连续追加字符。

#### `flush()` 与 `close()`

- **`flush()`**：如果 `Writer` 内部使用了缓冲区（如 `BufferedWriter`），数据可能暂存在内存中尚未写出。`flush()` 会强制将缓冲区内容推送到目标。
- **`close()`**：关闭流并释放资源。**规范要求 `close()` 在关闭前自动执行 `flush()`**，因此关闭后的 `Writer` 不应再被使用。

#### `Writer.nullWriter()`（Java 11+）

返回一个**丢弃所有字符**的 `Writer`，写入操作静默成功但不产生任何效果。常用于需要一个“空输出”占位符的场景。

### 💻 代码示例：通过子类使用 `Writer`

由于 `Writer` 是抽象类，以下示例均通过具体子类来演示其方法。

#### 🗂️ 示例 1：`FileWriter` — 将字符写入文件

`FileWriter` 是最常用的文件字符输出流。推荐使用 `try-with-resources` 自动关闭流，并显式指定编码（避免平台默认编码带来的乱码问题）。

```java
import java.io.FileWriter;
import java.io.Writer;
import java.nio.charset.StandardCharsets;

public class FileWriterDemo {
    public static void main(String[] args) {
        try (Writer writer = new FileWriter("output.txt", StandardCharsets.UTF_8)) {
            writer.write('H');                    // 单个字符
            writer.write("Hello".toCharArray());  // 字符数组
            writer.write(" World");               // 字符串
            writer.append("!").append(" Java");   // 链式 append
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

`FileWriter` 在构造时接收文件名（或 `File` 对象）以及可选的编码参数。如果不指定编码，则使用系统默认编码。

#### 🧠 示例 2：`StringWriter` — 在内存中构建字符串

`StringWriter` 将写入的字符收集到内部的 `StringBuffer` 中，最终可以通过 `toString()` 取出完整结果。它**不会抛出 `IOException`**（因为写入目标是内存），且**不需要关闭**（`close()` 无实际效果）。

```java
import java.io.StringWriter;

public class StringWriterDemo {
    public static void main(String[] args) throws Exception {
        StringWriter writer = new StringWriter();
        writer.write("Hello, ");
        writer.append("Writer");
        writer.write("!");

        String result = writer.toString();
        System.out.println(result); // 输出: Hello, Writer!
    }
}
```

#### 🧱 示例 3：`CharArrayWriter` — 生成字符数组

与 `StringWriter` 类似，`CharArrayWriter` 在内存中维护一个可增长的 `char` 缓冲区，最终通过 `toCharArray()` 获取数组。

```java
import java.io.CharArrayWriter;

public class CharArrayWriterDemo {
    public static void main(String[] args) throws Exception {
        CharArrayWriter writer = new CharArrayWriter();
        writer.write('A');
        writer.write('B');
        writer.write('C');

        char[] chars = writer.toCharArray(); // {'A', 'B', 'C'}
        System.out.println(new String(chars)); // 输出: ABC
    }
}
```

#### ⚡ 示例 4：`BufferedWriter` — 提升写入性能

`BufferedWriter` 在内部维护一个字符缓冲区，减少对底层流的物理写入次数。它还额外提供了 **`newLine()`** 方法，用于写入平台相关的换行符。

```java
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.Writer;
import java.nio.charset.StandardCharsets;

public class BufferedWriterDemo {
    public static void main(String[] args) {
        try (Writer writer = new BufferedWriter(
                new FileWriter("buffered.txt", StandardCharsets.UTF_8))) {
            writer.write("第一行");
            ((BufferedWriter) writer).newLine(); // 需要向下转型才能调用 newLine()
            writer.write("第二行");
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

`BufferedWriter` 通常作为“装饰器”包裹在其他 `Writer`（如 `FileWriter`）外层使用。

#### 🔄 示例 5：`OutputStreamWriter` — 桥接字节流与字符流

`OutputStreamWriter` 是**字符流到字节流的桥梁**。它接收一个 `OutputStream`，并按照指定的字符编码将写入的字符转换为字节输出。

```java
import java.io.FileOutputStream;
import java.io.OutputStreamWriter;
import java.io.Writer;

public class OutputStreamWriterDemo {
    public static void main(String[] args) {
        try (Writer writer = new OutputStreamWriter(
                new FileOutputStream("bridge.txt"), "UTF-8")) {
            writer.write("通过 OutputStreamWriter 写入");
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

事实上，`FileWriter` 的内部实现正是基于 `OutputStreamWriter` 的，显式使用 `OutputStreamWriter` 可以更清晰地控制编码行为。

### ⚠️ 使用要点

1. **`Writer` 本身不可实例化**：必须通过子类（`FileWriter`、`BufferedWriter`、`StringWriter` 等）创建对象。
2. **编码很重要**：涉及文件或字节流时，应显式指定字符编码（如 `StandardCharsets.UTF_8`），避免依赖平台默认编码。
3. **`close()` 前会 `flush()`**：规范要求 `close()` 先刷新再关闭，但如果不关闭流又希望数据立即输出，需要主动调用 `flush()`。
4. **`append` 与 `write` 的关系**：`append` 方法本质上是调用 `write` 并返回 `this`，区别在于**链式调用风格**和 `Appendable` 接口的约定。
5. **`lock` 字段与线程安全**：`Writer` 的同步机制依赖于 `lock` 对象。子类在扩展时应遵循这一约定，对 `lock` 加锁而非对 `this` 加锁。

`Writer` 是整个 Java 字符输出体系的抽象契约：它定义了“字符如何被写出”的核心方法（`write`、`flush`、`close`），而将**具体写入哪里、如何编码**的决策留给子类。理解 `Writer` 的抽象方法、便捷重载以及 `protected` 构造器的同步语义，就能在使用 `FileWriter`、`BufferedWriter` 等具体类时，清楚地知道每一个调用背后发生了什么。
