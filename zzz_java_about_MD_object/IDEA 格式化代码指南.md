# IntelliJ IDEA 格式化代码指南

在 IntelliJ IDEA 中格式化代码非常方便，最核心的操作是记住一个快捷键。除此之外，IDEA 还提供了菜单操作、保存时自动格式化以及针对不同范围的格式化方式。

---

## 一、核心操作：快捷键格式化

这是最常用、最高效的方式，它会根据当前项目设定的**代码样式（Code Style）**重新排列代码。

| 操作系统 | 格式化快捷键 |
| :--- | :--- |
| **Windows / Linux** | `Ctrl + Alt + L` |
| **macOS** | `Option + Command + L`（`⌥⌘L`） |

### 使用技巧

- **格式化整个文件**：不选中任何代码，直接按下快捷键。
- **格式化选中部分**：先用鼠标或键盘选中要格式化的代码片段，再按下快捷键。
- **调出格式化选项**：按 `Ctrl + Alt + Shift + L`（Windows/Linux）或 `Option + Shift + Command + L`（macOS）可打开对话框，选择是否优化导入、清理代码等。

---

## 二、备选方案：通过菜单操作

如果不习惯记快捷键，或想了解相关功能，可以通过主菜单操作。

- **路径**：`Code` → `Reformat Code`
- 在**项目视图（Project tool window）**中，右键点击一个或多个文件/目录，选择 `Reformat Code` 可批量格式化。

---

## 三、进阶设置：保存时自动格式化

为了保持代码整洁，可以设置 IDEA 在每次保存文件时自动执行格式化，无需手动触发。

### 设置路径

1. 打开设置：
    - Windows/Linux：`File` → `Settings`
    - macOS：`IntelliJ IDEA` → `Preferences`
2. 左侧菜单找到 `Tools` → `Actions on Save`。
3. 在右侧界面勾选 **`Reformat code`** 选项。
    - 还可进一步设置该操作生效的文件类型或范围（例如仅格式化变更部分）。

---

## 四、补充说明：代码样式配置

IDEA 的格式化并非千篇一律，它严格遵循一套可配置的规则。

- 配置路径：`Settings` → `Editor` → `Code Style` → `Java`
- 可自定义缩进、空格、换行、大括号位置等详细规则。
- **团队开发建议**：统一导入一份代码样式配置文件（XML），保证代码风格一致。

---

## 五、速查表

| 操作 | Windows / Linux | macOS |
| :--- | :--- | :--- |
| 格式化代码 | `Ctrl + Alt + L` | `⌥⌘L` |
| 打开格式化选项 | `Ctrl + Alt + Shift + L` | `⌥⇧⌘L` |
| 保存时自动格式化 | `Tools → Actions on Save → Reformat code` | 同左 |

---

> **提示**：格式化只调整代码的排版（空格、缩进、换行），不会改变代码逻辑。建议在提交代码前执行一次格式化，保持代码库整洁统一。
