# 团队统一代码风格：导入 Code Style XML 配置

统一团队代码风格，核心是使用 IntelliJ IDEA 的 **Code Style XML** 配置文件。主要有两种落地方式，推荐优先使用**项目级共享**
，最省心。

---

## 方式一：项目级共享（最推荐）⭐

这种方式将配置文件直接纳入版本控制（Git），团队成员拉取代码后 IDEA 会自动应用，**零操作成本**。

### 操作步骤

1. **在 IDEA 中配置好代码风格**
   进入 `Settings` → `Editor` → `Code Style` → `Java`，调整好缩进、空格、换行等规则。

2. **将项目方案复制到项目级别**
    - 在 `Code Style` 界面，确认顶部 `Scheme` 选择的是 **`Project`**（项目方案）。
    - 如果当前是 `Default`（IDE 级别），点击 `Scheme` 旁的齿轮图标，选择 **`Copy to Project...`**，将其复制到项目级别。

3. **配置会被自动保存**
   设置完成后，IDEA 会自动在项目根目录的 **`.idea/codeStyles/`** 文件夹下生成配置文件（如 `Project.xml`）。

4. **提交到版本库**
   将 **`.idea/codeStyles/`** 目录（以及 `.idea` 下相关的共享配置如 `inspectionProfiles/`）提交到 Git 仓库。

> **注意**：`.idea` 目录下并非所有文件都该提交。应将 `workspace.xml`、`shelf/` 等个人工作区文件加入 `.gitignore`，避免污染仓库。

### 团队成员视角

其他人克隆项目后，IDEA 会**自动读取** `.idea/codeStyles/` 下的配置并生效，无需任何手动导入操作。

---

## 方式二：手动导出 / 导入 XML（灵活，适合跨项目）

如果不想依赖项目目录，或需要将风格复用到其他项目，可以手动分发 XML 文件。

### 第 1 步：导出 XML（由负责人操作）

1. 进入 `Settings` → `Editor` → `Code Style`。
2. 在 `Scheme` 下拉框旁点击**齿轮图标**。
3. 选择 **`Export`** → **`IntelliJ IDEA code style XML`**。
4. 将导出的 XML 文件（可命名为 `code-style.xml`）保存，并分发给团队，或放入仓库的公共目录（如项目根目录）。

### 第 2 步：导入 XML（团队成员操作）

1. 进入 `Settings` → `Editor` → `Code Style`。
2. 点击 `Scheme` 下拉框旁的**齿轮图标**。
3. 选择 **`Import Scheme`** → **`IntelliJ IDEA code style XML`**。
4. 在弹出的文件选择框中，找到并选中团队提供的 XML 文件。
5. 导入后，在 `Scheme` 下拉列表中选中刚刚导入的方案（通常以文件名或方案名显示）即可应用。

> **提示**：导入时若提示版本不兼容，通常是因为 XML 文件来自不同大版本的 IDEA。建议团队尽量统一 IDEA
> 版本，或优先使用下方的 `EditorConfig` 方案。

---

## 补充最佳实践

- **配合 `.editorconfig`（更通用）**：IDEA 原生支持 `.editorconfig` 文件。可以在项目根目录创建此文件，定义基本的缩进、字符集等规则，这能被更多编辑器（VS
  Code 等）识别，是跨 IDE 团队的好选择。
- **统一保存时自动格式化**：团队达成一致后，可以开启 `Settings` → `Tools` → `Actions on Save` → 勾选 **`Reformat code`**
  ，让每次保存都自动统一格式。
- **进阶规范**：如果需要更严格的强制校验，可以引入 **Checkstyle** 或 **Spotless** 等工具，在 CI 或提交前自动检查代码风格。

---

## 总结

| 方式                                | 适用场景       | 团队成本     |
|:----------------------------------|:-----------|:---------|
| **项目级共享（`.idea/codeStyles/` 入库）** | 团队首选       | 零操作，自动生效 |
| **手动 XML 导入**                     | 灵活分发、跨项目复用 | 每人手动导入一次 |
| **`.editorconfig`**               | 跨 IDE 团队补充 | 自动生效     |

> **项目级共享是团队首选，手动 XML 导入适合灵活分发，`.editorconfig` 则是跨编辑器的良好补充。**
