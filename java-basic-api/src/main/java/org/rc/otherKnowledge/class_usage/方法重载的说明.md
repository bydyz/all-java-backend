# 方法重载（Overloading）详解

## 一、什么是方法重载？

**方法重载**是指在同一个类中，定义多个**方法名相同**、但**参数列表不同**的方法。

调用时，编译器会根据传入参数的**个数、类型、顺序**自动选择匹配的方法。因此方法重载属于**编译时多态**，也叫**静态多态**。

核心一句话：

> **同名不同参，返回类型不算数。**

---

## 二、方法重载的规则

满足以下条件即可构成重载：

1. 方法名必须相同；
2. 在同一个类中，或父子类中也可形成重载关系；
3. 参数列表必须不同，至少满足一项：

- 参数个数不同；
- 参数类型不同；
- 参数顺序不同；

4. **仅返回值类型不同，不构成重载**；
5. 仅访问修饰符、异常声明、方法体不同，也不构成重载。

---

## 三、基本示例

### 示例 1：参数个数不同

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {
        Calculator c = new Calculator();

        System.out.println(c.add(1, 2));       // 调用 add(int, int)
        System.out.println(c.add(1, 2, 3));    // 调用 add(int, int, int)
    }
}
```

输出：

```text
3
6
```

说明：

- `add(1, 2)` 匹配两个参数的方法；
- `add(1, 2, 3)` 匹配三个参数的方法。

---

### 示例 2：参数类型不同

```java
public class Printer {

    public void print(int value) {
        System.out.println("打印整数: " + value);
    }

    public void print(String value) {
        System.out.println("打印字符串: " + value);
    }

    public void print(double value) {
        System.out.println("打印小数: " + value);
    }

    public static void main(String[] args) {
        Printer p = new Printer();

        p.print(100);        // 调用 print(int)
        p.print("Hello");    // 调用 print(String)
        p.print(3.14);       // 调用 print(double)
    }
}
```

输出：

```text
打印整数: 100
打印字符串: Hello
打印小数: 3.14
```

---

### 示例 3：参数顺序不同

```java
public class Demo {

    public void show(int a, String b) {
        System.out.println("int, String: " + a + ", " + b);
    }

    public void show(String a, int b) {
        System.out.println("String, int: " + a + ", " + b);
    }

    public static void main(String[] args) {
        Demo d = new Demo();

        d.show(1, "A");   // 调用 show(int, String)
        d.show("B", 2);   // 调用 show(String, int)
    }
}
```

输出：

```text
int, String: 1, A
String, int: B, 2
```

注意：参数顺序不同可以构成重载，但实际开发中不建议设计过于相似的重载，容易降低可读性。

## 四、构造方法也可以重载

构造方法也可以重载，常见于创建对象时支持不同初始化方式。

```java
public class Student {
    private String name;
    private int age;

    public Student() {
        this.name = "未知";
        this.age = 0;
    }

    public Student(String name) {
        this.name = name;
        this.age = 0;
    }

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void show() {
        System.out.println(name + ", " + age);
    }

    public static void main(String[] args) {
        new Student().show();              // 未知, 0
        new Student("张三").show();         // 张三, 0
        new Student("李四", 20).show();     // 李四, 20
    }
}
```

## 五、常见错误：不能只靠返回值类型重载

下面代码**不能编译**：

```java
public class ErrorDemo {

    public int getValue() {
        return 1;
    }

    // 编译错误：方法签名冲突
    public String getValue() {
        return "hello";
    }
}
```

原因：

调用 `demo.getValue()` 时，编译器无法仅根据方法名和参数判断调用哪个方法。返回值类型不参与重载判断。

方法签名主要包括：

```text
方法名 + 参数列表
```

不包含：

```text
返回值类型
访问修饰符
异常声明
```

## 六、重载方法的选择规则

编译器选择重载方法时，大致遵循：

1. **精确匹配优先**：参数类型完全一致的方法优先；
2. **自动类型转换**：如 `int` 可转 `long`、`double`；
3. **装箱/拆箱**：如 `int` 与 `Integer`；
4. **可变参数**：最后考虑。

示例：

```java
public class OverloadDemo {

    public void test(int a) {
        System.out.println("int");
    }

    public void test(long a) {
        System.out.println("long");
    }

    public void test(double a) {
        System.out.println("double");
    }

    public static void main(String[] args) {
        OverloadDemo d = new OverloadDemo();

        d.test(10);      // int
        d.test(10L);     // long
        d.test(10.0);    // double
        d.test('A');     // int，因为 char 可提升为 int
    }
}
```

输出：

```text
int
long
double
int
```

说明：`char` 类型会优先匹配 `int`，因为存在基本类型提升。

## 七、可变参数重载示例

```java
public class VarargsDemo {

    public void sum(int a, int b) {
        System.out.println("两个参数: " + (a + b));
    }

    public void sum(int... nums) {
        int total = 0;
        for (int n : nums) {
            total += n;
        }
        System.out.println("可变参数: " + total);
    }

    public static void main(String[] args) {
        VarargsDemo d = new VarargsDemo();

        d.sum(1, 2);       // 优先调用 sum(int, int)
        d.sum(1, 2, 3);    // 调用 sum(int...)
    }
}
```

输出：

```text
两个参数: 3
可变参数: 6
```

说明：固定参数方法通常优先于可变参数方法。

## 八、方法重载与方法重写的区别

| 对比项  | 方法重载 Overloading | 方法重写 Overriding |
|------|------------------|-----------------|
| 发生位置 | 同一个类中，或父子类中      | 父子类之间           |
| 方法名  | 相同               | 相同              |
| 参数列表 | 必须不同             | 必须相同            |
| 返回值  | 无要求              | 一般相同或协变         |
| 多态类型 | 编译时多态            | 运行时多态           |
| 绑定时间 | 编译期              | 运行期             |
| 访问权限 | 无特殊要求            | 子类不能比父类更严格      |
| 异常   | 无特殊要求            | 子类不能抛出更宽泛的受检异常  |

示例：

```java
class Parent {
    public void show(int a) {
        System.out.println("Parent show(int)");
    }

    public void show(String s) {
        System.out.println("Parent show(String)");
    }
}

class Child extends Parent {
    @Override
    public void show(int a) {
        System.out.println("Child show(int)");
    }
}
```

- `Parent` 中两个 `show` 是**重载**；
- `Child.show(int)` 重写 `Parent.show(int)`，是**重写**。

---

## 九、使用建议

1. 重载方法应表达**相同或相近语义**，例如 `print(int)`、`print(String)`；
2. 避免设计仅参数顺序不同、含义不清的重载；
3. 注意基本类型转换、装箱拆箱可能带来的歧义；
4. 不要试图只通过返回值类型区分方法；
5. 构造方法重载常用于提供多种初始化方式。

---

## 十、总结

方法重载的关键点：

```text
同一个类中，方法名相同，参数列表不同。
参数列表不同包括：个数不同、类型不同、顺序不同。
返回值类型不同，不能构成重载。
重载在编译期确定调用哪个方法，是编译时多态。
```

最简记法：

> **同名不同参，返回不参与；编译期决定，调用看参数。**
