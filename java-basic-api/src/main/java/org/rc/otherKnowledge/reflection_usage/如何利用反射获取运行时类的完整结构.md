# Java 反射获取运行时类完整结构详解

"获取运行时类的完整结构"是反射的经典用途，本质是**通过 `Class` 对象把编译期不可见的类定义（修饰符、父类、接口、泛型、构造器、方法、字段、注解等）在运行时全部导出**。

下面按"入口 → 各部分 → 综合示例 → 坑点"的顺序说明，所有 API 都基于 `java.lang.reflect`。

---

## 一、反射入口：拿到 `Class` 对象

一切反射操作都从 `Class<?>` 开始，获取方式有四种：

```java
// 1. Class.forName（最常用，可配合类加载器）
Class<?> c1 = Class.forName("java.util.ArrayList");

// 2. 类名.class（编译期已知类型，不触发初始化）
Class<?> c2 = ArrayList.class;

// 3. 对象.getClass()
Class<?> c3 = new ArrayList<String>().getClass();

// 4. 类加载器
Class<?> c4 = ClassLoader.getSystemClassLoader().loadClass("java.util.ArrayList");

System.out.println(c1 == c2 && c2 == c3); // true，同一个 Class 对象
```

> 一个类在 JVM 中只有一个 `Class` 对象，上述四种方式得到的都是同一份。

## 二、获取"类本身"的结构

### 1. 名称、包、修饰符、类型种类

```java
Class<?> c = java.util.ArrayList.class;

c.getName();            // java.util.ArrayList      全限定名
c.getSimpleName();      // ArrayList                简单名
c.getCanonicalName();   // java.util.ArrayList      规范名（内部类是 a.b.Outer.Inner）
c.getPackage().getName();// java.util

int mod = c.getModifiers();          // 返回 int 位掩码
Modifier.toString(mod);              // public

c.isInterface();  // false
c.isEnum();       // false
c.isAnnotation(); // false
c.isArray();      // false
c.isPrimitive();  // false
c.isRecord();     // Java 16+，判断 record
```

### 2. 父类与接口（含泛型）

```java
// 普通父类
Class<?> superCls = c.getSuperclass();          // java.util.AbstractList
// 带泛型的父类
Type superType = c.getGenericSuperclass();      // java.util.AbstractList<E>

// 直接实现的接口（不含父接口）
Class<?>[] interfaces = c.getInterfaces();      // List, RandomAccess, Cloneable, Serializable
Type[] genericInterfaces = c.getGenericInterfaces(); // 保留泛型信息 List<E>

// 类的泛型形参
TypeVariable<?>[] tv = c.getTypeParameters();   // [E]
```

**易错点**：`getSuperclass()` 只返回**直接父类**；`getInterfaces()` 也只返回**直接实现**的接口，不会递归。要拿到全部继承体系需自己递归。

### 3. 类上的注解

```java
Annotation[] anns = c.getAnnotations();          // 含 @Inherited 的父类注解
Annotation[] declared = c.getDeclaredAnnotations(); // 只看本类声明的
```

要读取注解值，用 `Annotation` 的代理方法即可，例如：

```java
if (c.isAnnotationPresent(Deprecated.class)) { ... }
```

### 4. 内部类 / 外部类

```java
Class<?>[] inner = c.getDeclaredClasses();     // 本类中声明的所有内部类
Class<?> outer = c.getDeclaringClass();        // 若本类是内部类，返回外部类
Class<?> enclosing = c.getEnclosingClass();    // 最近的词法外围类（含匿名类）
```

### 5. 其他现代特性（JDK 11+/16+/17+）

```java
c.getRecordComponents();          // Java 16+，record 的组件
c.getPermittedSubclasses();       // Java 17+，sealed 类的允许子类
c.getNestHost();                  // Java 11+，嵌套宿主类（用于 nestmate 访问）
```

## 三、构造器（Constructor）

```java
Constructor<?>[] allPublic   = c.getConstructors();          // 所有 public 构造器
Constructor<?>[] allDeclared = c.getDeclaredConstructors();  // 本类声明的所有构造器（含 private）

// 精确获取
Constructor<?> ctor = c.getDeclaredConstructor(String.class); // 参数类型
```

常用方法：

```java
ctor.getName();              // 全限定名（注意：不是简单名）
ctor.getModifiers();
ctor.getParameterTypes();    // Class<?>[]
ctor.getParameterCount();
ctor.getParameters();        // Parameter[]，Java 8+，可 getName()（需 -parameters 编译）
ctor.getExceptionTypes();    // throws 列表
ctor.getAnnotations();
ctor.isVarArgs();            // 是否可变参数
ctor.isSynthetic();          // 是否编译器生成的合成构造器
```

**创建实例**：

```java
ctor.setAccessible(true);              // 突破 private（Java 9+ 对 JDK 内部模块受限）
Object obj = ctor.newInstance("hello");
```

---

## 四、方法（Method）

```java
Method[] publicMethods   = c.getMethods();          // public，含继承来的
Method[] declaredMethods = c.getDeclaredMethods();  // 本类声明的所有方法（含 private，不含继承）

Method m = c.getDeclaredMethod("add", Object.class); // 精确查找
```

常用方法：

```java
m.getName();
m.getModifiers();
m.getReturnType();              // Class<?>
m.getGenericReturnType();       // Type，保留泛型
m.getParameterTypes();
m.getParameterCount();
m.getParameters();              // Parameter[]
m.getExceptionTypes();
m.getAnnotations();
m.isVarArgs();
m.isBridge();                   // 泛型擦除产生的桥接方法
m.isSynthetic();                // 编译器生成的合成方法（如 lambda 的 lambda$xxx$0、访问私有成员的 access$000）
m.isDefault();                  // 接口默认方法（Java 8+）
```

**调用方法**：

```java
m.setAccessible(true);
Object result = m.invoke(obj, arg1, arg2);
// 静态方法：obj 传 null
```

> `getDeclaredMethods()` 返回顺序**不保证**是源码顺序（JVM 规范未要求），不要依赖顺序。

---

## 五、字段（Field）

```java
Field[] publicFields   = c.getFields();          // public，含继承（只能拿到父类的 public 字段）
Field[] declaredFields = c.getDeclaredFields();  // 本类声明的全部字段（含 private）

Field f = c.getDeclaredField("size");            // 精确查找
```

常用方法：

```java
f.getName();
f.getType();               // Class<?>    基本类型/数组都可以
f.getGenericType();        // Type，保留泛型（如 List<String>）
f.getModifiers();
f.getAnnotations();

// 读写
f.setAccessible(true);
Object v = f.get(obj);     // 静态字段：obj 传 null
f.set(obj, newVal);
```

**注意**：`getFields()` **不会**返回父类的非 public 字段；`getDeclaredFields()` **不会**返回继承字段。要遍历整个继承链得自己 while 循环。

## 六、综合示例：打印一个类的完整结构

下面这个类会输出类似 `javap -p` 的完整结构。

```java
import java.lang.annotation.*;
import java.lang.reflect.*;
import java.util.Arrays;
import java.util.stream.Collectors;

public class ClassStructurePrinter {

    public static void print(Class<?> clazz) {
        StringBuilder sb = new StringBuilder();

        // ---- 1. 包 ----
        Package pkg = clazz.getPackage();
        if (pkg != null) sb.append("package ").append(pkg.getName()).append(";\n\n");

        // ---- 2. 修饰符 + 类型关键字 ----
        int mod = clazz.getModifiers();
        if (mod != 0) sb.append(Modifier.toString(mod)).append(' ');
        if (clazz.isAnnotation())   sb.append("@interface ");
        else if (clazz.isEnum())    sb.append("enum ");
        else if (clazz.isInterface()) sb.append("interface ");
        else if (clazz.isRecord())  sb.append("record ");      // Java 16+
        else                        sb.append("class ");

        sb.append(clazz.getSimpleName());

        // ---- 3. 泛型形参 ----
        TypeVariable<?>[] tvs = clazz.getTypeParameters();
        if (tvs.length > 0) {
            sb.append('<').append(Arrays.stream(tvs)
                    .map(TypeVariable::getName).collect(Collectors.joining(", "))).append('>');
        }

        // ---- 4. 父类 ----
        Type sup = clazz.getGenericSuperclass();
        if (sup != null && sup != Object.class) {
            sb.append(" extends ").append(sup.getTypeName());
        }

        // ---- 5. 接口 ----
        Type[] ifs = clazz.getGenericInterfaces();
        if (ifs.length > 0) {
            sb.append(clazz.isInterface() ? " extends " : " implements ");
            sb.append(Arrays.stream(ifs).map(Type::getTypeName)
                    .collect(Collectors.joining(", ")));
        }

        sb.append(" {\n");

        // ---- 6. 字段 ----
        for (Field f : clazz.getDeclaredFields()) {
            sb.append("    ");
            for (Annotation a : f.getAnnotations()) sb.append(a).append(' ');
            sb.append(Modifier.toString(f.getModifiers())).append(' ');
            sb.append(f.getGenericType().getTypeName()).append(' ').append(f.getName()).append(";\n");
        }

        // ---- 7. 构造器 ----
        for (Constructor<?> ctor : clazz.getDeclaredConstructors()) {
            sb.append("    ");
            sb.append(Modifier.toString(ctor.getModifiers())).append(' ');
            sb.append(clazz.getSimpleName()).append('(');
            sb.append(params(ctor.getParameters())).append(')');
            throwsClause(sb, ctor.getExceptionTypes());
            sb.append(" { }\n");
        }

        // ---- 8. 方法（过滤桥接/合成） ----
        for (Method m : clazz.getDeclaredMethods()) {
            if (m.isBridge() || m.isSynthetic()) continue;
            sb.append("    ");
            for (Annotation a : m.getAnnotations()) sb.append(a).append(' ');
            sb.append(Modifier.toString(m.getModifiers())).append(' ');
            sb.append(m.getGenericReturnType().getTypeName()).append(' ');
            sb.append(m.getName()).append('(');
            sb.append(params(m.getParameters())).append(')');
            throwsClause(sb, m.getExceptionTypes());
            sb.append(" { }\n");
        }

        sb.append('}');
        System.out.println(sb);
    }

    private static String params(Parameter[] ps) {
        return Arrays.stream(ps)
                .map(p -> {
                    String type = p.getParameterizedType().getTypeName();
                    // 可变参数显示为 T...
                    if (p.isVarArgs()) type = type.replace("[]", "...");
                    return type + " " + p.getName();
                })
                .collect(Collectors.joining(", "));
    }

    private static void throwsClause(StringBuilder sb, Class<?>[] exs) {
        if (exs.length > 0) {
            sb.append(" throws ").append(Arrays.stream(exs)
                    .map(Class::getSimpleName).collect(Collectors.joining(", ")));
        }
    }
}
```

### 用来验证的示例类

```java
import java.io.Serializable;
import java.util.*;

@Deprecated
public class Demo<T extends Comparable<T>> extends AbstractList<T>
        implements Serializable, Cloneable {

    private static final long serialVersionUID = 1L;
    private List<T> data = new ArrayList<>();
    protected int capacity;

    public Demo() {}
    private Demo(int capacity) { this.capacity = capacity; }

    @Override public T get(int index) { return data.get(index); }
    @Override public int size() { return data.size(); }

    public <R> R convert(T value, R fallback) throws IllegalStateException { return fallback; }

    public static void main(String[] args) {
        ClassStructurePrinter.print(Demo.class);
    }
}
```

## 七、常见坑点与注意事项

| 易错点 | 说明 |
|---|---|
| `getMethods()` vs `getDeclaredMethods()` | 前者：public + **继承**；后者：本类**所有**访问级别，**不含继承** |
| `getFields()` 不返回父类 private 字段 | 要拿完整继承链字段，需 `while (cls != null) { cls.getDeclaredFields(); cls = cls.getSuperclass(); }` |
| `Constructor.getName()` 返回全限定名 | 想显示简单名用 `clazz.getSimpleName()` |
| 参数名默认是 `arg0/arg1` | 需要编译时加 `-parameters`（Maven: `<maven.compiler.parameters>true</maven.compiler.parameters>`） |
| 桥接方法与合成方法 | 泛型擦除、lambda、内部类访问外部私有成员会生成 `isBridge()` / `isSynthetic()` 方法，遍历时一般需过滤 |
| 私有成员访问 | `setAccessible(true)`；Java 9+ 对 JDK 模块内类会抛 `InaccessibleObjectException`，需 `--add-opens java.base/java.lang=ALL-UNNAMED` |
| 方法顺序不保证 | `getDeclaredMethods()` 返回顺序 JVM 不保证，切勿依赖 |
| `getGenericXxx()` 与 `getXxx()` | 前者返回 `Type`（保留泛型），后者返回 `Class`（已擦除） |
| `getInterfaces()` 只返回直接接口 | 要获取全部接口需递归遍历父类与父接口 |
| 数组类的特殊性 | `String[].class.getComponentType()` 返回 `String.class`；`getName()` 返回 `[Ljava.lang.String;` |

---

## 八、一句话总结

**反射获取完整结构 = `Class` 拿到后，用 `getDeclaredXxx()` 系列（本类全量）+ `getGenericXxx()`（保留泛型）+ `getAnnotations()/getParameters()`（附加元数据）三类 API 组合，再配合 `Modifier.toString()` 还原修饰符，就能在运行时还原出接近 `javap -p` 的类定义。** 使用时重点关注"是否含继承"、"是否含非 public"、"是否过滤 bridge/synthetic"三点即可。
