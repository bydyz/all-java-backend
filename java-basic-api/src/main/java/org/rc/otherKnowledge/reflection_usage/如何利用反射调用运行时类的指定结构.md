# Java 反射调用运行时类的指定结构详解

反射的核心是 `java.lang.reflect` 包下的四个类：`Class`、`Constructor`、`Field`、`Method`（以及 `AccessibleObject` 作为它们的父类）。整体流程可以概括为：

> **拿到 `Class` 对象 → 定位到具体成员（构造器 / 字段 / 方法） → `setAccessible` 破除访问检查 → 执行（newInstance / get / set / invoke）**

下面先给出示例目标类，后面所有代码都围绕它展开。

```java
// Person.java
import java.lang.annotation.*;

@Retention(RetentionPolicy.RUNTIME)
@Target({ElementType.TYPE, ElementType.FIELD, ElementType.METHOD})
@interface Info {
    String value() default "";
}

@Info("示例类")
public class Person {
    private String name;
    private int age;
    public  String hobby = "coding";
    private static String nation = "China";

    public Person() { this("无名", 0); }

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    private Person(String name) { this.name = name; }   // 私有构造器

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    @Info("内部密钥方法")
    private String secret(String key) { return "secret:" + key; }

    public static String getNation() { return nation; }
    public static void setNation(String n) { nation = n; }

    public String join(String... parts) { return String.join("-", parts); }  // 可变参数

    @Override
    public String toString() {
        return "Person{name='" + name + "', age=" + age +
               ", hobby='" + hobby + "', nation='" + nation + "'}";
    }
}
```

---

## 一、前置：获取 `Class` 对象的四种方式

```java
Class<?> c1 = Person.class;                       // 1. 类字面量，编译期确定，最快
Class<?> c2 = new Person().getClass();            // 2. 通过实例
Class<?> c3 = Class.forName("Person");            // 3. 全限定类名，会触发类初始化
Class<?> c4 = ClassLoader.getSystemClassLoader()
                         .loadClass("Person");    // 4. 类加载器，不初始化
```

- `Class.forName(String)` 默认会**初始化**该类（执行静态代码块）；`ClassLoader.loadClass` 只加载、不初始化。
- 三个基本要点：`int.class`、`Integer.class`、`int[].class` 是三个不同的 `Class` 对象。

---

## 二、调用构造器：`Constructor`

| API | 说明 |
|---|---|
| `getConstructor(Class<?>... types)` | 获取 **public** 构造器（含继承，但构造器不会继承） |
| `getDeclaredConstructor(Class<?>... types)` | 获取本类声明的**任意访问级别**构造器 |
| `getConstructors()` / `getDeclaredConstructors()` | 获取全部 |

```java
Class<?> clazz = Person.class;

// 1) public 有参构造器
Constructor<?> ctor = clazz.getDeclaredConstructor(String.class, int.class);
Person p1 = (Person) ctor.newInstance("张三", 28);

// 2) 私有构造器 —— 必须先 setAccessible(true)
Constructor<?> privCtor = clazz.getDeclaredConstructor(String.class);
privCtor.setAccessible(true);
Person p2 = (Person) privCtor.newInstance("李四");

// 3) 无参构造器（推荐写法，替代已废弃的 clazz.newInstance()）
Person p3 = (Person) clazz.getDeclaredConstructor().newInstance();

System.out.println(p1 + "\n" + p2 + "\n" + p3);
```

**要点**

- 参数类型必须**精确匹配**：`int` 用 `int.class`，不能用 `Integer.class`。
- `Constructor.newInstance(...)` 会把被调构造器抛出的异常**包装**成 `InvocationTargetException`；而 `Class.newInstance()`（Java 9 起 `@Deprecated`）会直接抛出原异常、且只能调无参 public 构造器——这正是它被废弃的原因。
- 内部类构造器的第一个参数是外部类实例：`Outer$Inner` 的构造器签名是 `(Outer, ...)`。
- 枚举、匿名类、`String`、包装类等没有可用的公开构造器，无法反射实例化。

---

## 三、访问字段：`Field`

| API | 说明 |
|---|---|
| `getField(String name)` | 获取 public 字段（**包含父类**） |
| `getDeclaredField(String name)` | 获取本类声明的任意字段（**不含父类**） |
| `field.get(obj)` / `field.set(obj, value)` | 读写，基本类型自动装箱/拆箱 |
| `field.getInt/setInt/getObject/setObject...` | 避免装箱开销 |

```java
Class<?> clazz = Person.class;
Object p = clazz.getDeclaredConstructor(String.class, int.class).newInstance("张三", 28);

// 1) 私有实例字段
Field nameField = clazz.getDeclaredField("name");
nameField.setAccessible(true);                 // 破除 private 访问检查
Object old = nameField.get(p);                 // 读："张三"
nameField.set(p, "王五");                      // 写

// 2) 公有字段
Field hobby = clazz.getField("hobby");
hobby.set(p, "reading");

// 3) 基本类型字段 —— 用类型化 API 避免装箱
Field ageField = clazz.getDeclaredField("age");
ageField.setAccessible(true);
ageField.setInt(p, 30);
int age = ageField.getInt(p);

// 4) 静态字段 —— obj 参数传 null
Field nationField = clazz.getDeclaredField("nation");
nationField.setAccessible(true);
nationField.set(null, "PRC");
Object nation = nationField.get(null);

System.out.println(p);
```

**要点与坑**

- `get` 返回的一定是**包装类型**，需要显式强转或走 `getInt/getObject` 等类型化方法。
- 静态字段 `get/set` 的 `obj` 传 `null` 即可（传实例也不会报错，但语义上应为 `null`）。
- **`final` 字段**：实例 `final` 字段的反射修改行为依赖 JIT，不保证生效；Java 12 起对 `static final` 字段 `set` 会直接抛 `IllegalAccessException`（除非用 `Unsafe` / `VarHandle`，不推荐）。
- **继承的私有字段**：`getDeclaredField` 只查本类，父类的私有字段需 `getSuperclass()` 逐层向上查找。
- **Java 9+ 模块封装**：对 JDK 内部类（如 `String.value`）`setAccessible(true)` 会抛 `InaccessibleObjectException`，需启动参数 `--add-opens java.base/java.lang=ALL-UNNAMED`。

## 四、调用方法：`Method`

| API | 说明 |
|---|---|
| `getMethod(name, Class<?>... types)` | public 方法（**含继承**，会返回子类重写后的版本） |
| `getDeclaredMethod(name, Class<?>... types)` | 本类声明的任意方法（不含继承） |
| `method.invoke(Object obj, Object... args)` | 调用；静态方法 `obj` 传 `null` |

```java
Class<?> clazz = Person.class;
Object p = clazz.getDeclaredConstructor(String.class, int.class).newInstance("张三", 28);

// 1) public 方法
Method setName = clazz.getMethod("setName", String.class);
setName.invoke(p, "赵六");

Method getName = clazz.getMethod("getName");          // 无参就不传类型
Object name = getName.invoke(p);                       // 返回值是 Object

// 2) 私有方法
Method secret = clazz.getDeclaredMethod("secret", String.class);
secret.setAccessible(true);
Object result = secret.invoke(p, "abc");               // "secret:abc"

// 3) 静态方法
Method getNation = clazz.getMethod("getNation");
Object nation = getNation.invoke(null);                // obj 传 null
Method setNation = clazz.getMethod("setNation", String.class);
setNation.invoke(null, "China");

// 4) 无返回值的方法：invoke 返回 null
System.out.println(name + " / " + result + " / " + nation);
```

**要点与坑**

- **可变参数方法容易踩坑**：`invoke` 的签名是 `invoke(Object obj, Object... args)`，当你传 `String[]` 时，编译器可能把它当作 `args` 数组本身而不是单个参数：

```java
Method join = clazz.getMethod("join", String[].class);   // 注意：参数类型是 String[].class

Object r1 = join.invoke(p, (Object) new String[]{"a","b","c"});  // ✅ 作为 1 个参数
Object r2 = join.invoke(p, "a", "b", "c");                        // ✅ 自动打包成 3 个参数
Object r3 = join.invoke(p, new Object[]{ new String[]{"a","b"} }); // ✅ 等价写法
// join.invoke(p, new String[]{"a","b"});  // ❌ IllegalArgumentException: wrong number of arguments
```

- **动态分派**：即使拿到的是父类的 `Method`，`invoke` 也会按实际对象类型分派到子类重写版本。
- **返回值**：基本类型自动装箱；`void` 返回 `null`；调用可能被重载为返回 `Object` 的桥接方法（synthetic bridge），用 `method.isBridge()` 可判断。
- **参数匹配**：`getMethod` 的 `Class...` 必须与方法签名精确一致，`Integer.class` 匹配不到 `int` 形参。
- **性能**：`invoke` 本身有装箱、参数数组分配、访问检查等开销。高频调用场景建议缓存 `Method` 对象、`setAccessible(true)` 后复用，或改走 `MethodHandle` / `LambdaMetafactory`（性能接近直接调用）。

## 五、`setAccessible` 与访问控制

```java
// setAccessible 是 AccessibleObject 的方法，Constructor / Field / Method 都继承它
field.setAccessible(true);
method.setAccessible(true);
constructor.setAccessible(true);
```

- 作用：关闭 Java 语言访问检查（private / protected / 包级），**不是**修改修饰符本身（`getModifiers()` 结果不变）。
- 在 Java 9+ 模块化环境下，还要看目标包是否对当前模块 `open`，否则抛 `InaccessibleObjectException`。
- 反射不能突破 `SecurityManager`（已废弃）的限制。

## 六、数组的反射：`java.lang.reflect.Array`

数组没有字段和方法，需要用 `Array` 工具类：

```java
Object arr = Array.newInstance(int.class, 3);       // 相当于 new int[3]
Array.setInt(arr, 0, 10);
Array.set(arr, 1, 20);                              // 自动装箱
int v = Array.getInt(arr, 0);
int len = Array.getLength(arr);
Class<?> compType = arr.getClass().getComponentType();   // int.class

// 二维数组
Object matrix = Array.newInstance(int.class, 2, 3);
```

## 七、读取注解

注解必须 `@Retention(RetentionPolicy.RUNTIME)` 才能被反射读取。

```java
// 类上的注解
Info classInfo = Person.class.getAnnotation(Info.class);
System.out.println(classInfo.value());              // "示例类"

// 方法上的注解
Method secret = Person.class.getDeclaredMethod("secret", String.class);
Info mInfo = secret.getAnnotation(Info.class);
System.out.println(mInfo.value());                  // "内部密钥方法"

// 注意：getAnnotation 会沿继承链查找，getDeclaredAnnotation 只查自身
```

## 八、异常处理

反射 API 的受检异常很多，且有一个关键的**包装异常**：

```java
try {
    Method m = Person.class.getDeclaredMethod("secret", String.class);
    m.setAccessible(true);
    m.invoke(person, "k");
} catch (NoSuchMethodException e) {
    // 方法不存在：名字或参数类型写错
} catch (IllegalAccessException e) {
    // 没有访问权限（忘了 setAccessible 或模块未 open）
} catch (IllegalArgumentException e) {
    // 参数类型/个数不匹配
} catch (InvocationTargetException e) {
    // ★ 被调方法自身抛出的异常被包装在这里
    Throwable real = e.getCause();   // 取真正的业务异常
}
```

> 记住：**`invoke` / `newInstance` 抛出的 `InvocationTargetException` 永远要通过 `getCause()` 取出原始异常**，这是反射代码最容易漏掉的点。

## 九、常见坑与最佳实践速查

| 问题 | 说明 / 对策 |
|---|---|
| `Class.newInstance()` | Java 9 起废弃，用 `getDeclaredConstructor().newInstance()` |
| 参数类型写错 | `int.class` ≠ `Integer.class`；可变参数用 `String[].class` |
| 私有继承成员 | `getDeclaredXxx` 只查本类，需逐层 `getSuperclass()` |
| `getMethod` vs `getDeclaredMethod` | 前者只找 public 且含继承；后者找本类全部访问级别 |
| 静态成员 | `obj` 传 `null` |
| 可变参数 invoke | 传数组时用 `(Object) arr` 或 `new Object[]{arr}` 明确语义 |
| `final` 字段 | 不保证可改，`static final` 在 JDK 12+ 直接拒绝 |
| JDK 内部类 | `--add-opens` 或改用公开 API |
| 性能 | 缓存 `Method/Field/Constructor`，`setAccessible(true)` 一次即可；高频用 `MethodHandle` |

## 十、完整可运行汇总

```java
import java.lang.reflect.*;

public class ReflectionDemo {

    public static void main(String[] args) throws Exception {
        Class<?> clazz = Person.class;

        // ---------- 构造器 ----------
        Constructor<?> ctor = clazz.getDeclaredConstructor(String.class, int.class);
        Object p = ctor.newInstance("张三", 28);

        Constructor<?> privCtor = clazz.getDeclaredConstructor(String.class);
        privCtor.setAccessible(true);
        Object p2 = privCtor.newInstance("李四");

        // ---------- 字段 ----------
        Field nameField = clazz.getDeclaredField("name");
        nameField.setAccessible(true);
        nameField.set(p, "王五");

        Field ageField = clazz.getDeclaredField("age");
        ageField.setAccessible(true);
        ageField.setInt(p, 30);

        Field hobby = clazz.getField("hobby");
        hobby.set(p, "reading");

        Field nation = clazz.getDeclaredField("nation");
        nation.setAccessible(true);
        nation.set(null, "PRC");

        // ---------- 方法 ----------
        Method setName = clazz.getMethod("setName", String.class);
        setName.invoke(p, "赵六");

        Method secret = clazz.getDeclaredMethod("secret", String.class);
        secret.setAccessible(true);
        Object secretResult = secret.invoke(p, "abc");

        Method getNation = clazz.getMethod("getNation");
        Object nationResult = getNation.invoke(null);

        Method join = clazz.getMethod("join", String[].class);
        Object joinResult = join.invoke(p, (Object) new String[]{"a", "b", "c"});

        // ---------- 数组 ----------
        Object arr = Array.newInstance(int.class, 3);
        Array.setInt(arr, 0, 10);

        // ---------- 注解 ----------
        Info info = clazz.getAnnotation(Info.class);

        // ---------- 输出 ----------
        System.out.println(p);                                  // Person{name='赵六', age=30, hobby='reading', nation='PRC'}
        System.out.println(p2);
        System.out.println(secretResult);                       // secret:abc
        System.out.println(nationResult);                       // PRC
        System.out.println(joinResult);                         // a-b-c
        System.out.println(Array.getInt(arr, 0));               // 10
        System.out.println(info.value());                       // 示例类
    }
}
```

以上就是反射调用运行时类"指定结构"的完整路径：**构造器用 `newInstance`、字段用 `get/set`、方法用 `invoke`、数组用 `Array`、注解用 `getAnnotation`，私有成员统一靠 `setAccessible(true)` 解锁**。掌握参数类型匹配规则、`InvocationTargetException.getCause()`、静态成员传 `null` 这三个关键细节，就能避开绝大多数反射陷阱。
