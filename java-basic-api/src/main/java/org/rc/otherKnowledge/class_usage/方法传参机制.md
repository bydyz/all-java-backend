# Java 方法参数传递机制详解

## 一、核心结论

Java 中方法参数传递机制只有一种：**值传递（Pass by Value）**。

- 基本数据类型：传递的是变量值的**副本**。
- 引用数据类型：传递的是对象引用的**副本**，即“引用的值”。
- 方法内部对形参重新赋值，不会改变调用方变量。
- 方法内部通过引用副本修改对象内容，可能会影响调用方看到的对象状态。

一句话总结：

> Java 传递的是值的副本。基本类型传的是具体数值的副本；引用类型传的是对象引用的副本。

---

## 二、基本数据类型参数传递

### 示例代码

```java
public class PrimitivePassDemo {
    public static void change(int x) {
        x = 100;
        System.out.println("方法内 x = " + x);
    }

    public static void main(String[] args) {
        int a = 10;
        change(a);
        System.out.println("方法外 a = " + a);
    }
}
```

### 输出结果

```text
方法内 x = 100
方法外 a = 10
```

### 详解

调用 `change(a)` 时，传递的是 `a` 的值的副本：

```text
a = 10
x = 10  // 副本
```

方法内执行：

```java
x = 100;
```

只是把副本 `x` 改成了 `100`，不会影响原来的变量 `a`。

因此：

```java
a 仍然是 10
```

## 三、引用类型参数传递

### 1. 通过引用副本修改对象内容

```java
class User {
    String name;

    User(String name) {
        this.name = name;
    }
}

public class ReferencePassDemo1 {
    public static void changeName(User user) {
        user.name = "李四";
    }

    public static void main(String[] args) {
        User u = new User("张三");
        changeName(u);
        System.out.println(u.name);
    }
}
```

### 输出结果

```text
李四
```

### 详解

调用 `changeName(u)` 时，传递的是对象引用的副本：

```text
u  ---> User 对象
user ---> 同一个 User 对象
```

`u` 和 `user` 是两个不同的引用变量，但它们指向同一个对象。

方法内执行：

```java
user.name = "李四";
```

通过引用副本找到同一个对象，并修改了对象属性，所以方法外可以看到变化。

---

### 2. 方法内重新赋值引用，不影响调用方变量

```java
class User {
    String name;

    User(String name) {
        this.name = name;
    }
}

public class ReferencePassDemo2 {
    public static void reassign(User user) {
        user = new User("王五");
        System.out.println("方法内 user.name = " + user.name);
    }

    public static void main(String[] args) {
        User u = new User("张三");
        reassign(u);
        System.out.println("方法外 u.name = " + u.name);
    }
}
```

### 输出结果

```text
方法内 user.name = 王五
方法外 u.name = 张三
```

### 详解

调用 `reassign(u)` 时：

```text
u    ---> User("张三")
user ---> User("张三")
```

此时 `u` 和 `user` 是引用的副本，指向同一个对象。

方法内执行：

```java
user = new User("王五");
```

只是让形参 `user` 指向了新对象：

```text
u    ---> User("张三")
user ---> User("王五")
```

因此方法外的 `u` 仍然指向原来的 `User("张三")`。

## 四、数组参数传递

数组也是引用类型。

```java
public class ArrayPassDemo {
    public static void changeArray(int[] arr) {
        arr[0] = 99;
    }

    public static void reassignArray(int[] arr) {
        arr = new int[]{7, 8, 9};
    }

    public static void main(String[] args) {
        int[] numbers = {1, 2, 3};

        changeArray(numbers);
        System.out.println(numbers[0]); // 99

        reassignArray(numbers);
        System.out.println(numbers[0]); // 99
    }
}
```

### 输出结果

```text
99
99
```

### 详解

`changeArray(numbers)` 中，形参 `arr` 是数组引用的副本，但和 `numbers` 指向同一个数组，所以：

```java
arr[0] = 99;
```

会修改原数组内容。

`reassignArray(numbers)` 中：

```java
arr = new int[]{7, 8, 9};
```

只是让形参 `arr` 指向新数组，不会改变 `main` 方法中的 `numbers`。

## 五、String 和包装类参数传递

`String` 和包装类（如 `Integer`）都是不可变对象。

```java
public class ImmutablePassDemo {
    public static void changeString(String s) {
        s = "world";
    }

    public static void changeInteger(Integer num) {
        num = 200;
    }

    public static void main(String[] args) {
        String str = "hello";
        Integer value = 100;

        changeString(str);
        changeInteger(value);

        System.out.println(str);   // hello
        System.out.println(value); // 100
    }
}
```

### 输出结果

```text
hello
100
```

### 详解

方法内：

```java
s = "world";
num = 200;
```

只是让形参指向了新的对象或新的值，不会修改调用方变量。

注意：`Integer` 缓存、自动装箱等机制不影响“Java 参数是值传递”这一结论。

## 六、经典误区：交换两个变量

### 1. 交换基本类型变量失败

```java
public class SwapPrimitiveDemo {
    public static void swap(int a, int b) {
        int temp = a;
        a = b;
        b = temp;
    }

    public static void main(String[] args) {
        int x = 1;
        int y = 2;

        swap(x, y);

        System.out.println("x = " + x);
        System.out.println("y = " + y);
    }
}
```

### 输出结果

```text
x = 1
y = 2
```

### 详解

方法内交换的只是副本 `a` 和 `b`，与 `x`、`y` 无关。

---

### 2. 交换对象引用也失败

```java
class Person {
    String name;

    Person(String name) {
        this.name = name;
    }
}

public class SwapReferenceDemo {
    public static void swap(Person p1, Person p2) {
        Person temp = p1;
        p1 = p2;
        p2 = temp;
    }

    public static void main(String[] args) {
        Person a = new Person("A");
        Person b = new Person("B");

        swap(a, b);

        System.out.println(a.name); // A
        System.out.println(b.name); // B
    }
}
```

### 输出结果

```text
A
B
```

### 详解

方法内交换的是引用副本 `p1`、`p2`，不会改变 `main` 方法中的 `a`、`b` 指向。

## 七、常见对比表

| 参数类型   | 传递内容   | 方法内重新赋值形参  | 方法内修改对象内容          |
|--------|--------|------------|--------------------|
| 基本类型   | 数值副本   | 不影响调用方     | 不适用                |
| 引用类型   | 对象引用副本 | 不影响调用方变量指向 | 可能影响原对象            |
| 数组     | 数组引用副本 | 不影响调用方变量指向 | 可能影响原数组            |
| String | 引用副本   | 不影响调用方变量   | String 不可变，不能修改原内容 |
| 包装类    | 引用副本   | 不影响调用方变量   | 包装类不可变，不能修改原内容     |

---

## 八、总结

1. Java 只有值传递。
2. 基本类型传递的是值的副本。
3. 引用类型传递的是引用的副本。
4. 引用副本和原引用可以指向同一个对象。
5. 通过引用副本修改对象属性，会影响原对象。
6. 对形参重新赋值，不会改变调用方变量。
7. 不能通过 Java 方法参数机制直接交换两个基本类型变量或两个引用变量。
