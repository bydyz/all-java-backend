## 1. 成员变量概述

成员变量（也称为实例变量或字段）是定义在类中、方法外的变量，用于描述对象的属性。

```java
public class Student {
    // ========== 成员变量（实例变量）==========
    // 位置：定义在类中、方法外
    // 作用域：整个类内部
    // 生命周期：随对象创建而创建，随对象被GC回收而销毁

    String name;        // 姓名
    int age;            // 年龄
    double score;       // 成绩
    boolean isGraduated; // 是否毕业

    // ========== 静态变量（类变量）==========
    // 位置：使用 static 修饰的成员变量
    // 作用域：整个类，所有对象共享
    // 生命周期：随类加载而创建，随类卸载而销毁

    static int studentCount = 0;  // 学生计数
    static String schoolName = "清华大学";  // 学校名称

    public Student(String name, int age) {
        this.name = name;  // this 指当前对象的成员变量
        this.age = age;
        studentCount++;    // 静态变量自增
    }
}
```

## 2. 修饰符详解

### 2.1 访问修饰符

访问修饰符控制变量的可见性和访问权限。

```java
public class AccessModifierDemo {
    // ========== public（公共）==========
    // 可以被任何类访问
    public String publicVar = "公共变量";

    // ========== protected（受保护）==========
    // 可以被同一包内的类、子类访问
    protected String protectedVar = "受保护变量";

    // ========== 默认（包-private）==========
    // 只能被同一包内的类访问
    String defaultVar = "默认变量";

    // ========== private（私有）==========
    // 只能被当前类访问
    private String privateVar = "私有变量";

    // 通常通过 getter/setter 方法访问私有变量
    public String getPrivateVar() {
        return privateVar;
    }

    public void setPrivateVar(String value) {
        this.privateVar = value;
    }
}
```

#### 访问修饰符对比表

| 修饰符 | 同一个类 | 同一个包 | 子类（不同包） | 任何地方 |
|--------|----------|----------|----------------|----------|
| `public` | ✅ | ✅ | ✅ | ✅ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| 默认 | ✅ | ✅ | ❌ | ❌ |
| `private` | ✅ | ❌ | ❌ | ❌ |

```java
// ========== 不同包的子类访问示例 ==========
package com.example.parent;

public class Parent {
    public String publicVar = "public";
    protected String protectedVar = "protected";
    String defaultVar = "default";
    private String privateVar = "private";
}
```

```java
package com.example.child;

import com.example.parent.Parent;

public class Child extends Parent {
    public void testAccess() {
        System.out.println(publicVar);     // ✅ 可以访问
        System.out.println(protectedVar);  // ✅ 可以访问（子类）
        // System.out.println(defaultVar); // ❌ 编译错误（不同包）
        // System.out.println(privateVar); // ❌ 编译错误（私有）
    }
}
```

### 2.2 非访问修饰符

非访问修饰符提供额外的功能控制。

```java
public class NonAccessModifierDemo {
    // ========== static（静态）==========
    // 属于类而非对象，所有对象共享
    static int count = 0;

    // ========== final（最终）==========
    // 变量值不能被修改（常量）
    final int MAX_SIZE = 100;
    final String COMPANY_NAME = "Java公司";

    // ========== transient（瞬时）==========
    // 序列化时忽略该变量
    transient String transientVar = "序列化时忽略";

    // ========== volatile（易变）==========
    // 多线程环境下保证可见性
    volatile boolean isRunning = true;

    public NonAccessModifierDemo() {
        count++;  // 每次创建对象，count 加 1
    }

    public void testFinal() {
        // MAX_SIZE = 200;  // ❌ 编译错误：final 变量不能修改
        System.out.println("最大容量: " + MAX_SIZE);
    }
}
```

#### 非访问修饰符对比表

| 修饰符 | 作用 | 使用场景 |
|--------|------|----------|
| `static` | 类级别，所有对象共享 | 计数器、常量、工具方法 |
| `final` | 值不可修改 | 常量、不可变引用 |
| `transient` | 序列化时忽略 | 敏感信息、临时数据 |
| `volatile` | 保证多线程可见性 | 状态标志、缓存变量 |

## 3. 数据类型

成员变量可以是任何 Java 数据类型。

```java
public class DataTypeDemo {
    // ========== 基本数据类型 ==========
    byte byteVar = 127;              // 1字节，范围：-128~127
    short shortVar = 32767;          // 2字节，范围：-32768~32767
    int intVar = 2147483647;         // 4字节，范围：±21亿
    long longVar = 9876543210L;      // 8字节，后缀L
    float floatVar = 3.14f;          // 4字节，后缀f
    double doubleVar = 3.1415926;    // 8字节，精度更高
    char charVar = 'A';              // 2字节，Unicode字符
    boolean booleanVar = true;       // 1位，true/false

    // ========== 引用数据类型 ==========
    String stringVar = "Hello";      // 字符串
    int[] arrayVar = {1, 2, 3};      // 数组
    Object objectVar = new Object(); // 对象

    // ========== 自定义类型 ==========
    Student studentVar;              // 自定义类（未初始化，为null）
    java.util.List<String> listVar;  // 集合类型

    // ========== 常见错误示例 ==========
    // long longVar2 = 9876543210;  // ❌ 编译错误：超出int范围需要后缀L
    // float floatVar2 = 3.14;      // ❌ 编译错误：默认是double，需要后缀f

    public DataTypeDemo() {
        studentVar = new Student();  // 必须初始化后才能使用
        listVar = new java.util.ArrayList<>();
    }
}
```

## 4. 初始化值

成员变量有默认初始化值，而局部变量没有。

```java
public class InitializationDemo {
    // ========== 成员变量默认值 ==========
    // 整数类型：0
    byte byteDefault;       // 0
    short shortDefault;     // 0
    int intDefault;         // 0
    long longDefault;       // 0L

    // 浮点类型：0.0
    float floatDefault;     // 0.0f
    double doubleDefault;   // 0.0

    // 字符类型：'\u0000'（空字符）
    char charDefault;       // '\u0000'

    // 布尔类型：false
    boolean booleanDefault; // false

    // 引用类型：null
    String stringDefault;       // null
    int[] arrayDefault;         // null
    Object objectDefault;       // null
    Student studentDefault;     // null

    public void printDefaults() {
        System.out.println("byte: " + byteDefault);       // 0
        System.out.println("short: " + shortDefault);     // 0
        System.out.println("int: " + intDefault);         // 0
        System.out.println("long: " + longDefault);       // 0
        System.out.println("float: " + floatDefault);     // 0.0
        System.out.println("double: " + doubleDefault);   // 0.0
        System.out.println("char: " + (int)charDefault);  // 0
        System.out.println("boolean: " + booleanDefault); // false
        System.out.println("String: " + stringDefault);   // null
    }

    // ========== 初始化方式 ==========
    public class InitMethods {
        // 方式1：声明时初始化
        String name = "张三";
        int age = 25;

        // 方式2：构造代码块初始化
        {
            name = "李四";
            age = 30;
        }

        // 方式3：构造方法初始化
        public InitMethods(String name, int age) {
            this.name = name;
            this.age = age;
        }
    }

    // ⚠️ 局部变量没有默认值，必须初始化
    public void localVarDemo() {
        int localVar;          // 声明但未初始化
        // System.out.println(localVar);  // ❌ 编译错误

        localVar = 100;        // 必须先初始化
        System.out.println(localVar);    // ✅ 正常
    }
}
```

### 初始化顺序

```java
public class InitOrderDemo {
    // 1. 静态变量（类级别）
    static String staticVar = "静态变量";

    // 2. 实例变量（对象级别）
    String instanceVar = "实例变量";

    // 3. 构造代码块
    {
        System.out.println("构造代码块执行");
    }

    // 4. 静态代码块
    static {
        System.out.println("静态代码块执行");
    }

    // 5. 构造方法
    public InitOrderDemo() {
        System.out.println("构造方法执行");
    }

    public static void main(String[] args) {
        // 执行顺序：
        // 1. 静态代码块（只执行一次）
        // 2. 构造代码块
        // 3. 构造方法

        InitOrderDemo demo1 = new InitOrderDemo();
        System.out.println("---");
        InitOrderDemo demo2 = new InitOrderDemo();
    }
}
```

```

---

```

## 5. 成员变量 vs 局部变量对比

### 5.1 详细对比表

| 特性 | 成员变量 | 局部变量 |
|------|----------|----------|
| **定义位置** | 类中、方法外 | 方法内、代码块内、参数列表 |
| **作用域** | 整个类内部 | 从声明到所在代码块结束 |
| **生命周期** | 随对象创建而创建 | 方法调用时创建，方法结束销毁 |
| **默认值** | 有（0/false/null） | 无，必须初始化 |
| **修饰符** | 可以使用各种修饰符 | 不能使用访问修饰符 |
| **存储位置** | 堆内存（对象内部） | 栈内存（栈帧中） |
| **访问方式** | 通过对象或类访问 | 直接使用变量名 |

### 5.2 代码对比示例

```java
public class ComparisonDemo {
    // ========== 成员变量 ==========
    // 定义在类中、方法外
    String memberVar = "成员变量";

    // 静态成员变量
    static String staticMemberVar = "静态成员变量";

    // final 成员变量
    final int MAX_VALUE = 100;

    // private 成员变量
    private String privateMemberVar = "私有成员变量";

    public void testMethod(String parameter) {
        // ========== 局部变量 ==========
        // 定义在方法内部
        String localVar = "局部变量";

        // 参数也是局部变量
        String paramVar = parameter;

        // 代码块中的局部变量
        {
            String blockVar = "代码块局部变量";
            System.out.println(blockVar);  // ✅ 可以访问
        }
        // System.out.println(blockVar);  // ❌ 编译错误：已超出作用域

        // ========== 访问对比 ==========
        // 成员变量：直接访问
        System.out.println(memberVar);          // ✅
        System.out.println(staticMemberVar);    // ✅
        System.out.println(MAX_VALUE);          // ✅
        System.out.println(privateMemberVar);   // ✅（同类中）

        // 局部变量：直接访问
        System.out.println(localVar);           // ✅
        System.out.println(paramVar);           // ✅

        // ========== 生命周期对比 ==========
        // 成员变量：随对象存在
        // 局部变量：方法结束后销毁
    }
}
```

## 6. 完整代码示例

```java
public class MemberVariableCompleteDemo {
    // ========== 修饰符 + 数据类型 + 初始化值 完整示例 ==========

    // 1. public + 基本类型 + 初始化值
    public int publicInt = 100;

    // 2. private + 引用类型 + 初始化值
    private String privateString = "私有字符串";

    // 3. protected + 数组 + 默认值
    protected int[] protectedArray;  // 默认值为 null

    // 4. 默认 + 浮点类型 + 初始化值
    double defaultDouble = 3.14;

    // 5. static + 常量 + final
    public static final String APP_NAME = "我的应用";
    public static final int VERSION = 1;

    // 6. static + 计数器
    private static int instanceCount = 0;

    // 7. transient（序列化时忽略）
    transient String transientString = "序列化时忽略";

    // 8. volatile（多线程可见）
    private volatile boolean isRunning = false;

    // 9. final（不可变引用）
    private final java.util.List<String> immutableList = new java.util.ArrayList<>();

    // ========== 构造方法 ==========
    public MemberVariableCompleteDemo() {
        instanceCount++;
        System.out.println("创建第 " + instanceCount + " 个对象");
    }

    // ========== 静态方法（不能访问非静态成员）==========
    public static void staticMethod() {
        // System.out.println(publicInt);  // ❌ 编译错误
        System.out.println("APP_NAME: " + APP_NAME);  // ✅ 可以访问静态成员
    }

    // ========== 实例方法（可以访问所有成员）==========
    public void instanceMethod() {
        // 访问成员变量
        System.out.println("publicInt: " + publicInt);
        System.out.println("privateString: " + privateString);
        System.out.println("protectedArray: " + protectedArray);
        System.out.println("defaultDouble: " + defaultDouble);
        System.out.println("isRunning: " + isRunning);

        // 访问静态成员
        System.out.println("APP_NAME: " + APP_NAME);
        System.out.println("instanceCount: " + instanceCount);

        // 修改成员变量
        publicInt = 200;
        isRunning = true;
        immutableList.add("item");

        // 局部变量
        String localVar = "局部变量";
        int localInt = 100;
        System.out.println("局部变量: " + localVar);
    }

    // ========== Getter/Setter 方法 ==========
    public String getPrivateString() {
        return privateString;
    }

    public void setPrivateString(String privateString) {
        this.privateString = privateString;
    }

    public boolean isRunning() {
        return isRunning;
    }

    public void setRunning(boolean running) {
        this.isRunning = running;
    }

    // ========== 主方法 ==========
    public static void main(String[] args) {
        // 创建对象
        MemberVariableCompleteDemo obj1 = new MemberVariableCompleteDemo();
        MemberVariableCompleteDemo obj2 = new MemberVariableCompleteDemo();

        // 访问成员变量
        System.out.println("obj1.publicInt: " + obj1.publicInt);
        System.out.println("obj2.publicInt: " + obj2.publicInt);

        // 修改成员变量（每个对象独立）
        obj1.publicInt = 300;
        System.out.println("修改后 obj1.publicInt: " + obj1.publicInt);
        System.out.println("修改后 obj2.publicInt: " + obj2.publicInt);  // 仍然是100

        // 静态变量（所有对象共享）
        System.out.println("instanceCount: " + MemberVariableCompleteDemo.instanceCount);

        // 调用方法
        obj1.instanceMethod();
        MemberVariableCompleteDemo.staticMethod();
    }
}
```

## 总结

### 成员变量核心要点

| 要点 | 说明 |
|------|------|
| **定义位置** | 类中、方法外 |
| **作用域** | 整个类内部 |
| **默认值** | 有（0/false/null） |
| **修饰符** | 可以使用 public/private/protected/static/final 等 |
| **存储位置** | 堆内存（对象内部） |
| **生命周期** | 随对象创建而创建 |

### 局部变量核心要点

| 要点 | 说明 |
|------|------|
| **定义位置** | 方法内、代码块内、参数列表 |
| **作用域** | 从声明到代码块结束 |
| **默认值** | 无，必须初始化 |
| **修饰符** | 不能使用访问修饰符 |
| **存储位置** | 栈内存（栈帧中） |
| **生命周期** | 方法调用时创建，方法结束销毁 |

### 常见错误

```java
public class CommonErrorsDemo {
    String memberVar = "成员变量";

    public void commonErrors() {
        // 错误1：局部变量未初始化
        // int localVar;
        // System.out.println(localVar);  // ❌ 编译错误

        // 错误2：静态上下文访问非静态成员
        // System.out.println(memberVar);  // ❌ 在静态方法中

        // 错误3：final 变量修改
        // final int FINAL_VAR = 100;
        // FINAL_VAR = 200;  // ❌ 编译错误

        // 正确做法
        int localVar = 100;  // ✅ 先初始化
        System.out.println(localVar);
    }

    // 静态方法中访问非静态成员
    public static void staticMethod() {
        // System.out.println(memberVar);  // ❌ 不能直接访问
        CommonErrorsDemo obj = new CommonErrorsDemo();
        System.out.println(obj.memberVar);  // ✅ 通过对象访问
    }
}
```
