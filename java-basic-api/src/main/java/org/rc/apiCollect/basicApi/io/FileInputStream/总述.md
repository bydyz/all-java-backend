# Java `java.io.FileInputStream` 详解

`java.io.FileInputStream` 是 Java I/O 体系中用于从文件读取**原始字节**的基础类。它直接与操作系统文件系统交互，适合读取图像、音频、可执行文件等二进制数据，也可用于读取文本文件，但处理文本时通常需要配合 `InputStreamReader` 来正确处理字符编码。

## 📌 功能定位与核心特征

`FileInputStream` 继承自 `InputStream`，提供的是**低级别、无缓冲**的文件访问。这意味着每次 `read()` 调用都可能触发一次系统调用，效率较低。因此在实际开发中，常将其包装在 `BufferedInputStream` 中以获得更好的性能。

一个关键特性是：**`FileInputStream` 不支持 `mark()` 和 `reset()` 操作**。`markSupported()` 方法固定返回 `false`，尝试调用 `reset()` 会抛出 `IOException`。

---

## 🏗️ 三个公开构造器

| 构造器 | 说明 | 抛出异常 |
| :--- | :--- | :--- |
| `FileInputStream(String name)` | 通过文件路径字符串创建流 | `FileNotFoundException` |
| `FileInputStream(File file)` | 通过 `File` 对象创建流 | `FileNotFoundException` |
| `FileInputStream(FileDescriptor fdObj)` | 通过已有的文件描述符创建流 | 无（但 `fdObj` 无效时行为未定义） |

前两个构造器最为常用。如果文件不存在、是一个目录，或因权限问题无法打开，它们都会抛出 `FileNotFoundException`。使用 `FileDescriptor` 的构造器通常用于需要复用底层系统文件句柄的高级场景。

```java
// 方式一：使用文件路径字符串
try (FileInputStream fis = new FileInputStream("data.bin")) {
    // 使用流
} catch (IOException e) { e.printStackTrace(); }

// 方式二：使用 File 对象
File file = new File("data.bin");
try (FileInputStream fis = new FileInputStream(file)) {
    // 使用流
} catch (IOException e) { e.printStackTrace(); }
```

> **务必关闭流**：`FileInputStream` 持有操作系统文件句柄，不关闭会导致资源泄漏。推荐始终使用 **try-with-resources** 语句，确保流在代码块结束时自动关闭，即使发生异常也不例外。

## 📖 核心 API 与代码示例

### `read()`：逐字节读取

`int read()` 读取**单个字节**，返回值的范围是 `0` 到 `255`。当到达文件末尾时，返回 **`-1`**。这是最简单的读取方式，但效率最低。

```java
try (FileInputStream fis = new FileInputStream("small.txt")) {
    int byteValue;
    while ((byteValue = fis.read()) != -1) {
        System.out.print((char) byteValue); // 对于 ASCII 文本可直接转 char
    }
} catch (IOException e) { e.printStackTrace(); }
```

### `read(byte[] b)`：读取到字节数组（块读取）

`int read(byte[] b)` 尝试读取最多 `b.length` 个字节并存入数组，返回**实际读取的字节数**。到达末尾时返回 `-1`。块读取远快于逐字节读取，是处理文件的标准方式。

```java
try (FileInputStream fis = new FileInputStream("largefile.dat")) {
    byte[] buffer = new byte[8192]; // 8KB 缓冲区
    int bytesRead;
    while ((bytesRead = fis.read(buffer)) != -1) {
        // 处理 buffer 中从下标 0 开始、长度为 bytesRead 的数据
        // 注意：不要直接处理整个 buffer，因为最后一次读取可能未填满
        process(buffer, 0, bytesRead);
    }
} catch (IOException e) { e.printStackTrace(); }
```

### `read(byte[] b, int off, int len)`：读取到数组的指定区间

此方法将数据读入 `b` 数组，从 `off` 位置开始存放，最多读取 `len` 个字节。适用于需要将不同来源的数据拼接到同一数组，或只关心文件特定片段的场景。

```java
try (FileInputStream fis = new FileInputStream("data.bin")) {
    byte[] buffer = new byte[1024];
    // 将接下来 512 个字节读入 buffer 的第 100 个位置之后
    int bytesRead = fis.read(buffer, 100, 512);
    System.out.println("实际读取: " + bytesRead + " 字节");
} catch (IOException e) { e.printStackTrace(); }
```

### `skip(long n)`：跳过指定字节数

`long skip(long n)` 尝试跳过 `n` 个字节，返回**实际跳过的字节数**（可能小于 `n`，比如已接近文件末尾）。常用于跳过文件头（Header）或不需要的元数据区域。

```java
try (FileInputStream fis = new FileInputStream("file_with_header.bin")) {
    long skipped = fis.skip(128); // 跳过 128 字节的头部
    System.out.println("实际跳过: " + skipped + " 字节");
    int nextByte = fis.read();    // 从头部之后开始读取
} catch (IOException e) { e.printStackTrace(); }
```

### `available()`：可用字节数估计

`int available()` 返回**无需阻塞即可读取的字节数估计值**。对于本地文件，它通常等于“文件总大小 - 当前已读取的字节数”，但 **`available()` 返回 `0` 并不一定意味着文件已读完**，不应该用它来判断读取是否结束。

```java
try (FileInputStream fis = new FileInputStream("input.txt")) {
    System.out.println("开始时可用: " + fis.available());
    fis.read(); fis.read(); fis.read();
    System.out.println("读取3字节后可用: " + fis.available()); // 通常会减少 3
} catch (IOException e) { e.printStackTrace(); }
```

### `close()`：释放资源

`void close()` 关闭流并释放关联的系统资源。再次强调，应通过 try-with-resources 自动调用，或在 `finally` 块中手动调用。

### `getChannel()` 与 `getFD()`：访问底层资源

这两个方法提供了与 NIO 和操作系统底层交互的入口。

- **`FileChannel getChannel()`**：返回与此流关联的 `FileChannel`，可用于内存映射（`map`）、文件锁定、以及高效的通道间传输（`transferTo` / `transferFrom`）。
- **`FileDescriptor getFD()`**：返回底层文件描述符对象，通常仅在需要与原生代码或特定系统 API 交互时使用。

```java
// 使用 FileChannel 进行零拷贝式传输的示例
try (FileInputStream fis = new FileInputStream("source.dat");
     FileChannel inChannel = fis.getChannel();
     FileOutputStream fos = new FileOutputStream("target.dat");
     FileChannel outChannel = fos.getChannel()) {

    long size = inChannel.size();
    long position = 0;
    while (position < size) {
        position += inChannel.transferTo(position, size - position, outChannel);
    }
}
```

## ⚠️ 关键注意事项

**字节流不是字符流**。`FileInputStream` 读取的是原始字节，如果文件包含多字节编码的字符（如 UTF-8 中的中文），直接将字节强制转换为 `char` 会导致乱码。处理文本文件的正确做法是使用 `InputStreamReader` 并明确指定字符集：

```java
try (var reader = new InputStreamReader(
        new FileInputStream("utf8_text.txt"), StandardCharsets.UTF_8)) {
    int charValue;
    while ((charValue = reader.read()) != -1) {
        System.out.print((char) charValue);
    }
}
```

**`FileInputStream` 适合二进制，文本处理优先考虑 `Files` 工具类**。对于简单的文本读写，`java.nio.file.Files` 提供了更简洁、更安全的 API（如 `Files.readAllBytes`、`Files.newInputStream`），在多数现代 Java 应用中往往是更好的选择。
