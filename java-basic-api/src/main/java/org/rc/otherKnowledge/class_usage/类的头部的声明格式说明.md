# Java 类声明大括号前的完整结构

全面的类声明语法结构如下：

```java
[访问修饰符] [非访问修饰符] class 类名 [<类型参数>] [extends 父类名] [implements 接口列表] {
    // 类体
}
```

其中，方括号 `[]` 内的部分都是可选的。

---

## 1. 修饰符 (Modifiers)

修饰符用于设定类的属性和行为约束，分为两大类。

### 1.1 访问修饰符 (Access Modifiers)

用于控制类对其他类的可见性。对于**顶层类**，通常只能使用 `public` 或默认（不写）。

- **`public`**：公共类，对所有类可见。
- **默认（无修饰符）**：包级私有，仅在同一包内可见。

> **注意**：`private` 和 `protected` 不能用于修饰顶层类，它们只能用于修饰内部类（嵌套类）。

### 1.2 非访问修饰符 (Non-Access Modifiers)

用于提供其他功能特性。

- **`abstract`**：抽象类，不能被实例化，可以包含抽象方法。
- **`final`**：最终类，不能被任何其他类继承。
- **`static`**：静态类，仅适用于**内部类**，表示它是一个嵌套的静态类。
- **`strictfp`**：用于确保浮点运算的精确可移植性（在较新的 Java 版本中，其行为已是默认的）。
- **`sealed`**（Java 17+）：密封类，限制哪些其他类可以继承它。
- **`non-sealed`**（Java 17+）：用于在密封类的子类中，取消密封限制。

> **组合规则**：`abstract` 和 `final` 不能同时使用，因为抽象类需要被继承来实现其方法，而最终类禁止被继承。

---

## 2. `class` 关键字与类名

- **`class`**：声明一个类的核心关键字。
- **类名**：一个有效的 Java 标识符，按惯例应以大写字母开头（如 `MyClass`）。

---

## 3. 泛型类型参数 (Type Parameters)

如果类是一个泛型类，在类名后面用尖括号 `<>` 声明类型参数。

- **格式**：`<T>`、`<K, V>`、`<E extends Number>` 等。
- **示例**：

```java
public class Box<T> {
    // ...
}
```

其中 `<T>` 就是类型参数。

---

## 4. 继承声明 (`extends`)

用于指定该类的直接父类（超类）。Java 是单继承，一个类只能有一个父类。

- **格式**：`extends 父类名`
- **示例**：

```java
public class Dog extends Animal {
    // ...
}
```

---

## 5. 接口实现声明 (`implements`)

用于指定该类实现的一个或多个接口。一个类可以实现多个接口。

- **格式**：`implements 接口1, 接口2, ...`
- **示例**：

```java
public class MyThread implements Runnable, Serializable {
    // ...
}
```

---

## 6. 总结

类声明大括号之前的部分远不止：

```java
[访问修饰符] [非访问修饰符] class 类名
```

它的完整结构包含了：

- **修饰符**
- **`class` 关键字**
- **类名**
- **可选的泛型参数**
- **可选的 `extends` 继承声明**
- **可选的 `implements` 接口实现声明**

这些部分共同定义了一个类的核心特征和它在类型系统中的位置。

至于大括号 `{}` 内部的**类体 (Class Body)**，它包含了类的具体实现，如成员变量、方法、构造器、内部类、初始化块等，这是类的“血肉”。
