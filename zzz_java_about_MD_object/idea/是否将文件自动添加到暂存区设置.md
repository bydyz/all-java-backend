# IntelliJ IDEA 暂存区设置指南

## 概述

在 IntelliJ IDEA 中，编辑后的文件是否自动进入暂存区，取决于当前的版本控制模式。

## 两种管理模式对比

| 模式 | 工作机制 | 适用场景 |
|------|----------|----------|
| **变更列表 (Changelists)** | 默认模式。修改的文件会自动暂存，无需手动 `git add` | 习惯简单、线性的提交流程 |
| **暂存区 (Staging Area)** | 模拟 Git 命令行操作。需要手动将更改添加到暂存区 | 习惯显式 `git add`，或需要对同一文件的不同部分分别提交 |

## 如何切换模式

1. 打开设置：
   - Windows/Linux：`File` -> `Settings`
   - macOS：`IntelliJ IDEA` -> `Preferences`

2. 导航到：`Version Control` -> `Git`

3. 找到 **Enable staging area** 复选框：
   - ✅ 勾选：进入"暂存区"模式，需要手动 `git add`
   - ❌ 取消勾选：回到默认的"变更列表"模式，编辑后文件自动进入待提交状态

## 控制新文件的自动添加

对于新创建的文件，IDEA 默认会弹窗询问是否添加到 Git。你可以调整此行为：

1. 进入 `Settings` / `Preferences`

2. 导航到：`Version Control` -> `Confirmation`

3. 在 `When files are created` 下拉菜单中选择：
   - **Add**：自动添加
   - **Show options before adding**：每次询问（推荐）
   - **Do not add**：不自动添加

## 注意事项

> ⚠️ **重命名或移动文件**
>
> 目前 IDEA 无法完全禁止重命名或移动文件时自动暂存。如果不想立刻提交这些改动，操作后需在终端手动执行 `git reset` 来取消暂存。

## 常见问题

**Q：当前已是暂存区模式，如何取消暂存？**

在 Commit 工具窗口（`Alt+9` / `Cmd+9`）的 Local 标签页中，选中文件，右键选择 **Unstage** 即可。
