## 一、先理解两个概念

一个对象在 new 的时候创建是哪个类型的对象，它从头至尾都不会变。即这个对象的运行时类型，本质的类型用于不会变。但是，把这个对象赋值给不同类型的变量时，这些变量的编译时类型却不同。

Java 中“转型”主要发生在**有继承/实现关系**的类型之间。

```java
class Animal { }
class Dog extends Animal { }
```

- `Dog` 是子类，`Animal` 是父类。
- 一个 `Dog` 对象，既可以被看成 `Dog`，也可以被看成 `Animal`。

```java
Dog dog = new Dog();
Animal animal = dog; // 向上转型
```

这里：

- `dog` 的编译时类型是 `Dog`
- `animal` 的编译时类型是 `Animal`
- 但两者运行时指向的都是同一个 `Dog` 对象

## 二、向上转型：子类 -> 父类

### 1. 语法

向上转型是**自动的**，不需要强制转换：

```java
父类类型 变量 = 子类对象;
```

### 2. 代码示例

```java
class Animal {
    public void eat() {
        System.out.println("Animal eat");
    }
}

class Dog extends Animal {
    @Override
    public void eat() {
        System.out.println("Dog eat");
    }

    public void bark() {
        System.out.println("Dog bark");
    }
}

public class UpCastDemo {
    public static void main(String[] args) {
        Dog dog = new Dog();

        // 向上转型：自动完成
        Animal animal = dog;

        // 调用的是 Dog 重写后的 eat()
        animal.eat(); // 输出：Dog eat

        // 编译报错：Animal 类型引用不能调用 Dog 特有方法
        // animal.bark();
    }
}
```

### 3. 向上转型的作用

#### 作用1：实现多态

父类引用可以指向不同子类对象，调用重写方法时执行子类实现：

```java
class Cat extends Animal {
    @Override
    public void eat() {
        System.out.println("Cat eat");
    }
}

public class PolymorphismDemo {
    public static void main(String[] args) {
        Animal a1 = new Dog();
        Animal a2 = new Cat();

        a1.eat(); // Dog eat
        a2.eat(); // Cat eat
    }
}
```

#### 作用2：统一参数类型

方法参数可以写成父类类型，接收所有子类对象：

```java
public class Zoo {
    public static void feed(Animal animal) {
        animal.eat();
    }

    public static void main(String[] args) {
        feed(new Dog()); // Dog eat
        feed(new Cat()); // Cat eat
    }
}
```

#### 作用3：统一容器存储

```java
import java.util.ArrayList;
import java.util.List;

public class ListDemo {
    public static void main(String[] args) {
        List<Animal> animals = new ArrayList<>();
        animals.add(new Dog());
        animals.add(new Cat());

        for (Animal animal : animals) {
            animal.eat();
        }
    }
}
```

### 4. 向上转型后能调用什么？

关键规则：

> **能调用哪些方法，看编译时类型；方法执行哪个实现，看运行时类型。**

```java
Animal animal = new Dog();

animal.eat();  // 编译通过，因为 Animal 有 eat()
// animal.bark(); // 编译失败，因为 Animal 没有 bark()
```

虽然运行时对象是 `Dog`，但引用类型是 `Animal`，编译器只认 `Animal` 中定义的方法。

## 三、向下转型：父类 -> 子类

### 1. 语法

向下转型需要**强制类型转换**：

```java
子类类型 变量 = (子类类型) 父类引用;
```

### 2. 代码示例

```java
public class DownCastDemo {
    public static void main(String[] args) {
        Animal animal = new Dog(); // 向上转型

        // 向下转型：强制转换
        Dog dog = (Dog) animal;
        dog.eat();  // Dog eat
        dog.bark(); // Dog bark
    }
}
```

这里 `animal` 虽然声明为 `Animal`，但运行时真实对象是 `Dog`，所以可以转回 `Dog`。

### 3. 错误示例：ClassCastException

```java
public class DownCastErrorDemo {
    public static void main(String[] args) {
        Animal animal = new Cat();

        // 运行时异常：Cat cannot be cast to Dog
        Dog dog = (Dog) animal;

        dog.bark();
    }
}
```

原因：

```java
Animal animal = new Cat();
```

真实对象是 `Cat`，不是 `Dog`，不能强转为 `Dog`。

## 四、向下转型的正确做法：先判断

### 1. 使用 `instanceof`

```java
public class SafeDownCastDemo {
    public static void main(String[] args) {
        Animal animal = new Dog();

        if (animal instanceof Dog) {
            Dog dog = (Dog) animal;
            dog.bark(); // Dog bark
        }
    }
}
```

### 2. Java 16+ 模式匹配

```java
public class PatternMatchDemo {
    public static void main(String[] args) {
        Animal animal = new Dog();

        if (animal instanceof Dog dog) {
            dog.bark();
        }
    }
}
```

等价于先判断再强转，代码更简洁。

### 3. 向下转型的作用

#### 作用1：调用子类特有方法

```java
public class UseDownCast {
    public static void main(String[] args) {
        Animal animal = new Dog();

        if (animal instanceof Dog dog) {
            dog.bark(); // bark 是 Dog 特有方法
        }
    }
}
```

#### 作用2：处理父类容器中的具体子类

```java
import java.util.ArrayList;
import java.util.List;

public class DownCastInList {
    public static void main(String[] args) {
        List<Animal> animals = new ArrayList<>();
        animals.add(new Dog());
        animals.add(new Cat());

        for (Animal animal : animals) {
            if (animal instanceof Dog dog) {
                dog.bark();
            } else if (animal instanceof Cat cat) {
                cat.catchMouse();
            }
        }
    }
}

class Cat extends Animal {
    @Override
    public void eat() {
        System.out.println("Cat eat");
    }

    public void catchMouse() {
        System.out.println("Cat catch mouse");
    }
}
```

## 五、需要注意的重点

### 1. 向上转型安全，向下转型有风险

```java
Animal animal = new Dog();
Dog dog = (Dog) animal; // 安全，因为真实对象是 Dog

Animal animal2 = new Cat();
Dog dog2 = (Dog) animal2; // 运行时 ClassCastException
```

向下转型前最好使用：

```java
if (animal instanceof Dog dog) {
    dog.bark();
}
```

---

### 2. 方法调用看运行时，字段访问看编译时

这是非常容易混淆的点。

```java
class Parent {
    String name = "Parent";

    public void print() {
        System.out.println("Parent print");
    }
}

class Child extends Parent {
    String name = "Child";

    @Override
    public void print() {
        System.out.println("Child print");
    }
}

public class FieldMethodDemo {
    public static void main(String[] args) {
        Parent p = new Child();

        System.out.println(p.name); // Parent
        p.print();                  // Child print
    }
}
```

原因：

- 字段不参与多态，访问看**编译时类型**。
- 实例方法参与多态，调用看**运行时类型**。

---

### 3. 静态方法看编译时类型

```java
class Parent {
    public static void staticMethod() {
        System.out.println("Parent static");
    }
}

class Child extends Parent {
    public static void staticMethod() {
        System.out.println("Child static");
    }
}

public class StaticDemo {
    public static void main(String[] args) {
        Parent p = new Child();
        p.staticMethod(); // Parent static
    }
}
```

静态方法不属于对象多态，取决于引用类型。

---

### 4. 私有方法、构造方法、final 方法不参与多态

- `private` 方法不能被重写。
- `final` 方法不能被重写。
- 构造方法不能被重写。

---

### 5. 向下转型不是“改变对象类型”

```java
Animal animal = new Dog();
Dog dog = (Dog) animal;
```

这里没有把对象变成 `Dog`，它本来就是 `Dog` 对象。强转只是把引用类型恢复成更具体的类型。

---

### 6. 不要滥用向下转型

如果代码中大量出现：

```java
if (animal instanceof Dog) {
    ...
} else if (animal instanceof Cat) {
    ...
}
```

往往说明设计可以优化，比如：

- 在父类中定义通用方法，让子类重写；
- 使用策略模式；
- 使用访问者模式；
- 使用多态替代类型判断。

向下转型适合“确实需要调用子类特有行为”的场景，不宜作为常规流程。

## 六、完整综合示例

```java
class Animal {
    public void eat() {
        System.out.println("Animal eat");
    }
}

class Dog extends Animal {
    @Override
    public void eat() {
        System.out.println("Dog eat");
    }

    public void bark() {
        System.out.println("Dog bark");
    }
}

class Cat extends Animal {
    @Override
    public void eat() {
        System.out.println("Cat eat");
    }

    public void catchMouse() {
        System.out.println("Cat catch mouse");
    }
}

public class CastDemo {
    public static void main(String[] args) {
        // 向上转型：自动
        Animal a1 = new Dog();
        Animal a2 = new Cat();

        // 多态：运行时调用子类重写方法
        a1.eat(); // Dog eat
        a2.eat(); // Cat eat

        // 向下转型：先判断，再强转
        if (a1 instanceof Dog dog) {
            dog.bark(); // Dog bark
        }

        if (a2 instanceof Cat cat) {
            cat.catchMouse(); // Cat catch mouse
        }

        // 错误示例：不要直接强转不匹配的类型
        // Dog wrong = (Dog) a2; // ClassCastException
    }
}
```

## 七、总结

| 项目  | 向上转型         | 向下转型                        |
|-----|--------------|-----------------------------|
| 方向  | 子类 -> 父类     | 父类 -> 子类                    |
| 语法  | 自动           | 强制 `(子类类型)`                 |
| 安全性 | 安全           | 有风险，可能 `ClassCastException` |
| 作用  | 多态、统一参数、统一容器 | 调用子类特有方法                    |
| 注意  | 只能调用父类声明的方法  | 先用 `instanceof` 判断          |

核心一句话：

> **向上转型是为了“用父类统一看待子类对象”，向下转型是为了“把父类引用还原成真实子类，以调用子类特有功能”。向上安全，向下需谨慎。
**
