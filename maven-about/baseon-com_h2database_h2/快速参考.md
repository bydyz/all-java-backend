
启动成功后访问: http://localhost:8080/health

## 📍 API 接口

### 基础接口

| 接口 | 方法 | URL | 说明 |
|------|------|-----|------|
| 健康检查 | GET | `/health` | 检查应用状态 |
| 获取所有用户 | GET | `/api/users` | 查询用户列表 |
| 获取单个用户 | GET | `/api/users/{id}` | 按ID查询 |
| 创建用户 | POST | `/api/users` | 添加用户 |
| 更新用户 | PUT | `/api/users/{id}` | 修改用户 |
| 删除用户 | DELETE | `/api/users/{id}` | 删除用户 |
| H2 控制台 | GET | `/h2-console` | 数据库管理 |

## ⚙️ 核心配置

### pom.xml 关键配置
```xml
<properties>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
</properties>
```

### application.yml 关键配置
```yaml
spring:
  datasource:
    driver-class-name: org.h2.Driver
    url: jdbc:h2:mem:testdb
  h2:
    console:
      enabled: true
```

### schema.sql 关键修复
```sql
-- MySQL: UNIQUE KEY uk_username (username)
-- H2: CONSTRAINT uk_username UNIQUE (username)
```
