# Java Record 全览

Record 在 Java 14 预览、**Java 16 正式发布**，用于声明「不可变的透明数据载体」。下面按主题逐条列举，尽量配代码。

---

## 1. 基本语法与编译器自动生成的内容

```java
public record Point(int x, int y) {}
```

这一行等价于：

```java
public final class Point extends java.lang.Record {
    private final int x;
    private final int y;

    public Point(int x, int y) { this.x = x; this.y = y; }

    public int x() { return x; }          // 注意是 x()，不是 getX()
    public int y() { return y; }

    @Override public boolean equals(Object o) { /* 按组件逐一比较 */ }
    @Override public int hashCode() { /* 按组件计算 */ }
    @Override public String toString() { return "Point[x=" + x + ", y=" + y + "]"; }
}
```

要点：
- 隐式 **final**，隐式继承 `java.lang.Record`，**不能 extends 其他类**。
- 组件（component）自动生成 `private final` 字段 + 同名访问器。
- `equals` 按组件比较（浮点用 `compare` 语义，能正确处理 `NaN` / `-0.0`）。
- `toString` 格式固定为 `Point[x=1, y=2]`。
- 组件名不能是 `clone / finalize / getClass / hashCode / notify / notifyAll / toString / wait`（编译错误）。

## 2. 构造器：三种写法

### 2.1 紧凑构造器（compact constructor）— 最常用

用于校验/规整，**不用写参数列表，也不用写字段赋值**：

```java
public record Range(int lo, int hi) {
    public Range {
        if (lo > hi) throw new IllegalArgumentException("lo > hi: " + lo + "," + hi);
        // 结尾隐式执行 this.lo = lo; this.hi = hi;
    }
}
```

紧凑构造器里可以**重新给参数赋值**，赋值结果会写入字段：

```java
public record Range(int lo, int hi) {
    public Range {
        if (lo > hi) { int t = lo; lo = hi; hi = t; }  // 自动交换
    }
}
```

### 2.2 规范构造器（canonical constructor）— 显式全写

```java
public record Point(int x, int y) {
    public Point(int x, int y) {
        this.x = x;   // 必须给所有字段赋值
        this.y = y;
    }
}
```

### 2.3 额外构造器 — 必须委托给其他构造器

```java
public record Point(int x, int y) {
    public Point() { this(0, 0); }            // 委托
    public Point(int v) { this(v, v); }
}
```

> 紧凑构造器与规范构造器**不能同时声明**。

## 3. 允许与禁止的成员

```java
public record Circle(double radius) {

    // ✅ 静态字段
    private static final double PI2 = Math.PI * 2;

    // ✅ 静态方法
    public static Circle unit() { return new Circle(1); }

    // ✅ 实例方法（但不能修改组件）
    public double circumference() { return PI2 * radius; }

    // ✅ 可以覆盖 equals/hashCode/toString
    @Override public String toString() { return "r=" + radius; }

    // ❌ 编译错误：实例字段（组件之外）
    // private int cache;

    // ❌ 编译错误：实例初始化块
    // { cache = 1; }

    // ❌ 编译错误：abstract / native
}
```

## 4. 实现接口、泛型

```java
public interface Shape { double area(); }

public record Rect(double w, double h) implements Shape {
    @Override public double area() { return w * h; }
}

// 泛型 record
public record Pair<A, B>(A first, B second) {
    public static <A, B> Pair<A, B> of(A a, B b) { return new Pair<>(a, b); }
    public Pair<B, A> swap() { return new Pair<>(second, first); }
}
```

## 5. 嵌套与局部 Record

```java
public class Outer {
    // 成员 record（隐式 static）
    record Inner(int v) {}

    void method() {
        // 局部 record（Java 16+），可用于方法内临时数据结构
        record Local(int a, int b) {}
        var l = new Local(1, 2);
    }
}
```

## 6. 与 sealed interface / 模式匹配配合（代数数据类型）

```java
public sealed interface Expr permits Num, Add, Mul {}
public record Num(int v) implements Expr {}
public record Add(Expr l, Expr r) implements Expr {}
public record Mul(Expr l, Expr r) implements Expr {}

static int eval(Expr e) {
    return switch (e) {                                  // 穷尽性由 sealed 保证
        case Num(int v)       -> v;                      // record 解构模式（Java 21）
        case Add(Expr l, Expr r) -> eval(l) + eval(r);
        case Mul(Expr l, Expr r) -> eval(l) * eval(r);
    };
}
```

嵌套解构：

```java
if (obj instanceof Line(Point(int x1, int y1), Point(int x2, int y2))) {
    System.out.println(x1 + y1 + x2 + y2);
}
```

## 7. 反射 API

```java
Class<?> c = Point.class;
System.out.println(c.isRecord());                       // true

for (RecordComponent rc : c.getRecordComponents()) {
    System.out.println(rc.getName() + " : " + rc.getType());   // x : int
    Object v = rc.getAccessor().invoke(new Point(1, 2));
}

// 通过反射构造
Object p = c.getDeclaredConstructor(int.class, int.class).newInstance(1, 2);
```

## 8. 序列化

```java
public record P(int x, String s) implements java.io.Serializable {}
```

- Record 的序列化**基于规范构造器**：反序列化时会调用它，因此紧凑构造器里的校验依然生效。
- **不能**自定义 `writeObject / readObject` 等钩子（编译错误）。
- 组件类型本身需可序列化。

## 9. 常见坑

### 9.1 只有浅不可变：数组/集合组件

```java
public record Basket(int[] items) {
    public Basket { items = items.clone(); }          // 入参防御性拷贝
    @Override public int[] items() { return items.clone(); }  // 出参防御性拷贝
}
```

若不做拷贝，外部可改内部状态；且自动生成的 `equals` 对数组用**引用比较**。

### 9.2 可变组件

```java
record Holder(List<String> list) {}
```
`list` 引用是 final，但内容可变。要真正不可变，用 `List.copyOf(...)` 并在紧凑构造器中赋值。

### 9.3 `equals` 比较的是字段而非「业务 id」

```java
record User(long id, String name) {}
new User(1, "a").equals(new User(1, "b"));  // false —— 两个组件都要相等
```
需要按 id 判定时，自行覆盖 `equals/hashCode`。

### 9.4 适合做 Map key

因为 `equals/hashCode` 自动且正确，record 天然适合做 `HashMap`/`HashSet` 的键（普通可变类常被误用）。

## 10. 限制速查表

| 项目 | 是否允许 |
|---|---|
| 继承其他类 | ❌（隐式继承 `Record`） |
| 被继承 | ❌（隐式 final） |
| 实现接口 | ✅ |
| 声明实例字段 | ❌ |
| 声明静态字段/方法 | ✅ |
| 声明实例方法 | ✅ |
| 实例初始化块 | ❌ |
| abstract / native | ❌ |
| 可变参数组件 | ✅（`record R(int... xs)`，注意浅不可变） |
| 泛型 | ✅ |
| 局部声明 | ✅ |
| 作为注解目标的组件传播 | ✅（`@Target(RECORD_COMPONENT)` 会传播到字段/方法/参数） |

## 11. 与 Lombok `@Value` 的对比

| | Record | Lombok `@Value` |
|---|---|---|
| 语言级支持 | ✅ JDK 16+ 原生 | 需注解处理器 |
| 能否继承 | ❌ | ✅（可 extends） |
| 可变字段 | ❌ | 可配合 `@Builder` 等 |
| 模式匹配解构 | ✅（Java 21） | ❌ |
| 与 sealed 组成 ADT | ✅ | 部分 |
| 语义清晰度 | 高（「就是数据」） | 中（依赖工具） |

---

## 小结

Record 的核心价值在于三件事：**① 样板代码由编译器生成**（构造器、访问器、`equals/hashCode/toString`）；**② 语义即契约**（不可变、透明、按值相等）；**③ 与 sealed + 模式匹配组合成 Java 的代数数据类型**。使用时记住两个边界：它是**浅不可变**的，且**不能参与类继承**。
