**`PrintWriter` 是 `java.io` 包中面向字符流的格式化输出类。它的设计目标是在 `Writer` 或 `OutputStream` 之上叠加一套“无受检异常、丰富的格式化方法、可选自动刷新”的便捷输出接口。** 代价是它将 I/O 错误从“抛出 `IOException`”改为“静默设置内部错误标志”，需要调用方主动通过 `checkError()` 来感知失败。

---

## 核心定位与关键特性

`PrintWriter` 继承自 `Writer`，是一个**装饰器（处理流）** 。它本身不直接管理文件句柄或网络连接，而是包装一个底层的 `Writer` 或 `OutputStream`，在其上提供打印能力。

与普通 `Writer` 最根本的差异在于**异常模型**：`PrintWriter` 的 `print`、`println`、`printf`、`format` 等方法**不抛出 `IOException`**。当底层写入失败时，它会在内部将错误标志置为 `true`，调用方随后通过 `checkError()` 查询是否发生过错误。这一设计使代码更简洁，但也意味着如果忘记检查错误，写入失败可能被无声忽略。

另一个关键特性是**自动刷新（autoFlush）** 。当构造时指定 `autoFlush = true`，调用 `println`、`printf` 或 `format` 会触发底层缓冲区的刷新；普通的 `print` 调用不会触发自动刷新。

---

## 构造器详解

`PrintWriter` 共有 **8 种公开构造器**，可以按“包装目标”与“是否自动刷新”两个维度来记忆。

### 包装 `Writer` 或 `OutputStream`（基础形式，无自动刷新）

```java
PrintWriter(Writer out)
PrintWriter(OutputStream out)
```

这两者创建**不带自动刷新**的 `PrintWriter`。`OutputStream` 版本内部会进行字符到字节的编码转换。

### 带自动刷新标志的包装形式

```java
PrintWriter(Writer out, boolean autoFlush)
PrintWriter(OutputStream out, boolean autoFlush)
```

`autoFlush` 为 `true` 时，`println`、`printf`、`format` 调用后自动刷新缓冲区。

### 直接基于文件（无自动刷新，使用平台默认字符编码）

```java
PrintWriter(File file)
PrintWriter(String fileName)
```

直接打开文件作为输出目标，但不支持指定字符集。

### 直接基于文件 + 指定字符编码

```java
PrintWriter(File file, String csn)
PrintWriter(String fileName, String csn)
```

在直接操作文件时可以指定字符集（如 `"UTF-8"`），同样**不带自动刷新**。

## 核心 API 与代码示例

### `print` 与 `println`：类型重载与换行控制

`PrintWriter` 为 `boolean`、`char`、`int`、`long`、`float`、`double`、`char[]`、`String`、`Object` 等类型都提供了 `print` 和 `println` 重载。`print` 写入后不换行；`println` 写入后追加与平台相关的行分隔符。

```java
try (PrintWriter writer = new PrintWriter("output.txt")) {
    writer.print(true);        // 不换行
    writer.print(' ');
    writer.print(42);
    writer.print(' ');
    writer.print(3.14159);
    writer.println();          // 仅换行
    writer.println("这一行输出后换行");
    writer.println(new Object()); // 调用 toString()
} catch (Exception e) {
    e.printStackTrace();
}
```

`print` 与 `write` 在多数场景下效果相似，但 `write` 提供了 `write(char[] buf, int off, int len)` 这样的按区间写入能力，`print` 没有对应的重载。

---

### `printf` 与 `format`：结构化格式化输出

`printf` 和 `format` 功能等价，均接受格式字符串和可变参数，支持类似 C 语言 `printf` 的格式说明符。这是 `PrintWriter` 相比普通 `Writer` 最核心的增值能力之一。

```java
try (PrintWriter writer = new PrintWriter("formatted.txt")) {
    String name = "John Doe";
    int age = 35;
    double salary = 45250.75;
    Date now = new Date();

    writer.printf("Name: %s, Age: %d%n", name, age);
    writer.printf("Salary: %,.2f%n", salary);
    writer.printf("Date: %tF %tT%n", now, now);
    writer.printf("Hex: %x, Octal: %o%n", 255, 255);
}
```

格式说明符支持 `%s`（字符串）、`%d`（整数）、`%f`（浮点数）、`%tF`/`%tT`（日期时间）、`%,.2f`（带千位分隔符和两位小数）等。

---

### `append`：链式追加

`append` 返回 `PrintWriter` 本身，支持链式调用，语义上等价于 `print`。注意：**`append` 并不控制文件追加模式**——它只是向当前流追加内容；如果要向已有文件末尾追加，需要在底层 `FileWriter` 构造时传入 `true`。

```java
PrintWriter pw = new PrintWriter(new FileWriter("log.txt", true)); // 文件追加模式
pw.append("第一段").append(" -> ").append("第二段").println();
pw.flush();
pw.close();
```

---

### `flush`、`close` 与 `checkError`

- **`flush()`**：强制将缓冲区数据推到底层输出流。即使 `autoFlush = true`，在关键节点（如网络请求完成）仍可主动调用以确保数据送出。
- **`close()`**：关闭流。`close()` 通常会隐式刷新，但不应依赖这一点来替代显式 `flush`。
- **`checkError()`**：刷新流并返回内部错误标志。**这是 `PrintWriter` 错误处理的唯一可靠出口**，因为其写入方法本身不抛出 `IOException`。

```java
PrintWriter writer = new PrintWriter(System.out);
writer.println("尝试写入");
// 模拟错误场景...
if (writer.checkError()) {
    System.err.println("PrintWriter 写入过程中发生了错误");
}
writer.close();
```

---

### 自动刷新行为：`autoFlush = true` vs 默认

```java
// 无自动刷新：print 后必须手动 flush，否则输出可能不立即出现
PrintWriter noAuto = new PrintWriter(System.out);
noAuto.print("这行不会立刻刷新");
noAuto.flush(); // 手动刷新后才保证输出

// 自动刷新：println 后立即刷新
PrintWriter auto = new PrintWriter(System.out, true);
auto.println("这行因 autoFlush 立即刷新");
```

**触发自动刷新的方法仅限于 `println`、`printf`、`format`**；`print`、`write`、`append` 不会触发自动刷新，即使 `autoFlush` 为 `true`。

---

## 与 `BufferedWriter` 的关系及性能要点

需要澄清一个常见混淆：`PrintWriter` **本身不内置字符缓冲区**。如果追求较高的写入吞吐量，标准做法是用 `PrintWriter` 包装 `BufferedWriter`（或 `BufferedWriter` 包装 `FileWriter`），让缓冲由 `BufferedWriter` 承担。

```java
try (PrintWriter out = new PrintWriter(
        new BufferedWriter(new FileWriter("output.txt")))) {
    out.println("通过 BufferedWriter 获得缓冲性能");
} catch (IOException e) {
    e.printStackTrace();
}
```

`BufferedWriter` 会抛出 `IOException`，迫使调用方处理 I/O 问题；`PrintWriter` 则用 `checkError()` 替代异常。选择原则：如果**主要需求是格式化输出和简洁 API**，直接用 `PrintWriter`（必要时包装缓冲层）；如果**写入量大且需要严格控制错误处理**，`BufferedWriter` 直接使用或作为底层缓冲层更合适。

---

## 典型使用场景

**文件文本写入（含追加与自动刷新）** ：

```java
try (PrintWriter pw = new PrintWriter(
        new BufferedWriter(new FileWriter("app.log", true)))) {
    pw.printf("[%tc] 用户 %s 登录成功%n", new Date(), "张三");
}
```

**Servlet / HTTP 响应输出**：`HttpServletResponse.getWriter()` 返回的正是 `PrintWriter`，用于向客户端发送 HTML、JSON 或纯文本。

**控制台格式化输出**：`new PrintWriter(System.out, true)` 可以在保留控制台输出的同时使用 `printf` 格式化能力。

---

**总结**：`PrintWriter` 的核心价值在于**格式化输出能力 + 无受检异常的简洁 API + 可选的自动刷新**。使用时需要牢记两点：其一，错误不会自动传播，必须主动调用 `checkError()`；其二，它不替代缓冲，高性能写入应通过包装 `BufferedWriter` 来实现。
