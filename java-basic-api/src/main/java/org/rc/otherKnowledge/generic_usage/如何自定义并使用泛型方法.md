# Java 泛型方法详解

## 一、先厘清概念：泛型方法 ≠ 泛型类中的方法

很多初学者会把"泛型类里的方法"当成泛型方法，其实二者不同：

```java
// 泛型类：类型参数 T 声明在类名后面
public class Box<T> {
    private T value;
    public void set(T value) { this.value = value; }
    public T get() { return value; }   // 这不是泛型方法，只是用了类的类型参数
}
```

**真正的泛型方法**是：**类型参数声明在方法签名中（返回类型之前）**，与所在类是否是泛型类无关。

```java
// 泛型方法：<T> 声明在方法返回类型前面
public <T> T identity(T value) {
    return value;
}
```

判定标准只有一条：**方法自己声明了类型参数 `<T>`**。

---

## 二、基本语法结构

```java
[访问修饰符] [static] [final] <类型参数列表> 返回类型 方法名(参数列表) [throws 异常] {
    // 方法体
}
```

关键点：

| 元素 | 位置 | 说明 |
|------|------|------|
| 类型参数 `<T>` | 返回类型**之前** | 可有多个，如 `<K, V>` |
| 返回类型 | 可以用 `T` | 也可以是 `void` |
| 参数列表 | 可以用 `T` | 也可以不用（靠推断） |

## 三、从简单到复杂：逐层示例

### 3.1 最基础的泛型方法

```java
public class GenericMethodDemo {

    // 声明 <T>，参数和返回值都用 T
    public static <T> T identity(T value) {
        return value;
    }

    public static void main(String[] args) {
        // 1) 显式指定类型参数
        String s = GenericMethodDemo.<String>identity("hello");

        // 2) 编译器自动类型推断（最常见）
        Integer i = identity(123);          // 推断 T = Integer
        String  t = identity("world");      // 推断 T = String
        System.out.println(s + " " + i + " " + t);
    }
}
```

### 3.2 参数与返回值类型不同（用类型参数串联）

```java
public class Converter {

    /**
     * 把 T 类型数组的第一个元素"包装"成 U 类型
     * 这里 T 和 U 都被方法自身声明
     */
    public static <T, U> U firstAs(T[] arr, Function<T, U> mapper) {
        if (arr == null || arr.length == 0) {
            throw new IllegalArgumentException("数组不能为空");
        }
        return mapper.apply(arr[0]);
    }

    public static void main(String[] args) {
        Integer[] nums = {1, 2, 3};
        String result = firstAs(nums, n -> "第" + n + "个");
        System.out.println(result);   // 第1个
    }
}
```

### 3.3 多个类型参数

```java
public class PairUtil {

    // K、V 由方法声明，与类无关
    public static <K, V> Map.Entry<K, V> entryOf(K key, V value) {
        return Map.entry(key, value);
    }

    // 交换数组中两个位置（类型参数 T 保证类型安全）
    public static <T> void swap(T[] arr, int i, int j) {
        T tmp = arr[i];
        arr[i] = arr[j];
        arr[j] = tmp;
    }

    public static void main(String[] args) {
        var e = entryOf("age", 18);      // 推断 K=String, V=Integer
        System.out.println(e);

        Integer[] a = {1, 2, 3};
        swap(a, 0, 2);
        System.out.println(Arrays.toString(a));   // [3, 2, 1]
    }
}
```

## 四、有界类型参数（Bounded Type Parameters）

### 4.1 上界：`<T extends 上界>`

```java
public class NumberUtil {

    /**
     * T 必须是 Number 的子类型，才能安全调用 doubleValue()
     */
    public static <T extends Number> double sum(T[] nums) {
        double s = 0;
        for (T n : nums) {
            s += n.doubleValue();   // 因为 T extends Number，所以这里合法
        }
        return s;
    }

    public static void main(String[] args) {
        Integer[] ints = {1, 2, 3};
        Double[] ds   = {1.5, 2.5};
        System.out.println(sum(ints));  // 6.0
        System.out.println(sum(ds));    // 4.0
        // sum(new String[]{"a"});      // 编译错误，String 不是 Number
    }
}
```

### 4.2 多个上界（一个类 + 若干接口，类必须写在最前）

```java
interface Named { String name(); }

public class BoundDemo {

    /**
     * T 必须同时继承 Number 且实现 Named 接口
     */
    public static <T extends Number & Named> String describe(T t) {
        return t.name() + ":" + t.intValue();
    }

    static class Score extends Number implements Named {
        private final String n;
        private final int v;
        Score(String n, int v) { this.n = n; this.v = v; }
        public String name() { return n; }
        public int intValue() { return v; }
        public long longValue() { return v; }
        public float floatValue() { return v; }
        public double doubleValue() { return v; }
    }

    public static void main(String[] args) {
        System.out.println(describe(new Score("语文", 95)));  // 语文:95
    }
}
```

> 注意：上界中有类时，类只能有一个且必须放**第一位**，接口用 `&` 连接。

## 五、递归类型边界（Fluent API 常用）

```java
public class RecursiveBound {

    // T 必须是 Comparable<T> 的子类型（自己跟自己比）
    public static <T extends Comparable<T>> T max(T a, T b) {
        return a.compareTo(b) >= 0 ? a : b;
    }

    public static void main(String[] args) {
        System.out.println(max(3, 7));               // 7
        System.out.println(max("apple", "banana"));  // banana
    }
}
```

## 六、泛型方法与可变参数

```java
public class VarargsDemo {

    @SafeVarargs   // 抑制堆污染警告；final/static/private 方法才能用
    public static <T> List<T> listOf(T... items) {
        return new ArrayList<>(Arrays.asList(items));
    }

    // 典型陷阱：泛型可变参数会创建 T[]，存在堆污染风险
    // 生产环境请优先使用 List<T> 而不是 T[]
    public static void main(String[] args) {
        List<Integer> l = listOf(1, 2, 3);
        System.out.println(l);
    }
}
```

> 泛型数组本身就是受限的（`new T[]` 不合法），因为类型擦除。可变参数是编译器"帮你建数组"，会带 `@SafeVarargs` 警告需要抑制。

## 七、泛型方法与泛型类组合：静态方法不能用类的 T

```java
public class Box<T> {
    private T value;
    public Box(T value) { this.value = value; }

    // ❌ 编译错误：静态方法不能使用类的类型参数 T
    // public static T getValue() { ... }

    // ✅ 但静态方法可以自己声明 <T>，名字相同也行（作用域不同）
    public static <T> Box<T> of(T value) {
        return new Box<>(value);
    }

    // ✅ 实例方法用类的 T
    public T unwrap() { return value; }
}
```

原因：类的 `T` 是随**实例**绑定的，静态方法没有实例，只能靠方法自己声明 `T`。

## 八、通配符 vs 方法类型参数

这是面试常考区别。

```java
// 只读场景：用通配符 ? extends 更简洁
public static double sumAll(List<? extends Number> list) {
    double s = 0;
    for (Number n : list) s += n.doubleValue();
    return s;
}

// 需要"把元素再写回/作为参数"的场景：用类型参数 T
public static <T> void addAll(List<T> dest, List<T> src) {
    dest.addAll(src);
}

// 极端例子：有类型参数 T 才能表达"两个参数类型相同"的约束
public static <T> T pick(T a, T b) {   // 要求 a、b 同一类型
    return a;
}
```

**判断口诀**：
- 只是"消费"元素（读取）→ `? extends X`（PECS 的 Producer）
- 只是"写入"元素 → `? super X`（Consumer）
- 需要**多个参数之间类型关联** → 用泛型方法的 `T`

## 九、类型推断细节

```java
public class Inference {

    // 菱形推断：目标类型 + 方法参数共同决定 T
    public static <T> List<T> newList(T seed) {
        List<T> l = new ArrayList<>();
        l.add(seed);
        return l;
    }

    public static void main(String[] args) {
        // 1) 从参数推断
        List<String> a = newList("x");

        // 2) 目标类型推断（target typing，Java 8+）
        List<Integer> b = newList(1);

        // 3) 显式指定（少见，但在链式或推断歧义时有用）
        List<String> c = Inference.<String>newList(null);

        // 4) 带类型边界的推断
        System.out.println(maxGeneric(3, 9));
    }

    public static <T extends Comparable<? super T>> T maxGeneric(T a, T b) {
        return a.compareTo(b) >= 0 ? a : b;
    }
}
```

> `T extends Comparable<? super T>` 是标准库 `Collections.max` 的签名，比 `Comparable<T>` 更宽容（能接受父类实现的 Comparable）。

## 十、实战：工具类的几种典型写法

### 10.1 安全的空值过滤

```java
public class CollectionUtil {

    public static <T> List<T> filterNonNull(List<T> src) {
        List<T> out = new ArrayList<>();
        for (T t : src) if (t != null) out.add(t);
        return out;
    }

    // 用 Predicate<T> 做通用过滤
    public static <T> List<T> filter(List<T> src, Predicate<? super T> p) {
        List<T> out = new ArrayList<>();
        for (T t : src) if (p.test(t)) out.add(t);
        return out;
    }

    public static void main(String[] args) {
        List<Integer> list = Arrays.asList(1, null, 2, null, 3);
        System.out.println(filterNonNull(list));            // [1, 2, 3]
        System.out.println(filter(list, x -> x != null && x > 1)); // [2, 3]
    }
}
```

### 10.2 类型安全的 Builder 链式返回

```java
public class FluentBuilder {

    static class Config {
        private final String name;
        private Config(String name) { this.name = name; }

        // 泛型方法：返回调用者自己的子类型
        public <T extends Config> T cast(Class<T> type) {
            return type.cast(this);
        }

        @Override public String toString() { return "Config(" + name + ")"; }
    }

    public static void main(String[] args) {
        Config c = new Config("demo");
        Config c2 = c.cast(Config.class);   // 类型安全转换
        System.out.println(c2);
    }
}
```

### 10.3 通用「默认值」工具

```java
public class Defaults {

    public static <T> T getOrDefault(T value, T defaultValue) {
        return value != null ? value : defaultValue;
    }

    // 用 Supplier 延迟计算默认值
    public static <T> T getOrDefault(T value, Supplier<T> supplier) {
        return value != null ? value : supplier.get();
    }

    public static void main(String[] args) {
        String s = getOrDefault(null, "默认");
        System.out.println(s);                                    // 默认
        System.out.println(getOrDefault(null, () -> "懒加载"));   // 懒加载
    }
}
```

## 十一、常见限制与坑

```java
public class Pitfalls {

    // ❌ 1) 类型参数不能是基本类型
    // public <T> void f(T t) {}
    // f(1);  // 会被自动装箱成 Integer，没问题；但不能写 <int>

    // ❌ 2) 不能 new T()（类型擦除，运行时不知道 T 是什么）
    // public <T> T create() { return new T(); }

    // ✅ 解决方案：传 Class 或用 Supplier
    public static <T> T create(Class<T> type) throws Exception {
        return type.getDeclaredConstructor().newInstance();
    }
    public static <T> T create(Supplier<T> supplier) {
        return supplier.get();
    }

    // ❌ 3) 不能 instanceof T，不能 new T[]，不能 T.class
    // if (obj instanceof T) {}
    // T[] arr = new T[10];
    // Class<T> c = T.class;

    // ✅ 用 Class<T> 做运行时类型令牌
    public static <T> boolean isInstance(Object o, Class<T> type) {
        return type.isInstance(o);
    }

    // ❌ 4) 泛型类的静态成员不能引用类类型参数（见第七节）

    // ❌ 5) 方法重载时，擦除后签名相同会冲突
    // public void f(List<String> l) {}
    // public void f(List<Integer> l) {}   // 编译错误：both methods have same erasure
}
```

### 类型擦除的直观体现

```java
public class Erasure {
    public static <T> void f(T t) { }
    public static void main(String[] args) {
        f("a");
        f(1);
        // 运行时 f(String) 和 f(Integer) 是同一个方法
        // 字节码签名都是 f(Object)
    }
}
```

## 十二、总结：写好泛型方法的 checklist

1. **类型参数声明在返回类型前**：`public <T> T foo(...)`。
2. **类型参数命名约定**：`T`（Type）、`E`（Element）、`K`/`V`（Key/Value）、`R`（Result）、`N`（Number）。
3. **能推断就不显式指定**：`identity(123)` 优于 `Xxx.<Integer>identity(123)`。
4. **需要约束就用上界**：`<T extends Number & Comparable<T>>`，类在前接口在后。
5. **多个参数之间有关联 → 用类型参数**；只读/只写单个容器 → 用通配符（PECS）。
6. **静态方法用类的 T 不行**，要么自己声明 `<T>`，要么把类也做成泛型并传实例。
7. **牢记类型擦除**：不能 `new T()`、`instanceof T`、`new T[]`、`T.class`；需要时传 `Class<T>`。
8. **可变参数泛型**加 `@SafeVarargs`，优先用 `List<T>` 代替 `T[]`。

掌握上面这些，日常框架源码（`Collections`、`Stream`、`Optional`、Spring 的 `RestTemplate` 等）里的泛型方法就都能读懂了。
