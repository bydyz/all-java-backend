# 总述

它的主要价值在于汇总与索引，让你可以从一个统一的位置（可以是本地、远程，或你自己配置的URL）出发，方便地发现和选取所有可用的项目模板。因此，官方文档把它定义为一个“存储Archetype信息的标准文件，用于让用户从中选择列表来创建新项目”


# 默认的Catalog

|  名称 | 位置 | 优先级 | 说明 |
| ----- | ----- | ----- | ----- |
| internal | Maven 安装包内部 | 最高 | 只包含最基础的几个官方模板，创建项目时总能显示。 |
| local (本地) | 用户本地的仓库目录 | 中等 | 主要用于存放你自己通过 mvn install 安装的自定义模板。 |
| remote (远程) |	Maven 中央仓库 |	最低（且最慢） | 包含了互联网上公开的海量模板，但每次都会从网络下载，导致项目创建变慢。 |


# 工作原理

当你使用 `mvn archetype:generate` 命令创建项目时，背后大致是这样的流程：

1. 参数指定：Maven 根据你输入的 `-DarchetypeCatalog` 参数（可选 `local`, `remote`, `internal` 等）决定去哪里获取菜单。

2. 解析菜单：Archetype 插件会解析对应位置的 `archetype-catalog.xml` 文件。

3. 展示选项：插件会将 Catalog 文件中列出的所有模板的序号和描述在终端列出，供你选择。

4. 生成项目：在你选定模板后，插件会根据该模板的 `groupId`, `artifactId`, `version` 等坐标信息，从 Maven 仓库中下载对应的模板包，最终生成项目骨架。
