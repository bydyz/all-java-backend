下面按“基本类型 ↔ 包装类”“字符串 ↔ 基本/包装”“包装类之间”“缓存与 `==`”“常见坑”来说明。Java 中对应关系：

| 基本类型      | 包装类         | 常用转换方法                                                      |
|-----------|-------------|-------------------------------------------------------------|
| `byte`    | `Byte`      | `Byte.valueOf` / `byteValue` / `Byte.parseByte`             |
| `short`   | `Short`     | `Short.valueOf` / `shortValue` / `Short.parseShort`         |
| `int`     | `Integer`   | `Integer.valueOf` / `intValue` / `Integer.parseInt`         |
| `long`    | `Long`      | `Long.valueOf` / `longValue` / `Long.parseLong`             |
| `float`   | `Float`     | `Float.valueOf` / `floatValue` / `Float.parseFloat`         |
| `double`  | `Double`    | `Double.valueOf` / `doubleValue` / `Double.parseDouble`     |
| `char`    | `Character` | `Character.valueOf` / `charValue`，无 `parseCharacter`        |
| `boolean` | `Boolean`   | `Boolean.valueOf` / `booleanValue` / `Boolean.parseBoolean` |

`Integer/Long/Short/Byte/Float/Double` 继承 `Number`；`Character`、`Boolean` 不继承 `Number`。包装类都是不可变对象。

## 1. 基本类型 ↔ 包装类：手动转换

### 基本类型 -> 包装类

推荐用 `valueOf`，不推荐 `new Integer(...)`。Java 9 起包装类构造器已标记为废弃。

```java
int i = 42;

Integer a = Integer.valueOf(i); // 推荐：基本类型 -> 包装类
Integer b = new Integer(i);     // 不推荐，Java 9+ 已废弃

long l = 100L;
Long l1 = Long.valueOf(l);

char c = 'A';
Character ch = Character.valueOf(c);

boolean flag = true;
Boolean bool = Boolean.valueOf(flag);
```

### 包装类 -> 基本类型

用 `xxxValue()`：

```java
Integer a = Integer.valueOf(42);

int i1 = a.intValue();     // 包装类 -> 基本类型
long l = a.longValue();    // 也可以转成其他数值基本类型
double d = a.doubleValue();

Character ch = Character.valueOf('A');
char c = ch.charValue();

Boolean bool = Boolean.TRUE;
boolean flag = bool.booleanValue();
```

注意：`intValue()`、`longValue()` 等可能发生截断、溢出或精度丢失，例如：

```java
Long l = 4294967296L; // 2^32
int i = l.intValue(); // 截断为低 32 位，结果为 0

Double d = 1.9;
int n = d.intValue(); // 1，直接截断小数部分
```

## 2. 自动装箱与自动拆箱

Java 5 开始支持自动装箱/拆箱。它们是编译期语法糖。

```java
Integer a = 10;  // 自动装箱：编译后近似 Integer.valueOf(10)
int b = a;       // 自动拆箱：编译后近似 a.intValue()
```

上面代码等价于：

```java
Integer a = Integer.valueOf(10);
int b = a.intValue();
```

**自动拆箱**常发生在需要基本类型的上下文中：赋值、算术运算、比较、方法参数、`switch`、三元表达式等。

```java
Integer x = 1;
Integer y = 2;

int sum = x + y; // x、y 自动拆箱后相加
```

集合中只能存引用类型，所以会出现自动装箱/拆箱：

```java
List<Integer> list = new ArrayList<>();
list.add(1);          // 自动装箱：Integer.valueOf(1)
int v = list.get(0);  // 自动拆箱：list.get(0).intValue()
```


由于我们经常要做基本类型与包装类之间的转换，**从 JDK5.0 开始**，基本类型与包装类的装箱、拆箱动作可以自动完成。例如：
  Integer i = 4;//自动装箱。相当于 Integer i = Integer.valueOf(4);
  i = i + 5;//等号右边：将 i 对象转成基本数值(自动拆箱) i.intValue() + 5;
  //加法运算完成后，再次装箱，把基本数值转成对象。

注意：只能与自己对应的类型之间才能实现自动装箱与拆箱。
  Integer i = 1;
  Double d = 1;// 错误的，1 是 int 类型

## 3. 字符串 ↔ 基本类型/包装类

### 字符串 -> 基本类型：`parseXxx`

```java
int i = Integer.parseInt("123");
long l = Long.parseLong("123456");
double d = Double.parseDouble("3.14");
boolean b = Boolean.parseBoolean("TRUE"); // true，忽略大小写
```

`Boolean.parseBoolean` 比较特殊：只有字符串等于 `"true"`（忽略大小写）才返回 `true`，其他都返回 `false`，不抛异常。

```java
System.out.println(Boolean.parseBoolean("true"));  // true
System.out.println(Boolean.parseBoolean("TRUE"));  // true
System.out.println(Boolean.parseBoolean("yes"));   // false
```

`Character` 没有 `parseCharacter`：

```java
char c = "Java".charAt(0); // 'J'
Character ch = Character.valueOf(c);
```

### 字符串 -> 包装类：`valueOf`

```java
Integer a = Integer.valueOf("123"); // 返回 Integer
Long l = Long.valueOf("1000");      // 返回 Long
Double d = Double.valueOf("3.14");  // 返回 Double
Boolean b = Boolean.valueOf("true");// 返回 Boolean
```

区别：

```java
int x = Integer.parseInt("123");    // 返回 int
Integer y = Integer.valueOf("123"); // 返回 Integer，内部会调用 parseInt，再 valueOf(int)
```

`Integer.valueOf("123")` 也可能复用缓存对象。

### 基本类型/包装类 -> 字符串

```java
int i = 123;

String s1 = Integer.toString(i); // 推荐：int -> String
String s2 = String.valueOf(i);   // 通用：基本类型 -> String

Integer a = Integer.valueOf(123);
String s3 = a.toString();        // 包装类 -> String
String s4 = String.valueOf(a);   // 包装类 -> String
```

## 4. 包装类之间的转换

包装类之间通常不能直接赋值，例如 `Integer` 不能直接赋给 `Long`：

```java
Integer i = 100;

long a = i;             // OK：拆箱 int，再拓宽为 long
Long l1 = i.longValue();// OK：Integer -> long，再自动装箱为 Long
Long l2 = (long) i;     // OK：先拆箱并拓宽为 long，再装箱为 Long

// Long l3 = i;         // 编译错误，不能直接把 Integer 赋给 Long
```

包装类可以通过 `Number` 统一处理：

```java
Number n = Integer.valueOf(42);

int i = n.intValue();
long l = n.longValue();
double d = n.doubleValue();
```

但要注意类型和精度：

```java
Integer a = Integer.valueOf(1);
Long b = Long.valueOf(1L);

System.out.println(a.equals(b)); // false，equals 对类型敏感
```

## 5. 缓存机制与 `==` 比较

包装类 `valueOf` 有缓存机制：

- `Boolean`：缓存 `TRUE`、`FALSE`
- `Byte`：全部缓存
- `Short`、`Integer`、`Long`：至少缓存 `-128 ~ 127`
- `Character`：缓存 `\u0000 ~ \u007F`
- `Float`、`Double`：通常不缓存

示例：

```java
Integer a = 127;
Integer b = 127;
System.out.println(a == b); // true，命中 Integer 缓存

Integer c = 128;
Integer d = 128;
System.out.println(c == d);      // 通常 false，超出默认缓存范围
System.out.println(c.equals(d)); // true，比较值
```

`==` 的规则要分清：

```java
Integer a = 1000;
Integer b = 1000;

System.out.println(a == b);      // false：两个包装类引用比较
System.out.println(a.equals(b)); // true：值比较

int x = 1000;
System.out.println(a == x); // true：a 自动拆箱，变成基本类型值比较
```

所以包装类值比较推荐：

```java
Integer a = 1000;
Integer b = 1000;

System.out.println(a.equals(b));        // 推荐，但注意 a 不能为 null
System.out.println(Objects.equals(a, b)); // 更安全
```

## 6. 常见坑

### 6.1 包装类为 `null` 时拆箱会 NPE

```java
Integer n = null;

// int x = n;       // NullPointerException，自动拆箱
// if (n == 1) { }  // NullPointerException，n 拆箱
```

安全比较：

```java
Integer n = null;

System.out.println(n == null);              // true，引用比较，安全
System.out.println(Objects.equals(n, 1));   // false，安全
```

### 6.2 三元表达式可能触发拆箱

```java
Integer a = null;
int b = true ? a : 0; // NullPointerException
```

因为三元表达式被统一为 `int` 类型，`a` 需要拆箱。

### 6.3 包装类 `equals` 类型敏感

```java
Integer a = 1;
Long b = 1L;

System.out.println(a.equals(b)); // false
```

### 6.4 循环中频繁装箱可能影响性能

```java
Long sum = 0L;
for (int i = 0; i < 100000; i++) {
    sum += i; // 每次 sum 拆箱、相加、再装箱
}
```

性能敏感场景建议用基本类型：

```java
long sum = 0L;
for (int i = 0; i < 100000; i++) {
    sum += i;
}
```

### 6.5 推荐 `valueOf`，不推荐包装类构造器

```java
Integer a = Integer.valueOf(10); // 推荐
Integer b = new Integer(10);     // 不推荐，Java 9+ 已废弃
```

---

## 总结

1. 基本类型 -> 包装类：用 `Wrapper.valueOf(value)` 或自动装箱。
2. 包装类 -> 基本类型：用 `wrapper.xxxValue()` 或自动拆箱。
3. 字符串 -> 基本类型：用 `parseXxx`，如 `Integer.parseInt`。
4. 字符串 -> 包装类：用 `Wrapper.valueOf`，如 `Integer.valueOf`。
5. 基本/包装 -> 字符串：用 `String.valueOf` 或 `toString`。
6. 包装类之间不要依赖直接赋值，使用 `xxxValue()` 明确转换。
7. 两个包装类用 `==` 比较的是引用，值比较用 `equals` 或先拆箱；注意缓存范围和 `null`。
8. 自动装箱/拆箱是编译期语法糖，底层是 `valueOf` 和 `xxxValue`。
