## 2. 对象的创建过程（new 运算符）

### 2.1 对象创建的完整流程

```java
public class ObjectCreationDemo {
    public static void main(String[] args) {
        // 这一行代码执行了什么？
        Person person = new Person("张三", 25);
    }
}

class Person {
    String name;
    int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

### 2.2 new 运算符的执行步骤

```
┌─────────────────────────────────────────────────────────────────────┐
│                    new Person("张三", 25) 执行流程                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  步骤1：类加载检查                                                   │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  JVM 检查方法区是否已加载 Person 类                          │   │

│  │  • 大小 = 所有成员变量占用的空间之和                         │   │

│  │  将分配的内存空间初始化为零值                                 │   │
│  │  • name = null（引用类型）                                   │   │

│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  设置对象的哈希码、GC 分代年龄、锁状态标志等                  │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              ↓                                      │
│  步骤5：执行构造方法                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  调用 <init> 构造方法，执行：                                │   │

│  步骤6：返回引用                                                     │

│  │  将对象的内存地址（引用）返回给变量 person                    │   │
│  │  person 存储的是地址，不是对象本身                            │   │
```

### 3.2 对象引用的本质

```java
public class ReferenceDemo {
    public static void main(String[] args) {
        // person 变量存储的是什么？
        Person person = new Person("张三", 25);

        // person 存储的是对象的内存地址（引用），不是对象本身
        System.out.println(person);  // 输出: Person@1b6d3586 (哈希码)

        // 两个引用指向同一个对象
        Person samePerson = person;
        System.out.println(person == samePerson);  // true（地址相同）

        // 修改一个引用不影响另一个
        samePerson = new Person("李四", 30);
        System.out.println(person.name);   // "张三"（未改变）
        System.out.println(samePerson.name); // "李四"（新对象）
    }
}
```

## 4. 成员变量在内存中的位置

### 4.1 成员变量 vs 局部变量

```java
public class VariableLocationDemo {
    // ========== 成员变量（实例变量）==========
    // 位置：堆内存中的对象实例内
    String name;        // 引用类型成员变量
    int age;            // 基本类型成员变量
    double salary;      // 基本类型成员变量

    // ========== 静态变量（类变量）==========
    // 位置：方法区
    static int count = 0;
    static String companyName = "Java公司";

    public void showInfo() {
        // ========== 局部变量 ==========
        // 位置：虚拟机栈的栈帧中
        String address = "北京";      // 局部变量
        int temp = 100;               // 局部变量

        System.out.println("成员变量: " + name + ", " + age);
        System.out.println("局部变量: " + address + ", " + temp);
        System.out.println("静态变量: " + companyName);
    }
}
```

### 5.2 方法执行时的内存变化

```java
public class MethodExecutionDemo {
    public static void main(String[] args) {
        Person person = new Person("张三", 25);
        String name = person.getName();
    }
}

class Person {
    String name;
    int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() {
        return name;  // 执行时需要访问堆中的对象
    }

    public int getAge() {
        return age;
    }
}
```

### 6.3 栈帧生命周期

```java
public class StackFrameLifecycle {
    public static void main(String[] args) {
        System.out.println("main 方法开始");

        methodA();

        System.out.println("main 方法结束");
    }

    public static void methodA() {
        System.out.println("methodA 开始");

        int a = 10;
        methodB(a);

        System.out.println("methodA 结束");
        // methodA 栈帧销毁，局部变量 a 被回收
    }

    public static void methodB(int param) {
        System.out.println("methodB 开始");

        int b = param * 2;
        System.out.println("b = " + b);

        System.out.println("methodB 结束");
        // methodB 栈帧销毁，局部变量 param, b 被回收
    }
}
```

**执行流程：**

```
1. main() 开始 → 创建 main 栈帧
2. 调用 methodA() → 创建 methodA 栈帧（压栈）
3. 调用 methodB() → 创建 methodB 栈帧（压栈）
4. methodB() 结束 → 销毁 methodB 栈帧（弹栈）
5. methodA() 结束 → 销毁 methodA 栈帧（弹栈）
6. main() 结束 → 销毁 main 栈帧（弹栈）

栈内存特点：
• 先进后出（LIFO）
• 栈帧自动创建和销毁
• 无需 GC 回收
• 栈溢出: StackOverflowError（递归过深）
```

```java
public class ReferenceTypesDemo {
    public static void main(String[] args) {
        // ========== 强引用（Strong Reference）==========
        // 最常见的引用，GC 不会回收
        Object strong = new Object();

        // ========== 软引用（Soft Reference）==========
        // 内存不足时会被 GC 回收

        // GC 时一定会被回收

        // 无法通过虚引用获取对象，用于跟踪对象被 GC 回收的状态
        java.lang.ref.ReferenceQueue<Object> queue =
            new java.lang.ref.ReferenceQueue<>();
        java.lang.ref.PhantomReference<Object> phantom =
            new java.lang.ref.PhantomReference<>(new Object(), queue);
    }
}
```

## 9. 常见内存问题分析

### 9.1 堆内存溢出（OutOfMemoryError）

```java
// ⚠️ 错误示例：无限创建对象
public class MemoryLeakDemo {
    public static void main(String[] args) {
        java.util.List<byte[]> list = new java.util.ArrayList<>();

        // 每次循环创建 1MB 的对象，且一直持有引用
        while (true) {
            list.add(new byte[1024 * 1024]);  // 1MB
            // 对象被 list 引用，无法被 GC 回收
            // 最终导致 OutOfMemoryError: Java heap space
        }
    }
}

// ✅ 正确示例：及时释放引用
public class MemorySafeDemo {
    public static void main(String[] args) {
        java.util.List<byte[]> list = new java.util.ArrayList<>();

        for (int i = 0; i < 100; i++) {
            list.add(new byte[1024 * 1024]);

            if (list.size() > 10) {
                list.remove(0);  // 移除旧对象，允许 GC 回收
            }
        }
    }
}
```

### 9.2 栈内存溢出（StackOverflowError）

```java
// ⚠️ 错误示例：无限递归
public class StackOverflowDemo {
    public static void main(String[] args) {
        recursiveMethod();  // 无限递归
    }

    public static void recursiveMethod() {
        // 每次调用都会创建新的栈帧
        // 栈空间耗尽后抛出 StackOverflowError
        recursiveMethod();
    }
}

// ✅ 正确示例：设置递归终止条件
public class RecursiveDemo {
    public static void main(String[] args) {
        factorial(10);
    }

    public static int factorial(int n) {
        if (n <= 1) {  // 终止条件
            return 1;
        }
        return n * factorial(n - 1);
    }
}
```

### 9.3 对象引用内存分析

```java
public class ReferenceAnalysisDemo {
    public static void main(String[] args) {
        // ========== 场景1：对象创建和销毁 ==========
        Person p1 = new Person("张三", 25);  // 创建对象，p1 持有强引用
        Person p2 = p1;                      // p2 也持有强引用

        p1 = null;  // 移除 p1 的引用
        // 对象不会被 GC，因为 p2 还持有引用

        p2 = null;  // 移除 p2 的引用
        // 对象现在没有任何强引用，可以被 GC 回收

        // ========== 场景2：方法参数传递 ==========
        int num = 100;
        modifyValue(num);
        System.out.println("num = " + num);  // 100（基本类型是值传递）

        Person person = new Person("李四", 20);
        modifyObject(person);
        System.out.println("person.name = " + person.name);  // "修改后"（引用传递）
    }

    public static void modifyValue(int value) {
        value = 200;  // 修改的是副本，不影响原变量
    }

    public static void modifyObject(Person p) {
        p.name = "修改后";  // 通过引用修改对象内容
    }
}
```

## 总结

### 内存位置速查表

| 内容 | 存储位置 | 说明 |
|------|----------|------|
| **成员变量（基本类型）** | 堆 | 随对象存储在堆中 |
| **成员变量（引用类型）** | 堆 | 引用存储在对象中，实际对象也在堆中 |
| **静态变量** | 方法区 | 类加载时分配，整个程序生命周期 |
| **局部变量（基本类型）** | 栈 | 方法执行时分配，方法结束释放 |
| **局部变量（引用类型）** | 栈 | 引用存储在栈中，对象在堆中 |
| **方法字节码** | 方法区 | 类加载时读入，整个程序生命周期 |
| **方法执行** | 栈 | 每次调用创建栈帧，方法结束销毁 |
| **字符串常量** | 方法区（常量池） | 字面量存储在字符串常量池 |
| **对象实例** | 堆 | 通过 new 关键字创建 |
| **数组** | 堆 | 数组本身是对象，存储在堆中 |
