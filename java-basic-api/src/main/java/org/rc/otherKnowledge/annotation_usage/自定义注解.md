# Java 自定义注解：声明、使用、读取与处理详解

自定义注解必须配上注解的信息处理流程才有意义。
我们自己定义的注解，只能使用反射的代码读取。所以自定义注解的声明周期 必须是 RetentionPolicy.RUNTIME。

## 一、注解的基础认知

注解（Annotation）本身是一段**元数据**，它不改变程序语义，真正让注解“干活”的是**读取注解的处理器**。按保留策略（`@Retention`
）不同，注解在三个时期可被读取：

| RetentionPolicy | 保留位置                      | 读取者                  |
|-----------------|---------------------------|----------------------|
| `SOURCE`        | 仅源码，编译后丢弃                 | 编译期处理器（APT）、Lombok 等 |
| `CLASS`（**默认**） | 保留在 `.class` 字节码中，运行时不可见  | 字节码工具（ASM、Javassist） |
| `RUNTIME`       | 保留在 `.class` 中，运行时可通过反射读取 | 反射 API、Spring 等框架    |

> ⚠️ 最常见的坑：自定义注解忘了写 `@Retention(RUNTIME)`，结果反射读不到，因为默认是 `CLASS`。

## 二、声明自定义注解

一个完整的注解应该包含三个部分： （1）声明 （2）使用 （3）读取

### 2.1 语法要点

```java
public @interface 注解名 {
    // 属性定义：类型 属性名() default 默认值;
}
```

* 自定义注解可以通过四个元注解@Retention,@Target，@Inherited,@Documented，分别说明它的声明周期，使用位置，是否被继承，是否被生成到 API 文档中。
* Annotation 的成员在 Annotation 定义中以无参数有返回值的抽象方法的形式来声明，我们又称为配置参数。返回值类型只能是八种基本数据类型、String 类型、Class类型、enum 类型、Annotation 类型、以上所有类型的数组
* 可以使用 default 关键字为抽象方法指定默认返回值
* 如果定义的注解含有抽象方法，那么使用时必须指定返回值，除非它有默认值。格式是“方法名 = 返回值”，如果只有一个抽象方法需要赋值，且方法名为 value，可以省略“value=”，所以如果注解只有一个抽象方法成员，建议使用方法名 value。


属性（注解方法）的**合法返回类型**只有：

- 八种基本类型（`int`、`boolean`、`char` …）
- `String`
- `Class`（或 `Class<?>`）
- `enum`
- 其他注解类型
- 以上类型的**一维数组**

不能有参数、不能抛异常、不能用 `null` 作默认值（数组可以用 `{}` 表示空）。

### 2.2 元注解（Annotation on Annotation）

```java
@Retention(RetentionPolicy.RUNTIME)                 // 运行时可读
@Target({ElementType.TYPE, ElementType.METHOD})     // 可修饰的位置
@Documented                                          // 生成 javadoc
@Inherited                                           // 类继承时子类可见（仅类）
@Repeatable(Schedules.class)                         // 可重复标注（Java 8+）
public @interface MyAnnotation {
    String value() default "";                       // 名字为 value 可省略 key
    int priority() default 0;
    Class<?>[] handlers() default {};
    RetentionPolicy policy() default RetentionPolicy.CLASS;
    Nested nested() default @Nested;                 // 嵌套注解需要默认值
}

@interface Nested { String x() default ""; }
```

`@Target` 的常用取值：

| ElementType        | 可修饰                           |
|--------------------|-------------------------------|
| `TYPE`             | 类、接口、枚举、注解                    |
| `FIELD`            | 字段、枚举常量                       |
| `METHOD`           | 方法                            |
| `PARAMETER`        | 形参                            |
| `CONSTRUCTOR`      | 构造器                           |
| `LOCAL_VARIABLE`   | 局部变量                          |
| `ANNOTATION_TYPE`  | 注解类型（用于组合注解）                  |
| `PACKAGE`          | 包（`package-info.java`）        |
| `TYPE_USE`         | 类型使用处（`@NonNull String`、泛型实参） |
| `TYPE_PARAMETER`   | 类型参数（`<@T T>`）                |
| `RECORD_COMPONENT` | record 组件（Java 16+）           |

若省略 `@Target`，则**任何位置都可用**。

## 三、使用注解

```java
@MyAnnotation(value = "demo", priority = 1)
public class Demo {

    @MyAnnotation("methodLevel")          // value 可省略 key
    public void doSomething() {}

    @MyAnnotation(
        priority = 5,
        handlers = {Runnable.class},
        policy = RetentionPolicy.RUNTIME
    )
    public void complex() {}
}
```

- 只有 `value` 一个属性时，可写 `@MyAnnotation("x")`。
- 属性值必须是**编译期常量**（不能是变量）。
- 数组值用 `{}` 包裹，单元素可省略花括号。

## 四、读取注解（反射 API）

所有可被注解的元素（类、方法、字段、构造器、参数……）都实现了 `java.lang.reflect.AnnotatedElement` 接口：

```java
public interface AnnotatedElement {
    boolean isAnnotationPresent(Class<? extends Annotation> annotationClass);
    <T extends Annotation> T getAnnotation(Class<T> annotationClass);
    Annotation[] getAnnotations();
    <T extends Annotation> T[] getAnnotationsByType(Class<T> annotationClass);     // 支持 @Repeatable
    <T extends Annotation> T getDeclaredAnnotation(Class<T> annotationClass);
    Annotation[] getDeclaredAnnotations();
    <T extends Annotation> T[] getDeclaredAnnotationsByType(Class<T> annotationClass);
}
```

### 关键区别

- `getAnnotation(...)`：包含**通过 `@Inherited` 继承来的**类级注解。
- `getDeclaredAnnotation(...)`：只取**本元素直接声明**的。
- `getAnnotationsByType(...)`：是读取 `@Repeatable` 注解的**正确姿势**（`getAnnotation` 只会返回容器）。
- `@Inherited` **只对类继承有效**，对方法、字段、接口实现无效。

### 完整读取示例

```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
@Inherited
@interface Tag { String value(); }

@Retention(RetentionPolicy.RUNTIME)
@Target({ElementType.METHOD, ElementType.FIELD})
@interface Info { String author(); int version() default 1; }

@Tag("base")
class Parent {}

@Info(author = "alice")
class Child extends Parent {
    @Info(author = "bob", version = 2)
    private String name;

    @Info(author = "carol")
    public void work() {}
}

public class ReadDemo {
    public static void main(String[] args) throws Exception {
        Class<?> c = Child.class;

        // 类注解：@Inherited 生效
        System.out.println(c.getAnnotation(Tag.class).value());        // base
        System.out.println(c.getDeclaredAnnotation(Tag.class));        // null

        // 字段
        Field f = c.getDeclaredField("name");
        Info fi = f.getAnnotation(Info.class);
        System.out.println(fi.author() + " v" + fi.version());          // bob v2

        // 方法
        Method m = c.getMethod("work");
        System.out.println(m.getAnnotation(Info.class).author());       // carol

        // 遍历所有注解
        for (Annotation a : c.getAnnotations()) {
            System.out.println(a.annotationType().getName());
        }
    }
}
```

### 读取方法参数上的注解

```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.PARAMETER)
@interface Param { String name(); }

void call(@Param(name = "id") int id, @Param(name = "token") String token) {}

// 读取
Method m = ReadDemo.class.getDeclaredMethod("call", int.class, String.class);
Annotation[][] all = m.getParameterAnnotations();  // [参数索引][注解]
for (int i = 0; i < all.length; i++) {
    for (Annotation a : all[i]) {
        if (a instanceof Param p) {
            System.out.println("参数" + i + " -> " + p.name());
        }
    }
}
```

## 五、处理注解：三种典型方式

### 5.1 运行时反射处理（最常用）

写一个**简易校验框架**，演示“注解定义 + 使用 + 处理器”的完整闭环。

#### ① 定义注解

```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.FIELD)
public @interface NotNull {
    String message() default "不能为 null";
}

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.FIELD)
public @interface Range {
    int min() default Integer.MIN_VALUE;
    int max() default Integer.MAX_VALUE;
    String message() default "数值越界";
}

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.FIELD)
public @interface Length {
    int min() default 0;
    int max() default Integer.MAX_VALUE;
    String message() default "长度不合规";
}
```

#### ② 使用注解

```java
public class User {
    @NotNull(message = "用户名不能为空")
    @Length(min = 3, max = 16, message = "用户名长度需在 3~16 之间")
    private String username;

    @NotNull
    @Range(min = 1, max = 120, message = "年龄需在 1~120")
    private Integer age;

    public User(String username, Integer age) {
        this.username = username;
        this.age = age;
    }
    // getter/setter 略
}
```

#### ③ 反射处理器

```java
public final class Validator {
    public static List<String> validate(Object obj) {
        List<String> errors = new ArrayList<>();
        Class<?> clazz = obj.getClass();
        for (Field field : clazz.getDeclaredFields()) {
            field.setAccessible(true);
            Object value;
            try {
                value = field.get(obj);
            } catch (IllegalAccessException e) {
                throw new RuntimeException(e);
            }

            NotNull notNull = field.getAnnotation(NotNull.class);
            if (notNull != null && value == null) {
                errors.add(field.getName() + ": " + notNull.message());
                continue;                        // 为 null 就不做后续校验
            }
            if (value == null) continue;

            Range range = field.getAnnotation(Range.class);
            if (range != null && value instanceof Integer i
                    && (i < range.min() || i > range.max())) {
                errors.add(field.getName() + ": " + range.message()
                        + " [实际=" + i + "]");
            }

            Length len = field.getAnnotation(Length.class);
            if (len != null && value instanceof CharSequence cs
                    && (cs.length() < len.min() || cs.length() > len.max())) {
                errors.add(field.getName() + ": " + len.message()
                        + " [实际长度=" + cs.length() + "]");
            }
        }
        return errors;
    }
}
```

#### ④ 调用

```java
public class Main {
    public static void main(String[] args) {
        User u = new User("ab", 200);
        Validator.validate(u).forEach(System.out::println);
        // username: 用户名长度需在 3~16 之间 [实际长度=2]
        // age: 年龄需在 1~120 [实际=200]
    }
}
```

> 这就是 Hibernate Validator（JSR-380）的核心思路；Spring 的 `@RequestMapping`、`@Transactional`、`@Autowired`
> 也均是同一套机制（Spring 还额外扫描了 `MergedAnnotations` 以支持元注解组合）。

### 5.2 可重复注解 `@Repeatable`

Java 8 之前不允许同一元素标注多个相同注解；`@Repeatable` 通过“容器注解”实现。

```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
@Repeatable(Schedules.class)
public @interface Schedule {
    String cron();
}

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
public @interface Schedules {
    Schedule[] value();
}
```

使用：

```java
class Job {
    @Schedule(cron = "0 0 1 * * ?")
    @Schedule(cron = "0 0 13 * * ?")
    public void run() {}
}
```

读取（**必须用 `getAnnotationsByType`**）：

```java
Method m = Job.class.getMethod("run");
Schedule[] arr = m.getAnnotationsByType(Schedule.class);
for (Schedule s : arr) {
    System.out.println(s.cron());
}
// 0 0 1 * * ?
// 0 0 13 * * ?
```

如果误用 `m.getAnnotation(Schedule.class)`，在“多个”的情况下会返回 `null`（因为真实存的是 `@Schedules` 容器）。

### 5.3 编译期注解处理器（APT）

用于**代码生成**（如 Lombok、MapStruct、Dagger、Room）。注解一般 `@Retention(SOURCE)` 即可。

```java
@Retention(RetentionPolicy.SOURCE)
@Target(ElementType.TYPE)
public @interface Builder {}
```

处理器：

```java
@SupportedAnnotationTypes("com.example.Builder")
@SupportedSourceVersion(SourceVersion.RELEASE_17)
public class BuilderProcessor extends AbstractProcessor {

    @Override
    public boolean process(Set<? extends TypeElement> annotations,
                           RoundEnvironment roundEnv) {
        for (Element e : roundEnv.getElementsAnnotatedWith(Builder.class)) {
            TypeElement type = (TypeElement) e;
            String pkg = processingEnv.getElementUtils()
                    .getPackageOf(type).getQualifiedName().toString();
            String simple = type.getSimpleName().toString();
            try {
                JavaFileObject file = processingEnv.getFiler()
                        .createSourceFile(pkg + "." + simple + "Builder");
                try (Writer w = file.openWriter()) {
                    w.write("package " + pkg + ";\n");
                    w.write("public class " + simple + "Builder {\n");
                    w.write("  public " + simple + " build() { return new "
                            + simple + "(); }\n");
                    w.write("}\n");
                }
            } catch (IOException ex) {
                processingEnv.getMessager().printMessage(
                        Diagnostic.Kind.ERROR, ex.getMessage(), e);
            }
        }
        return true;
    }
}
```

注册处理器（`src/main/resources/META-INF/services/javax.annotation.processing.Processor`）：

```
com.example.BuilderProcessor
```

Maven 编译时即可自动运行生成源码。若用 `-processor` 命令行参数则可不注册。

### 5.4 组合注解 / 元注解（“注解的注解”）

Spring 大量使用，比如 `@RestController = @Controller + @ResponseBody`。Java **不会自动展开元注解**，需要自己递归：

```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
@interface Service { String name() default ""; }

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
@Service(name = "userService")          // 元注解
@interface UserService {}

// 递归查找元注解
static <A extends Annotation> A findMetaAnnotation(
        AnnotatedElement el, Class<A> type, Set<Class<?>> visited) {
    A direct = el.getAnnotation(type);
    if (direct != null) return direct;
    for (Annotation a : el.getAnnotations()) {
        Class<?> t = a.annotationType();
        if (t == type || !visited.add(t)) continue;
        A found = findMetaAnnotation(t, type, visited);
        if (found != null) return found;
    }
    return null;
}

// 使用
Class<?> c = SomeController.class;
Service s = findMetaAnnotation(c, Service.class, new HashSet<>());
```

> Spring 5.2+ 提供了 `MergedAnnotations`、`AnnotatedElementUtils.findMergedAnnotation(...)` 帮你处理这一层，不必手写递归。

## 六、注意事项与常见坑

1. **默认 `@Retention` 是 `CLASS`**：想运行时反射读，必须写 `@Retention(RUNTIME)`。
2. **`@Inherited` 只对类继承有效**：`class B extends A` 能读到 A 上的注解，`class C implements I` 读不到 I
   上的注解；方法、字段上的注解永不被继承。
3. **`getAnnotation` 与 `getDeclaredAnnotation` 的区别**，如上例。
4. **`@Repeatable` 必须用 `getAnnotationsByType` 读取**，`getAnnotation` 在数量>1 时返回 null。
5. **注解属性不可为 `null`**，需要表达“未设置”时用特殊值（`""`、`-1`、`Void.class`）。
6. **性能**：反射读注解会触发 `AnnotationInvocationHandler` 生成动态代理对象，且 `field.setAccessible(true)` 有安全检查成本。
   **读一次就缓存**（`Map<Class<?>, Meta>`）是框架通行做法；Spring、Jackson、MyBatis 都维护了注解元数据缓存。
7. **模块化（JPMS）影响**：`setAccessible(true)` 对未 `opens` 的模块会抛 `InaccessibleObjectException`
   ，访问第三方库私有成员需配置 `--add-opens`。
8. **注解不能声明为 `null` 返回**，也不能像类一样 `extends`；接口不能继承注解。
9. **不能用基本类型 `int` 的默认值触发拆箱 NPE**（`@Range(min=null)` 不合法）。
10. **`@Target` 缺省等价于“不限制”**——但推荐明确写出，避免误用。

## 七、小结

| 阶段   | 保留策略      | 读取方式                                                 | 典型库                                |
|------|-----------|------------------------------------------------------|------------------------------------|
| 编译期  | `SOURCE`  | APT（`AbstractProcessor`）                             | Lombok、MapStruct                   |
| 字节码期 | `CLASS`   | ASM / Javassist 读 `RuntimeVisibleAnnotations` 之外的常量池 | AspectJ、Spring AOP（部分）             |
| 运行期  | `RUNTIME` | 反射 `AnnotatedElement`                                | Spring、Jackson、Hibernate Validator |

自定义注解使用“声明—标注—读取—处理”四步走：**声明时选好 `@Retention`/`@Target`，使用时属性写常量，读取时用对反射方法，处理时把逻辑写在一个显式的处理器里
**。理解了这一套闭环，Spring、MyBatis、JUnit 这些框架的注解魔法就都变成“显式反射调用”了。
