# Java 方法引用

Java 中方法引用（Method Reference）是 Lambda 表达式的一种简化写法，语法是 `::`。它必须出现在“目标类型”为函数式接口的上下文中，例如赋值给 `Function`、`Consumer`、`Supplier`、`Runnable` 等。

Java 中常见的方法引用主要有以下几类：

| 类型 | 语法 | 等价 Lambda 形式 | 示例 |
|---|---|---|---|
| 静态方法引用 | `类名::静态方法` | `(args) -> 类名.静态方法(args)` | `Integer::parseInt` |
| 特定对象的实例方法引用 | `对象::实例方法` | `(args) -> 对象.实例方法(args)` | `System.out::println` |
| 任意对象的实例方法引用 | `类名::实例方法` | `(obj, args) -> obj.实例方法(args)` | `String::length` |
| 构造器引用 | `类名::new` | `(args) -> new 类名(args)` | `Person::new` |
| 数组构造器引用 | `数组类型::new` | `n -> new 数组类型[n]` | `int[]::new` |
| this/super 变体 | `this::方法`、`super::方法` | `() -> this.方法()`、`() -> super.方法()` | `this::printName` |

下面是一个较完整的示例：

```java
import java.util.ArrayList;
import java.util.function.*;

public class MethodRefDemo {

    static class Person {
        private final String name;

        Person() {
            this("无名");
        }

        Person(String name) {
            this.name = name;
        }

        static int compareByName(Person a, Person b) {
            return a.name.compareTo(b.name);
        }

        String getName() {
            return name;
        }

        void printName() {
            System.out.println("Person: " + name);
        }
    }

    static class Student extends Person {
        Student() {
            super("学生");
        }

        @Override
        void printName() {
            System.out.println("Student: " + getName());
        }

        void testThis() {
            // this::实例方法
            Runnable r = this::printName;
            r.run();
        }

        void testSuper() {
            // super::实例方法
            Runnable r = super::printName;
            r.run();
        }
    }

    public static void main(String[] args) {

        // 1. 静态方法引用
        Function<String, Integer> parse = Integer::parseInt;
        BiFunction<Integer, Integer, Integer> sum = Integer::sum;
        System.out.println(parse.apply("123")); // 123
        System.out.println(sum.apply(1, 2));    // 3

        // 2. 特定对象的实例方法引用
        Person p = new Person("Tom");
        Runnable printP = p::printName;
        printP.run(); // Person: Tom

        Consumer<String> println = System.out::println;
        println.accept("hello"); // hello

        // 3. 任意对象的实例方法引用
        // String::length 等价于 s -> s.length()
        Function<String, Integer> length = String::length;
        System.out.println(length.apply("abc")); // 3

        // Person::getName 等价于 person -> person.getName()
        Function<Person, String> getName = Person::getName;
        System.out.println(getName.apply(p)); // Tom

        // String::equals 等价于 (a, b) -> a.equals(b)
        BiPredicate<String, String> equals = String::equals;
        System.out.println(equals.test("a", "a")); // true

        // 4. 构造器引用
        Supplier<Person> newPerson = Person::new;
        Function<String, Person> newPersonWithName = Person::new;
        Supplier<ArrayList<String>> newList = ArrayList::new;

        System.out.println(newPerson.get().getName());       // 无名
        System.out.println(newPersonWithName.apply("Jerry").getName()); // Jerry
        System.out.println(newList.get().size());            // 0

        // 5. 数组构造器引用
        IntFunction<int[]> newIntArray = int[]::new;
        IntFunction<String[]> newStringArray = String[]::new;

        System.out.println(newIntArray.apply(3).length);    // 3
        System.out.println(newStringArray.apply(4).length); // 4

        // 6. this:: 和 super::
        new Student().testThis();  // Student: 学生
        new Student().testSuper(); // Person: 学生
    }
}
```

需要特别注意：

1. `类名::实例方法` 不是静态方法引用。例如 `String::length` 等价于 `s -> s.length()`，第一个参数作为方法接收者。
2. `对象::实例方法` 中接收者对象是固定的，例如 `System.out::println`。
3. 构造器引用 `类名::new` 会根据目标函数式接口的参数选择对应构造器。
4. 数组构造器引用 `int[]::new` 等价于 `n -> new int[n]`。
5. 方法引用必须有目标类型，不能单独存在；如果出现重载歧义，可以改用显式 Lambda 或进行类型转换。
