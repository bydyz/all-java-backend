构造器引用是 Java 方法引用的一种，语法形式为：

```java
类型::new
```

它用于**函数式接口**，调用该接口方法时创建对象。编译器根据目标函数式接口的参数列表和返回类型，匹配对应的构造器。常见形式包括：无参构造器、有参构造器、多参构造器、数组构造器、泛型类构造器、泛型构造器、非静态内部类构造器引用等。

---

## 1. 常见构造器引用形式

| 形式 | 示例 | 说明 |
|---|---|---|
| 无参构造器 | `Supplier<Person> s = Person::new;` | 匹配 `Person()` |
| 单参构造器 | `Function<String, Person> f = Person::new;` | 匹配 `Person(String)` |
| 双参构造器 | `BiFunction<String,Integer,Person> f = Person::new;` | 匹配 `Person(String,Integer)` |
| 多参构造器 | `TriFunction<A,B,C,R> f = Xxx::new;` | 需自定义函数式接口 |
| 数组构造器 | `IntFunction<String[]> f = String[]::new;` | 等价 `n -> new String[n]` |
| 泛型类构造器 | `Function<String, Box<String>> f = Box<String>::new;` | 指定泛型类型 |
| 泛型构造器 | `GenericCtor::<String>new` | 显式指定构造器类型参数，较少用 |
| 非静态内部类构造器 | `BiFunction<Outer,String,Outer.Inner> f = Outer.Inner::new;` | 第一个参数是外部类实例 |

---

## 2. 综合代码示例

```java
import java.util.function.*;

class Person {
    private String name;
    private Integer age;

    public Person() {
        this("unknown", 0);
    }

    public Person(String name) {
        this(name, 0);
    }

    public Person(String name, Integer age) {
        this.name = name;
        this.age = age;
    }

    @Override
    public String toString() {
        return name + ":" + age;
    }
}

@FunctionalInterface
interface TriFunction<A, B, C, R> {
    R apply(A a, B b, C c);
}

class Triple {
    public Triple(String a, Integer b, Boolean c) {
        System.out.println("Triple: " + a + ", " + b + ", " + c);
    }
}

class Box<T> {
    private T value;

    public Box(T value) {
        this.value = value;
    }
}

class GenericCtor {
    public <T> GenericCtor(T value) {
        System.out.println("GenericCtor: " + value);
    }
}

class Outer {
    class Inner {
        public Inner(String s) {
            System.out.println("Inner: " + s);
        }
    }
}

public class ConstructorRefDemo {
    public static void main(String[] args) {
        // 1. 无参构造器引用：Person()
        Supplier<Person> s = Person::new;
        Person p0 = s.get();
        System.out.println(p0);

        // 2. 单参构造器引用：Person(String)
        Function<String, Person> f1 = Person::new;
        Person p1 = f1.apply("Alice");
        System.out.println(p1);

        // 3. 双参构造器引用：Person(String, Integer)
        BiFunction<String, Integer, Person> f2 = Person::new;
        Person p2 = f2.apply("Bob", 20);
        System.out.println(p2);

        // 4. 多参构造器引用：需要自定义函数式接口
        TriFunction<String, Integer, Boolean, Triple> f3 = Triple::new;
        f3.apply("A", 1, true);

        // 5. 数组构造器引用
        IntFunction<String[]> arr1 = String[]::new;
        String[] strings = arr1.apply(3); // 等价 new String[3]
        System.out.println("strings.length = " + strings.length);

        IntFunction<int[]> arr2 = int[]::new;
        int[] ints = arr2.apply(5); // 等价 new int[5]
        System.out.println("ints.length = " + ints.length);

        // 二维数组：创建第一维长度为 2 的 int[2][]
        IntFunction<int[][]> arr3 = int[][]::new;
        int[][] matrix = arr3.apply(2);
        System.out.println("matrix.length = " + matrix.length);

        // 6. 泛型类构造器引用
        Function<String, Box<String>> boxFactory1 = Box<String>::new;
        Box<String> box1 = boxFactory1.apply("hello");

        // 也可以由目标类型推断
        Function<String, Box<String>> boxFactory2 = Box::new;
        Box<String> box2 = boxFactory2.apply("world");

        // 7. 泛型构造器引用
        Function<String, GenericCtor> gc1 = GenericCtor::new;
        gc1.apply("推断类型参数");

        // 显式指定泛型构造器类型参数，语法为 Class::<T>new
        Function<String, GenericCtor> gc2 = GenericCtor::<String>new;
        gc2.apply("显式类型参数");

        // 8. 非静态内部类构造器引用
        // Inner(String) 是非静态内部类构造器，隐式需要 Outer 实例
        BiFunction<Outer, String, Outer.Inner> innerFactory = Outer.Inner::new;
        Outer outer = new Outer();
        Outer.Inner inner = innerFactory.apply(outer, "inner value");
    }
}
```

## 3. 使用注意点

1. **构造器引用必须有目标函数式接口**
   例如下面写法不合法，因为无法确定匹配哪个构造器：

   ```java
   // var f = Person::new; // 编译错误：需要目标类型
   ```

2. **重载构造器由目标函数式接口决定**
   `Person::new` 在 `Supplier<Person>` 中匹配无参构造器；在 `Function<String, Person>` 中匹配单参构造器。

3. **数组构造器引用**
   `String[]::new` 等价于 `n -> new String[n]`；`int[][]::new` 等价于 `n -> new int[n][]`。

4. **非静态内部类构造器引用**
   非静态内部类构造器隐含外部类实例参数，因此函数式接口通常需要把 `Outer` 作为第一个参数。

5. **访问权限限制**
   构造器引用只能引用当前上下文中可访问的构造器，私有构造器只能在所属类内部引用。

6. **抽象类和接口不能直接实例化**
   构造器引用本质上会调用 `new` 创建实例，因此通常用于可实例化的类；接口没有构造器，抽象类不能直接实例化。
