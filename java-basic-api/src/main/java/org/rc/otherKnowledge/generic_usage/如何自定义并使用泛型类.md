# Java 泛型类：自定义与使用详解

## 一、概念铺垫

**泛型类**：在类名后声明**类型参数**（Type Parameter），让类在定义时不绑定具体类型，而是在**使用时**由调用方指定类型。

核心价值：
- **类型安全**：编译期检查，避免 `ClassCastException`
- **代码复用**：一套逻辑适配多种类型
- **可读性**：`Box<String>` 比 `Object` + 强制转换更清晰

语法骨架：

```
[修饰符] class 类名<类型参数列表> [extends 父类] [implements 接口] { ... }
```

类型参数命名惯例：`T`(Type)、`E`(Element)、`K`/`V`(Key/Value)、`R`(Result)、`U`/`S`(第二、第三类型)。

## 二、第一个完整的泛型类

```java
import java.util.function.Function;

public class Box<T> {

    private T content;                 // 成员变量使用类型参数

    public Box() {}

    public Box(T content) {            // 构造器使用类型参数
        this.content = content;
    }

    public T getContent() {            // 返回值使用类型参数
        return content;
    }

    public void setContent(T content) {// 参数使用类型参数
        this.content = content;
    }

    // 泛型类中再定义泛型方法：U 是本方法自己声明的类型参数
    public <U> Box<U> map(Function<? super T, ? extends U> mapper) {
        return new Box<>(mapper.apply(content));
    }

    @Override
    public String toString() {
        return "Box[" + content + "]";
    }
}
```

要点：
- `T` 在整个类体内可见，相当于"占位类型"。
- `T` 不是静态字段，每个实例的 `T` 由**使用时的类型实参**决定。
- `map` 方法里的 `<U>` 是**方法级**类型参数，与类级 `T` 相互独立。

## 三、使用泛型类

### 3.1 显式指定类型实参

```java
Box<String> sb = new Box<>("hello");   // 菱形运算符 <> 由编译器推断
String s = sb.getContent();            // 无需强转

Box<Integer> ib = new Box<>(100);      // 100 自动装箱为 Integer
int n = ib.getContent();               // 自动拆箱

// 组合使用
Box<String> upper = sb.map(String::toUpperCase);
System.out.println(upper);             // Box[HELLO]
```

### 3.2 Java 10+ 用 `var` 简化

```java
var box = new Box<String>("hi");       // 推断为 Box<String>
```

### 3.3 基本类型不能作为类型实参

```java
// Box<int> b;   // 编译错误
Box<Integer> b = new Box<>(1);          // 必须用包装类
```

### 3.4 泛型类不能存放"不同类型混用"的值

```java
Box<String> b = new Box<>();
b.setContent("a");
// b.setContent(123);  // 编译错误，这正是类型安全的价值
```

## 四、多类型参数

```java
public class Pair<K, V> {

    private final K key;
    private final V value;

    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }

    public K getKey()   { return key; }
    public V getValue() { return value; }

    // 静态工厂方法：静态方法不能使用类级类型参数，需自己声明
    public static <K, V> Pair<K, V> of(K key, V value) {
        return new Pair<>(key, value);
    }

    // 交换键值，返回新的类型组合
    public Pair<V, K> swap() {
        return new Pair<>(value, key);
    }

    @Override
    public String toString() {
        return "(" + key + ", " + value + ")";
    }
}
```

使用：

```java
Pair<String, Integer> p = Pair.of("age", 18);
System.out.println(p);                 // (age, 18)
System.out.println(p.swap());          // (18, age)  —— 类型变为 Pair<Integer, String>
```

## 五、有界类型参数（Bounded Type Parameter）

限定 `T` 必须是某类/接口的子类型，从而**可以调用边界类型的方法**。

```java
// T 必须是 Number 的子类，且实现 Comparable<T>
public class NumberBox<T extends Number & Comparable<T>> {

    private T value;

    public NumberBox(T value) { this.value = value; }

    public double asDouble() {
        return value.doubleValue();          // Number 提供的方法
    }

    public boolean isGreaterThan(T other) {
        return value.compareTo(other) > 0;   // Comparable 提供的方法
    }

    // 静态泛型方法同样可以有界
    public static <N extends Number> double sum(N a, N b) {
        return a.doubleValue() + b.doubleValue();
    }
}
```

```java
NumberBox<Integer> a = new NumberBox<>(10);
NumberBox<Integer> b = new NumberBox<>(20);
System.out.println(a.isGreaterThan(b.getValue()));  // false
System.out.println(NumberBox.sum(1.5, 2.5));        // 4.0
```

> 注意：多个上界时，**类必须写在第一个**，且最多一个类；`&` 连接接口。

## 六、泛型类的继承

### 6.1 子类固定类型实参

```java
public class StringBox extends Box<String> {
    public StringBox(String s) { super(s); }

    public int length() { return getContent().length(); }  // 已确定是 String
}
```

### 6.2 子类继续泛型

```java
public class SubBox<T> extends Box<T> {
    public SubBox(T c) { super(c); }
}

// 也可以扩展类型参数
public class LabeledBox<T, L> extends Box<T> {
    private final L label;
    public LabeledBox(T content, L label) {
        super(content);
        this.label = label;
    }
    public L getLabel() { return label; }
}
```

### 6.3 实现泛型接口

```java
public interface Repository<T, ID> {
    T findById(ID id);
    void save(T entity);
}

// 方式一：实现时确定类型
public class UserRepository implements Repository<User, Long> {
    @Override public User findById(Long id) { /* ... */ return new User(); }
    @Override public void save(User entity)  { /* ... */ }
}

// 方式二：实现时保留泛型
public class InMemoryRepository<T, ID> implements Repository<T, ID> {
    private final Map<ID, T> store = new HashMap<>();
    @Override public T findById(ID id)      { return store.get(id); }
    @Override public void save(T entity)    { /* 略 */ }
}
```

## 七、泛型类中的静态成员限制

因为类型擦除，**类级类型参数在静态上下文中不可用**：

```java
public class Box<T> {

    // private static T instance;          // ❌ 编译错误
    // public static T create() { ... }    // ❌ 编译错误
    // public static void f(T t) { ... }   // ❌ 编译错误

    // ✅ 静态方法自己声明类型参数，则没问题
    public static <U> Box<U> empty(U defaultValue) {
        return new Box<>(defaultValue);
    }

    // ✅ 静态常量也不能依赖 T
    private static final int CAPACITY = 16;
}
```

## 八、泛型类与通配符配合

通配符 `?` 常用于**方法参数**，让方法能接收"一系列"具体泛型类型。

```java
public class BoxUtil {

    // 只读场景：任何 Box<?> 都能传入
    public static void print(Box<?> box) {
        Object o = box.getContent();   // 只能当 Object 读
        System.out.println(o);
        // box.setContent("x");        // ❌ 不能写，因为不知道具体是哪个 T
    }

    // 协变读取：只接收 Number 及其子类
    public static double sum(Box<? extends Number> b1, Box<? extends Number> b2) {
        return b1.getContent().doubleValue() + b2.getContent().doubleValue();
    }

    // 逆变写入：可以接收 Integer 的父类容器
    public static void fillZero(Box<? super Integer> box) {
        box.setContent(0);             // ✅ 可写
    }

    // 典型"拷贝"场景，符合 PECS 原则
    public static <T> void copy(Box<? extends T> src, Box<? super T> dst) {
        dst.setContent(src.getContent());
    }
}
```

调用示例：

```java
Box<Integer> ai = new Box<>(1);
Box<Double>  ad = new Box<>(2.5);
System.out.println(BoxUtil.sum(ai, ad));   // 3.5

Box<Number> target = new Box<>();
BoxUtil.fillZero(target);                   // target = Box[0]

Box<Object> objBox = new Box<>();
BoxUtil.copy(ai, objBox);                   // objBox = Box[1]
```

**PECS 记忆法**：Producer → `extends`，Consumer → `super`。

## 九、泛型方法 vs 泛型类

| 对比点 | 泛型类 | 泛型方法 |
|---|---|---|
| 类型参数作用域 | 整个类 | 仅该方法 |
| 声明位置 | `class Box<T>` | `public <T> T f(T t)` |
| 静态方法能否使用 | 不能使用类级 T | 自己声明的 T 可以 |
| 使用场景 | 数据载体、容器 | 通用工具方法 |

泛型类中结合泛型方法示例：

```java
public class Converter<T> {
    private final T value;
    public Converter(T value) { this.value = value; }

    // 方法级泛型参数 R，与类级 T 独立
    public <R> R to(Function<? super T, ? extends R> f) {
        return f.apply(value);
    }
}
```

```java
Converter<String> c = new Converter<>("42");
Integer i = c.to(Integer::valueOf);   // R 推断为 Integer
```

## 十、类型擦除与常见陷阱

**擦除**：编译后类型参数被擦除为其**第一个上界**（默认 `Object`），因此：

```java
Box<String> a = new Box<>("x");
Box<Integer> b = new Box<>(1);
System.out.println(a.getClass() == b.getClass());  // true，都是 Box.class
```

由此产生 **四大禁区**：

```java
public class Bad<T> {

    // 1. 不能 new T()
    // public T create() { return new T(); }   ❌

    // 2. 不能 new T[10]
    // T[] arr = new T[10];                    ❌

    // 3. 不能对 T 做 instanceof
    // if (t instanceof String) { }            ❌

    // 4. 不能定义两个"擦除后相同"的重载
    // void f(Box<String> b) {}
    // void f(Box<Integer> b) {}               ❌
}
```

**绕过方式 1：传入 `Class<T>` 做运行时检查**

```java
public class TypeSafeBox<T> {
    private final Class<T> type;
    private T content;

    public TypeSafeBox(Class<T> type) { this.type = type; }

    public void set(T t) {
        if (!type.isInstance(t)) {
            throw new IllegalArgumentException("类型不符");
        }
        this.content = t;
    }

    public T get() { return content; }

    // 用 Class 辅助创建数组也是可行手段
    @SuppressWarnings("unchecked")
    public T[] newArray(int size) {
        return (T[]) java.lang.reflect.Array.newInstance(type, size);
    }
}
```

**绕过方式 2：通过反射读取泛型信息（框架常用）**

```java
public class GenericReader<T> {
    public Class<?> read() throws Exception {
        ParameterizedType t = (ParameterizedType) getClass().getGenericSuperclass();
        return (Class<?>) t.getActualTypeArguments()[0];
    }
}
// class IntReader extends GenericReader<Integer> {}
// new IntReader().read();   // => class java.lang.Integer
```

## 十一、综合实战：泛型 Result 容器

```java
import java.util.function.Function;

public class Result<T> {

    private final boolean success;
    private final T data;
    private final String error;

    private Result(boolean success, T data, String error) {
        this.success = success;
        this.data = data;
        this.error = error;
    }

    public static <T> Result<T> ok(T data) {
        return new Result<>(true, data, null);
    }

    public static <T> Result<T> fail(String error) {
        return new Result<>(false, null, error);
    }

    public boolean isSuccess() { return success; }
    public T getData()         { return data; }
    public String getError()   { return error; }

    // 链式转换，失败时短路
    public <R> Result<R> map(Function<? super T, ? extends R> f) {
        if (!success) {
            return Result.fail(error);
        }
        return Result.ok(f.apply(data));
    }

    public T orElse(T fallback) {
        return success ? data : fallback;
    }

    @Override
    public String toString() {
        return success ? "Result.ok(" + data + ")" : "Result.fail(" + error + ")";
    }

    public static void main(String[] args) {
        Result<String> r1 = Result.ok("123");
        Result<Integer> r2 = r1.map(Integer::parseInt);       // Result.ok(123)

        Result<String> r3 = Result.<String>fail("boom");
        Result<Integer> r4 = r3.map(Integer::parseInt);       // 仍是 fail

        System.out.println(r2);                // Result.ok(123)
        System.out.println(r4.getData());      // null
        System.out.println(r4.orElse(-1));     // -1
    }
}
```

## 十二、自定义泛型类的最佳实践清单

1. **优先窄化类型**：能写成 `Box<T>` 就不要用 `Object` + 强转。
2. **命名规范**：单字母大写，`T`、`E`、`K`、`V`、`R`，不混用。
3. **用 `extends` 边界换取能力**：需要在内部调用某方法时（如 `compareTo`、`doubleValue`），必须写边界。
4. **方法参数用通配符**（PECS），**不要用通配符定义类**（`class Box<?>` 非法）。
5. **静态成员需自声明类型参数**：`static <U> ...`。
6. **不要用泛型构造"不可变共享"的 API 返回 `Object`**：直接返回 `T`。
7. **绕过类型擦除前想清楚是否必须**：能用 `Class<T>` 就优先于反射。
8. **公开 API 尽量避免裸类型**：`Box` 裸用会丢失类型检查，只在不得已（如遗留代码）时使用并 `@SuppressWarnings("rawtypes")`。

---

## 结语

自定义泛型类本质是"**在类型层面做参数化**"：类名后声明 `<T>`，在字段、构造器、方法签名中自由使用；使用时给出具体实参或由编译器推断。真正把泛型用好的关键，是掌握**边界（extends）**、**通配符（? extends / ? super）**与**类型擦除**这三件事，再结合 `Class<T>` 或反射处理运行时类型需求。
