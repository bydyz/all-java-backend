# Java 父类引用指向子类对象的多态详解

## 关键

**此处的 父类 只要满足 子类对象 instanceof 父类 === true 即可**

## 一、核心概念

**多态（Polymorphism）** 是面向对象三大特性之一。在 Java 中，最典型的多态形式就是：

```java
父类类型 引用变量 = new 子类对象();
```

这种写法叫 **向上转型（Upcasting）**，它是多态的前提。核心规则是：

> **编译时看左边（父类），运行时看右边（子类）。**
> —— 编译时只能调用父类中声明的方法，运行时实际执行的是子类重写后的方法。

> Java 引用变量有两个类型：编译时类型和运行时类型。编译时类型由声明该变量时使用的类型决定，运行时类型由实际赋给该变量的对象决定。简称：编译时，看左边；运行时，看右边。

> 编译时看父类：只能调用父类声明的方法，不能调用子类扩展的方法；运行时，看“子类”，如果子类重写了方法，一定是执行子类重写的方法体，否则执行父类的；

## 二、基础代码示例

```java
// 父类
class Animal {
    public void makeSound() {
        System.out.println("动物发出叫声");
    }

    public void eat() {
        System.out.println("动物在吃东西");
    }
}

// 子类 Dog
class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("汪汪汪");
    }

    // 子类特有方法
    public void wagTail() {
        System.out.println("狗摇尾巴");
    }
}

// 子类 Cat
class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("喵喵喵");
    }
}

public class PolymorphismDemo {
    public static void main(String[] args) {
        // 父类引用指向子类对象
        Animal a1 = new Dog();
        Animal a2 = new Cat();

        // 调用的是子类重写的方法（运行时决定）
        a1.makeSound();   // 输出：汪汪汪
        a2.makeSound();   // 输出：喵喵喵

        // 调用父类未被子类重写的方法，执行父类版本
        a1.eat();         // 输出：动物在吃东西

        // 编译错误！父类引用无法调用子类特有方法
        // a1.wagTail();  // ❌ Cannot resolve method 'wagTail()'
    }
}
```

**关键点说明：**

| 调用内容          | 编译期依据    | 运行期依据 | 结果     |
|---------------|----------|-------|--------|
| `makeSound()` | 父类有该方法 ✔ | 子类重写了 | 执行子类版本 |
| `eat()`       | 父类有该方法 ✔ | 子类未重写 | 执行父类版本 |
| `wagTail()`   | 父类无该方法 ✘ | —     | 编译报错   |

## 三、多态的实现原理：动态绑定（Dynamic Binding）

Java 方法调用分两种：

- **静态绑定（编译期）**：`static`、`private`、`final` 方法，构造方法 —— 编译时就确定调用哪个方法。
- **动态绑定（运行期）**：普通实例方法 —— 运行时根据对象的**实际类型**决定调用哪个方法。

**JVM 层面（简要）：** 类加载时，每个类的方法区中保存有**虚方法表（vtable）**
，子类重写的方法会替换父类方法表中对应位置。运行时调用 `a1.makeSound()`，通过 `a1`
指向对象的实际类型去查虚方法表，从而执行 `Dog.makeSound()`。

```java
// 演示动态绑定的过程
Animal a = new Dog();
//   ↑          ↑
// 声明类型    实际类型（运行时类型）
// (Animal)    (Dog)

// JVM 执行 makeSound() 时：
// 1. 取 a 实际指向对象的类型 → Dog
// 2. 在 Dog 的虚方法表中查找 makeSound() → Dog.makeSound()
// 3. 执行 Dog.makeSound()
```

## 四、多态能"作用"和"不能作用"的成员

这是考试/面试高频考点，用一个完整示例说明：

```java
class Parent {
    // 1. 成员变量：不具备多态性
    public String name = "父类变量";

    // 2. 普通实例方法：具备多态性（可被重写）
    public void normalMethod() {
        System.out.println("父类普通方法");
    }

    // 3. 静态方法：不具备多态性（按引用类型绑定）
    public static void staticMethod() {
        System.out.println("父类静态方法");
    }

    // 4. private 方法：不能被重写，无多态
    private void privateMethod() {
        System.out.println("父类私有方法");
    }

    // 5. final 方法：不能被重写，无多态
    public final void finalMethod() {
        System.out.println("父类final方法");
    }

    // 提供调用 private 方法的入口
    public void callPrivate() {
        privateMethod();
    }
}

class Child extends Parent {
    public String name = "子类变量";

    @Override
    public void normalMethod() {
        System.out.println("子类普通方法");
    }

    // @Override 会报错，静态方法不是重写而是隐藏
    public static void staticMethod() {
        System.out.println("子类静态方法");
    }

    // 这不是重写，是子类新定义的方法
    public void privateMethod() {
        System.out.println("子类同名方法（非重写）");
    }
}

public class MemberTest {
    public static void main(String[] args) {
        Parent p = new Child();

        // 1. 成员变量：编译看左边，运行也看左边（父类）
        System.out.println(p.name);           // 输出：父类变量

        // 2. 普通方法：编译看左边，运行看右边（子类）
        p.normalMethod();                     // 输出：子类普通方法

        // 3. 静态方法：编译看左边，运行也看左边（父类）
        p.staticMethod();                     // 输出：父类静态方法

        // 4. private 方法：由父类入口调用，执行父类版本
        p.callPrivate();                      // 输出：父类私有方法

        // 5. final 方法：执行父类版本
        p.finalMethod();                      // 输出：父类final方法

        // 子类对象引用访问（对照）
        Child c = new Child();
        System.out.println(c.name);           // 输出：子类变量
        c.staticMethod();                     // 输出：子类静态方法
    }
}
```

**记忆口诀：**

> - **成员变量**：编译看左，运行看左（没有多态）
> - **普通方法**：编译看左，运行看右（多态生效）
> - **静态方法**：编译看左，运行看左（没有多态）

## 五、多态的实际应用价值

多态的威力在于：**面向抽象编程**，调用方只依赖父类/接口，新增子类无需修改调用代码。

```java
abstract class Shape {
    public abstract double area();

    public void describe() {
        System.out.printf("%s 的面积为 %.2f%n", getClass().getSimpleName(), area());
    }
}

class Circle extends Shape {
    private double r;
    public Circle(double r) { this.r = r; }
    @Override public double area() { return Math.PI * r * r; }
}

class Rectangle extends Shape {
    private double w, h;
    public Rectangle(double w, double h) { this.w = w; this.h = h; }
    @Override public double area() { return w * h; }
}

class Triangle extends Shape {
    private double base, height;
    public Triangle(double base, double height) {
        this.base = base;
        this.height = height;
    }
    @Override public double area() { return 0.5 * base * height; }
}

public class ShapeDemo {
    // 统一的处理入口：只依赖父类 Shape
    public static void printAll(Shape[] shapes) {
        for (Shape s : shapes) {
            s.describe();   // 多态调用 area()
        }
    }

    public static void main(String[] args) {
        Shape[] shapes = {
            new Circle(2),
            new Rectangle(3, 4),
            new Triangle(4, 5)
        };
        printAll(shapes);
        // Circle 的面积为 12.57
        // Rectangle 的面积为 12.00
        // Triangle 的面积为 10.00
    }
}
```

**如果没有多态**，`printAll` 需要写一堆 `if (s instanceof Circle) ... else if ...`，而且每新增一种形状都要修改这个函数，违反
**开闭原则**。

## 六、向上转型与向下转型

### 1. 向上转型（自动完成）

```java
Animal a = new Dog();   // 自动，安全
```

### 2. 向下转型（需要强制转换 + 类型检查）

```java
Animal a = new Dog();

// 正确：Dog 转回 Dog
Dog d = (Dog) a;
d.wagTail();            // ✔ 可以调用子类特有方法

// 错误：Dog 对象不能转成 Cat（运行时抛异常）
// Cat c = (Cat) a;     // ❌ ClassCastException

// 安全做法：先用 instanceof 判断
if (a instanceof Dog) {
    Dog dog = (Dog) a;
    dog.wagTail();
}

// Java 16+ 模式匹配写法
if (a instanceof Dog dog) {
    dog.wagTail();
}
```

### 3. 为什么需要向下转型？

因为父类引用**编译期无法看到**子类特有方法，若确实需要调用，须转回子类类型：

```java
Animal[] animals = { new Dog(), new Cat(), new Dog() };
for (Animal a : animals) {
    a.makeSound();
    if (a instanceof Dog dog) {
        dog.wagTail();   // 需要子类特有行为时才向下转型
    }
}
```

## 七、多态与重载（Overload）的区别

| 维度   | 重写 Override   | 重载 Overload        |
|------|---------------|--------------------|
| 发生位置 | 父子类之间         | 同一个类中              |
| 方法签名 | 相同（返回类型协变）    | 参数列表不同             |
| 绑定时机 | **运行时**（动态绑定） | **编译时**（静态绑定）      |
| 是否多态 | **是多态的核心**    | 属于"编译时多态"（本质是静态分派） |

```java
class OverloadDemo {
    void print(Animal a) { System.out.println("Animal 参数"); }
    void print(Dog d)     { System.out.println("Dog 参数"); }

    public static void main(String[] args) {
        OverloadDemo demo = new OverloadDemo();
        Animal a = new Dog();
        demo.print(a);      // 输出：Animal 参数（编译期按声明类型 Animal 选择）
        demo.print((Dog)a); // 输出：Dog 参数
    }
}
```

> 注意：重载方法的选择是**编译期**根据引用变量的**静态类型**决定的，与重写"运行期看实际类型"截然不同。

## 八、常见陷阱

### 陷阱 1：构造方法中调用可重写方法

```java
class Parent {
    Parent() {
        init();   // ⚠️ 多态在这里会"出问题"
    }
    void init() {
        System.out.println("Parent.init");
    }
}

class Child extends Parent {
    private int value = 42;
    @Override
    void init() {
        // 此时 value 还未初始化，仍是 0！
        System.out.println("Child.init, value = " + value);
    }
}

new Child();
// 输出：Child.init, value = 0
```

**原因**：`new Child()` 时先执行父类构造方法，此时子类字段 `value` 尚未赋值，但多态让 `init()` 调用到了子类版本，造成"
半初始化"状态。**结论：构造方法中不要调用可重写方法。**

### 陷阱 2：成员变量的"隐藏"

```java
class A { String s = "A"; }
class B extends A { String s = "B"; }

A obj = new B();
System.out.println(obj.s);   // 输出：A   （成员变量按声明类型）
```

### 陷阱 3：不要混淆 `instanceof` 的 null 行为

```java
Animal a = null;
System.out.println(a instanceof Dog);   // false，不会 NPE
```

### 陷阱 4：静态方法"隐藏"不是"重写"

```java
Parent p = new Child();
p.staticMethod();   // 输出：父类静态方法
```

虽然可以用子类对象调用静态方法，但实际绑定的是**引用的声明类型**（`Parent`），因此这里始终输出父类版本。

## 九、总结

```mermaid
graph TD
    A[Animal a = new Dog()] --> B[编译期: 只能调用 Animal 中定义的方法]
    A --> C[运行期: 实际执行 Dog 中重写的方法]
    B --> D[普通方法 ✔]
    B --> E[静态方法 ✔ 但按父类绑定]
    B --> F[成员变量 ✔ 按父类绑定]
    B --> G[子类特有方法 ✘ 编译报错]
```

**核心要点回顾：**

1. **前提**：必须存在**继承** + **方法重写**，然后用**父类引用指向子类对象**。
2. **本质**：动态绑定 —— 运行时根据对象实际类型决定方法版本。
3. **能多态的**：普通实例方法（被重写）。
4. **不能多态的**：成员变量、静态方法、private/final 方法、构造方法。
5. **价值**：面向抽象编程，提高扩展性，符合开闭原则。
6. **配套技巧**：`instanceof` + 向下转型访问子类特有成员；避免在构造方法中调用可重写方法。
