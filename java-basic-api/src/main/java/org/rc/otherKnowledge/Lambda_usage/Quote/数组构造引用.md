# Java 数组构造引用说明

如果你说的“数组构造引用”是 Java 8 方法引用中的 **数组构造器引用 / Array Constructor Reference**，它的典型形式是：

```java
类型[]::new
```

含义等价于一个 lambda：`length -> new 类型[length]`。常用于需要“根据长度创建数组”的函数式接口，例如 `IntFunction<T[]>`、`Stream.toArray(String[]::new)` 等。

## 1. 基本类型数组构造引用

```java
import java.util.function.IntFunction;

IntFunction<int[]> creator = int[]::new;
int[] arr = creator.apply(4); // 创建长度为 4 的 int 数组

// 等价于：
IntFunction<int[]> creator2 = length -> new int[length];
```

`new int[4]` 的元素默认值是 `0`。

## 2. 引用类型数组构造引用

```java
import java.util.function.IntFunction;

IntFunction<String[]> creator = String[]::new;
String[] arr = creator.apply(3); // 创建长度为 3 的 String 数组

// 元素默认值为 null
```

## 3. 常见用法：Stream 转数组

```java
import java.util.stream.Stream;

String[] arr = Stream.of("a", "b", "c")
                     .toArray(String[]::new);

System.out.println(arr.length); // 3
```

这里 `String[]::new` 等价于：

```java
length -> new String[length]
```

## 4. 作为方法参数：泛型数组工厂

```java
import java.util.function.IntFunction;

public class ArrayFactoryDemo {
    static <T> T[] createArray(IntFunction<T[]> factory, int length) {
        return factory.apply(length);
    }

    public static void main(String[] args) {
        String[] strings = createArray(String[]::new, 2);
        Integer[] integers = createArray(Integer[]::new, 3);

        System.out.println(strings.length); // 2
        System.out.println(integers.length); // 3
    }
}
```

## 5. 多维数组构造引用

`int[][]::new` 创建的是“外层数组”，等价于 `length -> new int[length][]`，内层元素默认为 `null`。

```java
import java.util.function.IntFunction;

IntFunction<int[][]> creator = int[][]::new;
int[][] matrix = creator.apply(3);

System.out.println(matrix.length); // 3
System.out.println(matrix[0]);     // null
```

如果要创建规则二维数组 `new int[rows][cols]`，不能用 `int[][]::new` 直接表达，应使用 lambda：

```java
import java.util.function.BiFunction;

BiFunction<Integer, Integer, int[][]> creator =
        (rows, cols) -> new int[rows][cols];

int[][] matrix = creator.apply(2, 3); // 等价于 new int[2][3]
```

或者固定列数：

```java
import java.util.function.IntFunction;

IntFunction<int[][]> creator = rows -> new int[rows][4];
int[][] matrix = creator.apply(3); // 3 行 4 列
```

## 6. 限制与注意事项

### 6.1 只能表达“按长度创建空数组”

```java
IntFunction<int[]> creator = int[]::new;
int[] a = creator.apply(3); // 可以：new int[3]
```

不能直接表达带初始元素的数组：

```java
// 不能写成 int[]::new 来产生 {1, 2, 3}
```

带初始元素要用 lambda：

```java
import java.util.function.Supplier;

Supplier<int[]> supplier = () -> new int[]{1, 2, 3};
int[] arr = supplier.get();
```

### 6.2 类型必须匹配

```java
import java.util.function.IntFunction;

IntFunction<int[]> ok = int[]::new;

// IntFunction<Integer[]> wrong = int[]::new; // 编译错误：int[] 不是 Integer[]
```

### 6.3 数组构造引用通常需要一个 `int` 长度参数

```java
import java.util.function.Supplier;

// Supplier<int[]> s = int[]::new; // 编译错误：缺少长度参数

Supplier<int[]> s = () -> new int[0]; // 可以
```

## 附：普通数组“构造与引用”的基础写法

如果不是指方法引用，而是普通数组对象的创建和引用，常见写法如下：

```java
int[] a;                  // 声明数组引用
a = new int[3];           // 构造数组对象并赋给引用

int[] b = {1, 2, 3};      // 静态初始化
int[] c = new int[]{1, 2, 3};

int[][] d = new int[2][3]; // 规则二维数组
int[][] e = new int[2][];  // 只创建外层数组
e[0] = new int[4];         // 再创建内层数组

a[0] = 10;                 // 通过下标引用元素
int x = a[0];              // 读取元素
int len = a.length;        // length 是属性，不是方法

int[] alias = a;
alias[1] = 20;             // a[1] 也会变成 20，因为指向同一个数组对象
```

总结：**`类型[]::new` 是数组构造引用，等价于 `length -> new 类型[length]`；它适合配合 `IntFunction<T[]>`、`Stream.toArray(...)`、泛型数组工厂等场景使用。**
