下面按常见场景列举 Java 泛型的使用，并尽量配代码说明。示例默认需要：

```java
import java.util.*;
```

## 1. 集合框架中的泛型

集合是最常见的泛型使用场景：`List<E>`、`Set<E>`、`Map<K,V>`、`Iterator<E>` 等。

```java
List<String> names = new ArrayList<>();
names.add("Alice");
names.add("Bob");
// names.add(123); // 编译错误：List<String> 只能放 String
String first = names.get(0);

Map<String, Integer> scores = new HashMap<>();
scores.put("Tom", 90);
scores.put("Jerry", 85);

for (Map.Entry<String, Integer> entry : scores.entrySet()) {
    System.out.println(entry.getKey() + " = " + entry.getValue());
}
```

泛型让编译器在编译期检查类型，避免运行时强制类型转换错误。

## 2. 比较器 Comparator<T> 和 Comparable<T>

### Comparator<T>

```java
class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public int getAge() {
        return age;
    }

    public String getName() {
        return name;
    }
}

List<Person> people = new ArrayList<>();
people.add(new Person("Tom", 20));
people.add(new Person("Jerry", 18));

Comparator<Person> byAge = Comparator.comparingInt(Person::getAge);
people.sort(byAge);

Comparator<Person> byName = Comparator.comparing(Person::getName);
people.sort(byName);
```

`Comparator<Person>` 表示“比较 Person 对象的比较器”，`compare` 方法参数类型由泛型保证。

### Comparable<T>

```java
class Student implements Comparable<Student> {
    private String name;
    private int score;

    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    @Override
    public int compareTo(Student other) {
        return Integer.compare(this.score, other.score);
    }
}

List<Student> students = new ArrayList<>();
students.add(new Student("A", 90));
students.add(new Student("B", 80));

Collections.sort(students); // 使用 Student 的 Comparable<Student>
```

## 3. 自定义泛型类

```java
class Box<T> {
    private T value;

    public Box(T value) {
        this.value = value;
    }

    public T get() {
        return value;
    }

    public void set(T value) {
        this.value = value;
    }
}

Box<String> stringBox = new Box<>("hello");
String s = stringBox.get();

Box<Integer> intBox = new Box<>(123);
Integer i = intBox.get();
```

`T` 是类型参数，使用时可替换为具体类型。

## 4. 自定义泛型接口

```java
interface Repository<T, ID> {
    void save(T entity);
    T findById(ID id);
}

class User {
}

class UserRepository implements Repository<User, Long> {
    @Override
    public void save(User entity) {
        // 保存用户
    }

    @Override
    public User findById(Long id) {
        return new User();
    }
}
```

`Repository<T, ID>` 中 `T` 表示实体类型，`ID` 表示主键类型。

## 5. 泛型方法

```java
public class GenericMethodDemo {

    public static <T extends Comparable<T>> T max(List<T> list) {
        if (list.isEmpty()) {
            throw new IllegalArgumentException("list is empty");
        }
        T best = list.get(0);
        for (T item : list) {
            if (item.compareTo(best) > 0) {
                best = item;
            }
        }
        return best;
    }

    public static void main(String[] args) {
        String maxStr = max(List.of("apple", "pear", "orange"));
        Integer maxInt = max(List.of(3, 7, 2));
        System.out.println(maxStr); // pear
        System.out.println(maxInt); // 7
    }
}
```

`<T extends Comparable<T>>` 表示类型参数 `T` 必须可比较。

## 6. 通配符：`? extends` 和 `? super`

### `? extends Number`：读取安全

```java
static double sum(List<? extends Number> list) {
    double total = 0;
    for (Number n : list) {
        total += n.doubleValue();
    }
    return total;
}

List<Integer> ints = List.of(1, 2, 3);
List<Double> doubles = List.of(1.5, 2.5);

double a = sum(ints);
double b = sum(doubles);
```

`List<? extends Number>` 可以接收 `List<Integer>`、`List<Double>` 等，但通常不能往里面添加元素，因为编译器不知道具体子类型。

### `? super Integer`：写入安全

```java
static void addOne(List<? super Integer> list) {
    list.add(1);
}

List<Number> numbers = new ArrayList<>();
addOne(numbers); // 可以，因为 Number 是 Integer 的父类型

List<Object> objects = new ArrayList<>();
addOne(objects); // 也可以
```

这就是常说的 PECS 原则：

- Producer Extends：主要读取数据时用 `? extends T`
- Consumer Super：主要写入数据时用 `? super T`

## 7. 泛型与继承关系

`List<Integer>` 不是 `List<Number>` 的子类型：

```java
List<Integer> ints = new ArrayList<>();
// List<Number> nums = ints; // 编译错误

List<? extends Number> nums = ints; // 可以
// nums.add(1); // 编译错误，除了 null 之外不能添加
```

说明泛型默认是不型变的，需要通配符表达更灵活的关系。

## 8. 有界类型参数

```java
static <T extends Number> double sumNumbers(List<T> list) {
    double total = 0;
    for (T n : list) {
        total += n.doubleValue();
    }
    return total;
}

static <T extends Number & Comparable<T>> T maxNumber(List<T> list) {
    T best = list.get(0);
    for (T item : list) {
        if (item.compareTo(best) > 0) {
            best = item;
        }
    }
    return best;
}
```

多个上界时，类只能有一个，并且必须放在第一个，例如 `T extends Number & Comparable<T>`。

## 9. 泛型的常见限制

由于 Java 泛型存在类型擦除，有一些限制：

```java
class Demo<T> {
    // T value = new T();       // 编译错误：不能直接 new 类型参数
    // static T staticValue;    // 编译错误：静态成员不能使用类类型参数
    // T[] arr = new T[10];     // 编译错误：不能创建泛型数组

    void check(Object obj) {
        // if (obj instanceof List<String>) { } // 编译错误
        if (obj instanceof List<?>) { }          // 可以
    }
}

// List<String>[] arr = new List<String>[10]; // 编译错误
List<?>[] arr = new List<?>[10];               // 可以
```

另外，泛型类型参数不能是基本类型：

```java
// List<int> list = new ArrayList<>(); // 编译错误
List<Integer> list = new ArrayList<>();  // 正确，使用包装类型
```

## 总结

Java 泛型常见使用点包括：

- 集合：`List<String>`、`Map<String, Integer>`、`Set<T>`、`Iterator<T>`
- 比较器：`Comparator<T>`、`Comparable<T>`
- 自定义泛型类：`class Box<T>`
- 自定义泛型接口：`interface Repository<T, ID>`
- 泛型方法：`static <T> T method(...)`
- 通配符：`? extends T`、`? super T`
- 有界类型参数：`<T extends Number>`、`<T extends Comparable<T>>`
- 注意类型擦除带来的限制：不能 `new T()`、不能创建泛型数组、不能 `instanceof List<String>` 等。
