Java 的局部变量类型推断主要是 Java 10 引入的 `var`（JEP 286）。`var` 让编译器根据初始化表达式推断局部变量的**编译期静态类型**，它不是动态类型。

```java
var message = "hello"; // 推断为 String
var count = 10;        // 推断为 int
// count = "abc";      // 编译错误：count 已经是 int
```

## 1. 适用场景

### 1.1 普通局部变量声明

```java
var message = "hello";                 // String
var count = 10;                        // int
var price = 12.5;                      // double
var list = new ArrayList<String>();    // ArrayList<String>
var map = new HashMap<String, List<Integer>>();
```

注意泛型钻石运算符：

```java
var list1 = new ArrayList<String>(); // ArrayList<String>
var list2 = new ArrayList<>();       // ArrayList<Object>，不是 ArrayList<String>
```

### 1.2 for 循环初始化变量

```java
for (var i = 0; i < 10; i++) {
    System.out.println(i); // i 推断为 int
}
```

### 1.3 增强 for 循环变量

```java
List<String> names = List.of("Alice", "Bob");

for (var name : names) {
    System.out.println(name.length()); // name 推断为 String
}
```

### 1.4 try-with-resources 资源变量

```java
import java.io.FileInputStream;
import java.io.IOException;

void read() throws IOException {
    try (var in = new FileInputStream("a.txt")) {
        System.out.println(in.read());
    }
}
```

### 1.5 匿名类变量

`var` 可以保留匿名类的具体类型，因此可以调用匿名类中新增的方法：

```java
var obj = new Object() {
    void hello() {
        System.out.println("hello");
    }
};

obj.hello(); // 合法，obj 被推断为匿名类类型
```

### 1.6 与 final 一起使用

```java
final var pi = 3.14; // pi 推断为 double，且为 final
```

## 2. 不适用或受限制的场景

### 2.1 不能用于字段、方法参数、返回类型等

```java
class Demo {
    // var field = 1;          // 错误：不能用于字段

    // void method(var x) {}   // 错误：不能用于方法参数

    // var method() { return 1; } // 错误：不能用于返回类型

    void test() {
        var x = 1; // 正确：局部变量
    }
}
```

### 2.2 必须有初始化器

```java
// var x;        // 错误：没有初始化器，无法推断
var x = 1;       // 正确
```

### 2.3 不能用 null 初始化

```java
// var x = null;        // 错误：null 没有具体类型
var x = (String) null;  // 正确：强制类型转换后可以推断为 String
```

### 2.4 不能一次声明多个变量

```java
// var a = 1, b = 2; // 错误：var 不支持复合声明
var a = 1;
var b = 2;
```

### 2.5 不能使用数组初始化简写

```java
// var arr = {1, 2, 3};        // 错误
var arr = new int[]{1, 2, 3};  // 正确，arr 推断为 int[]
```

### 2.6 lambda 表达式和方法引用作为初始化器时通常不能推断

```java
// var f = () -> 1;          // 错误：lambda 需要目标类型
// var g = String::length;   // 错误：方法引用需要目标类型

var r = (Runnable) () -> {}; // 正确：强制转换提供了目标类型
```

### 2.7 不能用于 catch 参数

```java
try {
    // ...
} catch (var e) { // 错误：catch 参数不能用 var
    // ...
}
```

## 3. 相关但不同的语法：Java 11 lambda 形参中的 var

Java 11 允许 lambda 形参使用 `var`，主要用于统一加注解，但它不属于局部变量类型推断本身：

```java
BiFunction<Integer, Integer, Integer> f =
        (var x, var y) -> x + y;
```

带注解时：

```java
list.forEach((@Deprecated var s) -> System.out.println(s));
```

注意：lambda 形参中要么全部使用 `var`，要么全部省略类型，不能混用。

## 4. 补充说明

- `var` 不是动态类型，推断结果在编译期确定。
- `var` 不是普通关键字，而是“保留类型名”：不能用作类名/接口名，但通常仍可作为变量名、方法名等。
- `var` 不能用于字段、方法参数、返回类型、构造器参数、catch 参数等。
- `var` 最常用于减少冗长的泛型声明，但不应滥用；当初始化表达式本身不能清晰表达类型时，显式类型可能更易读。
