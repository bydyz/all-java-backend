这里的“绑定/未绑定”只针对**实例方法引用**：绑定的是实例方法调用时的**接收者对象**，也就是 `obj.method(args)` 里的 `obj`。

- **未绑定实例方法引用**：`类型::实例方法`，没有给出具体接收者；调用时由函数式接口的**第一个参数**充当接收者。
- **已绑定实例方法引用**：`对象表达式::实例方法`，接收者已经确定；函数式接口的参数只对应方法参数。

| 写法 | 类型 | 等价 lambda |
|---|---|---|
| `Integer::parseInt` | 静态方法引用 | `s -> Integer.parseInt(s)` |
| `String::length` | **未绑定**实例方法引用 | `(String s) -> s.length()` |
| `System.out::println` | **已绑定**实例方法引用，接收者是 `System.out` 这个 `PrintStream` 对象 | `x -> System.out.println(x)` |
| `ArrayList::new` | 构造器引用 | `() -> new ArrayList<>()` |
| `String[]::new` | 数组构造器引用 | `n -> new String[n]` |

重点看两个：

```java
Function<String, Integer> b = String::length;
// 等价于：
Function<String, Integer> b2 = s -> s.length();

System.out.println(b.apply("abc")); // 3
```

`String::length` 没有绑定任何具体字符串；`apply("abc")` 传入的 `"abc"` 才是接收者，等价于 `"abc".length()`。所以它是“未绑定”。

```java
Consumer<String> c = System.out::println;
// 等价于：
Consumer<String> c2 = x -> System.out.println(x);

c.accept("hello"); // 等价于 System.out.println("hello")
```

`System.out::println` 中接收者 `System.out` 已经确定了；`Consumer<String>` 的参数 `"hello"` 只是 `println` 的方法参数。所以它是“已绑定”。

同一个方法可以写成已绑定或未绑定：

```java
// 已绑定：接收者是 System.out
Consumer<String> bound = System.out::println;
bound.accept("A"); // System.out.println("A")

// 未绑定：接收者作为第一个参数传入
BiConsumer<PrintStream, String> unbound = PrintStream::println;
unbound.accept(System.out, "B"); // System.out.println("B")
```

再比如：

```java
Function<String, Integer> unboundLen = String::length; // 未绑定：s -> s.length()

String s = "hello";
Supplier<Integer> boundLen = s::length;                // 已绑定：() -> s.length()

System.out.println(unboundLen.apply("abc")); // 3
System.out.println(boundLen.get());          // 5
```

参数个数规律：

- 已绑定：接口参数个数 = 方法参数个数
  `System.out::println` 对应 `println(String)`，`Consumer<String>` 也是 1 个参数。
- 未绑定：接口参数个数 = 1 个接收者 + 方法参数个数
  `String::length` 的 `length()` 无参，但 `Function<String,Integer>` 有 1 个参数，这个参数就是接收者。
  `PrintStream::println` 的 `println(String)` 有 1 个参数，未绑定后对应 `BiConsumer<PrintStream,String>` 的 2 个参数。

另外注意：你最后一行

```java
Function<String, String[]> e = String[]::new; // 不合法
```

`String[]::new` 需要的是数组长度，是整数，不是 `String`。正确写法例如：

```java
IntFunction<String[]> e = String[]::new;
String[] arr = e.apply(3); // new String[3]
```

总结：**已绑定 = 接收者对象已经写在 `::` 左边；未绑定 = 左边只写类型，接收者由函数式接口的第一个参数在调用时传入。**
