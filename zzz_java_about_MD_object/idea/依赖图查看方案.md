# IntelliJ IDEA 包依赖图查看方案

## 方案1：类图表中的依赖关系

### 操作步骤：
1. **打开项目窗口**：`View | Tool Windows | Project`
2. **选择目标包**：右键点击要分析的包
3. **生成图表**：选择 `Diagrams | Show Diagram (Ctrl+Alt+Shift+U)`
4. **选择图表类型**：在弹出窗口中选择 `Java Class Diagram`
5. **显示依赖**：点击图表工具栏的 **Show Dependencies** 图标（类似网络连接图标）

### 功能特点：
- 显示类之间的继承、实现、关联等关系
- 依赖关系用箭头表示，遵循UML规范
- 可以调整可见性级别（public/protected/private）
- 灰色显示不同包中的类

## 方案2：依赖矩阵分析

### 操作步骤：
1. **打开分析菜单**：`Analyze | Dependency Matrix`
2. **选择分析范围**：
    - **Packages**：分析包之间的依赖
    - **Modules**：分析模块之间的依赖
    - **Classes**：分析类之间的依赖
3. **配置选项**：
    - 设置分析深度
    - 选择是否包含测试代码
    - 配置过滤器
4. **生成矩阵**：点击 `OK` 生成依赖矩阵

### 功能特点：
- 以矩阵形式显示依赖关系强度
- 颜色深浅表示依赖程度
- 可以点击矩阵单元查看具体依赖
- 支持导出为HTML或图片

## 方案3：模块依赖视图

### 操作步骤：
1. **打开项目结构**：`File | Project Structure (Ctrl+Alt+Shift+S)`
2. **选择模块**：在左侧面板选择 `Modules`
3. **查看依赖**：选择具体模块，查看 `Dependencies` 选项卡
4. **分析依赖**：
    - 查看模块间的依赖关系
    - 检查库依赖
    - 查看依赖范围（compile/runtime/test）

### 功能特点：
- 显示模块间的编译依赖
- 可以添加/删除依赖关系
- 支持依赖范围配置
- 显示传递性依赖

## 对比总结

| 方案 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| 类图表依赖 | 类级别关系分析 | 直观的图形化显示 | 大型项目可能复杂 |
| 依赖矩阵 | 整体架构分析 | 清晰的依赖强度显示 | 需要学习如何解读 |
| 模块依赖视图 | 模块配置管理 | 直接的配置界面 | 仅限模块级别 |

## 建议

- 对于**架构分析**，推荐使用**依赖矩阵**
- 对于**具体类关系调试**，使用**类图表依赖**
- 对于**模块配置**，使用**模块依赖视图**

## 相关快捷键

| 功能 | 快捷键 |
|------|--------|
| 显示类图表 | `Ctrl+Alt+Shift+U` |
| 打开项目结构 | `Ctrl+Alt+Shift+S` |
| 打开设置 | `Ctrl+Alt+S` |
| 查看依赖关系 | 图表工具栏依赖图标 |

## 注意事项

1. 确保 `Diagrams` 插件已启用（默认已启用）
2. 大型项目生成图表可能需要较长时间
3. 依赖矩阵分析可能消耗较多内存
4. 建议在分析前保存工作进度
