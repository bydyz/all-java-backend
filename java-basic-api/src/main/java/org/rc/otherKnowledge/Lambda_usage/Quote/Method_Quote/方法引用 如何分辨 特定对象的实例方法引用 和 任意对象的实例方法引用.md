# Java 方法引用：特定对象 vs 任意对象实例方法引用

核心：**看 `::` 左边是“实例表达式”还是“类型名”，再结合方法是实例方法还是静态方法，以及目标函数式接口的参数签名**。方法引用本身是“多表达式”，最终含义由目标函数式接口决定。

## 1. 两种实例方法引用

| 写法 | 名称 | 等价 Lambda | 函数式接口参数 |
|---|---|---|---|
| `obj::instanceMethod` | 特定对象的实例方法引用（bound） | `(a,b) -> obj.instanceMethod(a,b)` | 参数 = 方法参数，**不包含 obj** |
| `Type::instanceMethod` | 任意对象的实例方法引用（unbound） | `(x,a,b) -> x.instanceMethod(a,b)` | 第一个参数 = 接收者，后面 = 方法参数 |

关键区别：

- `obj::method`：接收者 `obj` 已经被捕获固定。
- `Type::method`：接收者不固定，由函数式接口的第一个参数传入。

## 2. 例子

```java
class Person {
    String getName() { return "Tom"; }
    boolean startsWith(String prefix) { return getName().startsWith(prefix); }
}

Person p = new Person();

// 特定对象实例方法引用：接收者是 p
Supplier<String> s1 = p::getName;
// 等价于 () -> p.getName()

Function<String, Boolean> f1 = p::startsWith;
// 等价于 prefix -> p.startsWith(prefix)

// 任意对象实例方法引用：接收者由参数传入
Function<Person, String> f2 = Person::getName;
// 等价于 person -> person.getName()

BiFunction<Person, String, Boolean> f3 = Person::startsWith;
// 等价于 (person, prefix) -> person.startsWith(prefix)
```

对比：

```java
String str = "abc";

Supplier<Integer> a = str::length;
// 特定对象：() -> str.length()

Function<String, Integer> b = String::length;
// 任意对象：s -> s.length()
```

## 3. 判断步骤

看到 `X::method` 时：

1. **`X` 是变量、`this`、`super`、方法调用结果、`new` 表达式等实例表达式？**
  - 且 `method` 是实例方法：**特定对象实例方法引用**。
  - 例如：`p::getName`、`this::foo`、`super::bar`。

2. **`X` 是类型名？**
  - 且 `method` 是实例方法：**任意对象实例方法引用**。
  - 例如：`Person::getName`、`String::length`。

3. **方法是 `static`？**
  - 那是静态方法引用，不是实例方法引用。
  - 例如：`Integer::parseInt`。

4. **看目标函数式接口签名**
  - 特定对象引用：接口参数个数 = 方法参数个数。
  - 任意对象引用：接口参数个数 = 方法参数个数 + 1，第一个参数是接收者。

## 4. 注意点

- 不要只靠大小写判断 `Person::getName` 还是 `person::getName`，要看编译器把左边解析为**类型**还是**变量/表达式**。
- `Type::instanceMethod` 只有当 `instanceMethod` 不是静态方法时，才是任意对象实例方法引用。
- 任意对象实例方法引用要求第一个函数参数类型能作为该方法的接收者。例如：

```java
Function<Person, String> f = Person::getName; // OK
Function<Object, String> g = Person::getName; // 编译错误，Object 不一定是 Person
```

总结成一句话：

> **`obj::instMethod` 是特定对象引用，接收者被固定；`Type::instMethod` 是任意对象引用，接收者由函数式接口的第一个参数传入。**
