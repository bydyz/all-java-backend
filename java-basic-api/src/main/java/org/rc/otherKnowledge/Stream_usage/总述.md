Java Stream 是 Java 8 引入的核心特性，它提供了一种**声明式**的、函数式的数据处理方式，将数据集合的复杂操作（如筛选、排序、聚合）抽象为一条可组装的“流水线”。

### 🧩 Stream 的定义与核心特性

**Stream（流）** 是来自数据源的元素队列，支持聚合操作。它本身**不存储数据**，而是像一个“视图”一样，对源数据进行计算和处理。

Stream 具有几个关键特性：
*   **不存储数据**：Stream 不是数据结构，它不保存元素，只是按需计算。
*   **不改变源数据**：对 Stream 的任何操作都不会修改其数据源（如 List），通常会生成一个新的集合或值。
*   **延迟执行 (Lazy Evaluation)**：这是 Stream 的核心机制之一。**中间操作**（如 `filter`, `map`）只是记录下要执行的操作，并不会立即计算；只有等到**终端操作**（如 `collect`, `forEach`）被调用时，所有中间操作才会一次性执行，这避免了多次遍历数据源，提升了效率。

### ⚙️ Stream 的操作步骤

一个完整的 Stream 使用流程通常包含三个步骤，形成一个流畅的管道：

1.  **创建 Stream (获取流)**：从一个数据源（如集合、数组、`Stream.of` 等）生成一个流。
2.  **中间操作 (转换/处理)**：对数据流进行零次或多次的转换操作，如过滤、映射、排序等，每一步都返回一个新的 Stream，从而形成链式调用。
3.  **终端操作 (终止/结果)**：触发整个流水线的执行，并产生一个最终结果（如集合、数值、布尔值等）。**一个流只能被消费一次，终端操作后流即关闭。**

### 🛠️ 常用 API 的定义与使用方法

Stream 的 API 主要分为**中间操作**和**终端操作**两大类。

#### 创建 Stream 的常用方式

```java
// 1. 从 Collection 创建 (最常用)
List<String> list = Arrays.asList("a", "b", "c");
Stream<String> streamFromList = list.stream(); // 串行流
Stream<String> parallelStream = list.parallelStream(); // 并行流

// 2. 从数组创建
int[] arr = {1, 2, 3};
IntStream streamFromArray = Arrays.stream(arr);

// 3. 使用 Stream.of() 直接创建
Stream<String> streamOf = Stream.of("a", "b", "c");

// 4. 从 Map 创建
Map<String, Integer> map = new HashMap<>();
map.put("a", 1);
Stream<String> keyStream = map.keySet().stream(); // 键的流
Stream<Integer> valueStream = map.values().stream(); // 值的流
Stream<Map.Entry<String, Integer>> entryStream = map.entrySet().stream(); // 键值对的流
```
以上创建方式参考了。

#### 中间操作 (Intermediate Operations)

中间操作是“懒”的，它们返回一个新的 Stream，允许链式调用。

| API | 定义 | 说明 | 代码示例 |
| :--- | :--- | :--- | :--- |
| **`filter(Predicate)`** | 过滤 | 保留符合断言条件的元素。 | `list.stream().filter(s -> s.startsWith("a"))` |
| **`map(Function)`** | 映射 | 将每个元素转换（映射）为另一种形式。 | `list.stream().map(String::toUpperCase)` |
| **`flatMap(Function)`** | 扁平化映射 | 将每个元素转换成一个 Stream，然后把所有 Stream 合并（扁平化）成一个新的 Stream。 | `listOfLists.stream().flatMap(List::stream)` |
| **`distinct()`** | 去重 | 去除流中重复的元素（基于 `equals()`）。 | `list.stream().distinct()` |
| **`sorted()`** | 排序 | 对元素进行自然排序，或通过 `Comparator` 自定义排序。 | `list.stream().sorted(Comparator.comparing(User::getAge))` |
| **`limit(n)`** | 限制 | 截断流，使其元素不超过 `n` 个。 | `list.stream().limit(3)` |
| **`skip(n)`** | 跳过 | 跳过前 `n` 个元素，返回剩下的元素。 | `list.stream().skip(2)` |
| **`peek(Consumer)`** | 窥视 | 对每个元素执行操作（常用于调试），但**不改变流的内容**。 | `list.stream().peek(System.out::println)` |

> **注意**：`sorted()`, `distinct()`, `limit()`, `skip()` 属于**有状态操作**，它们需要等待处理完之前的所有元素后，才能确定当前操作的结果。

#### 终端操作 (Terminal Operations)

终端操作是“急”的，它们触发实际计算并结束流。

| API | 定义 | 说明 | 代码示例 |
| :--- | :--- | :--- | :--- |
| **`collect(Collector)`** | 收集 | 将流中的元素收集到一个结果容器中（如 `List`, `Set`, `Map`, 字符串等）。 | `list.stream().collect(Collectors.toList())` |
| **`forEach(Consumer)`** | 遍历 | 对流中的每个元素执行一个操作。 | `list.stream().forEach(System.out::println)` |
| **`count()`** | 计数 | 返回流中元素的总个数。 | `list.stream().filter(...).count()` |
| **`reduce()`** | 归约 | 将流中的所有元素反复结合起来，得到一个值。 | `numbers.stream().reduce(0, Integer::sum)` |
| **`anyMatch(Predicate)`** | 任意匹配 | 判断是否**至少有一个**元素满足条件（短路操作）。 | `list.stream().anyMatch(s -> s.length() > 5)` |
| **`allMatch(Predicate)`** | 全部匹配 | 判断是否**所有**元素都满足条件（短路操作）。 | `list.stream().allMatch(s -> s.startsWith("a"))` |
| **`findFirst()`** | 查找第一个 | 返回流中的第一个元素（短路操作）。 | `list.stream().filter(...).findFirst()` |
| **`toArray()`** | 转数组 | 将流转换为一个数组。 | `list.stream().toArray(String[]::new)` |

终端操作可分为**非短路操作**（如 `collect`, `forEach`, `reduce`，需要处理所有元素）和**短路操作**（如 `anyMatch`, `findFirst`，一旦得到结果就提前终止）。

### 💻 综合代码示例

以下示例综合运用了创建、中间操作和终端操作，展示了一个完整的数据处理管道。

**示例1：基础过滤与映射**
```java
List<User> users = Arrays.asList(
    new User("Alice", 17), new User("Bob", 20), new User("Charlie", 22)
);
// 步骤: 创建流 -> filter (年龄>18) -> map (名字大写) -> collect (收集到List)
List<String> adultNames = users.stream()          // 1. 创建流
    .filter(user -> user.getAge() > 18)            // 2. 中间操作: 过滤
    .map(user -> user.getName().toUpperCase())     // 2. 中间操作: 映射
    .collect(Collectors.toList());                 // 3. 终端操作: 收集
// 结果: [BOB, CHARLIE]
```
此示例参考了。

**示例2：扁平化操作 (flatMap)**
```java
List<List<String>> listOfLists = Arrays.asList(
    Arrays.asList("a", "b"), Arrays.asList("c", "d")
);
List<String> flatList = listOfLists.stream()
    .flatMap(List::stream) // 将每个内部 List 转换成一个 Stream 并合并
    .collect(Collectors.toList());
// 结果: [a, b, c, d]
```
此示例参考了。

**示例3：聚合操作 (reduce)**
```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
int sum = numbers.stream()
    .reduce(0, Integer::sum); // 从初始值0开始，反复应用 Integer::sum
// 结果: 15
```
此示例参考了。

**示例4：链式组合操作 (过滤、映射、去重、收集)**
```java
List<String> sourceList = Arrays.asList("1", "2", "", "12", "2", "5");
List<Integer> result = sourceList.stream()
    .filter(s -> !s.isEmpty())       // 过滤空字符串
    .map(Integer::valueOf)            // 将字符串转换为整数
    .distinct()                       // 去重
    .sorted()                         // 排序
    .collect(Collectors.toList());    // 收集
// 结果: [1, 2, 5, 12]
```
此示例综合了多项操作。

**示例5：分组与统计 (高级 `collect` 用法)**
```java
// 按成绩分组
Map<Double, List<User>> groupByScore = users.stream()
    .collect(Collectors.groupingBy(User::getScore));

// 统计分数信息 (最大、最小、总和、平均)
DoubleSummaryStatistics stats = users.stream()
    .mapToDouble(User::getScore)
    .summaryStatistics();
```

Java Stream 的核心价值在于将“**如何做**”（命令式循环）转变为“**做什么**”（声明式描述），使代码更简洁、可读性更强，并能轻松利用多核架构进行并行处理。
