# Java 中 BufferedWriter 详解

`BufferedWriter` 是 Java `java.io` 包中的一个**装饰器（Decorator）** 类，它通过为底层 `Writer` 添加内存缓冲区，将大量小的写操作合并为少数几次实际的 I/O 调用，从而显著提升文本写入的效率。

---

## 功能定位：为什么要用 BufferedWriter？

直接使用 `FileWriter` 等底层写入器时，每次 `write()` 调用都可能触发一次昂贵的系统调用（磁盘 I/O）。`BufferedWriter` 在内存中维护一个字符数组作为缓冲区，数据先写入缓冲区，只有缓冲区满、被显式刷新（`flush`）或关闭（`close`）时，才将数据一次性写入底层流。

官方文档明确指出：**除非需要即时输出（prompt output），否则建议在任何 `write()` 操作可能昂贵的 `Writer`（如 `FileWriter`、`OutputStreamWriter`）外层包装一个 `BufferedWriter`**。

---

## 构造器（构造方法）

`BufferedWriter` 提供两个构造器：

| 构造器 | 说明 |
|---|---|
| `BufferedWriter(Writer out)` | 使用**默认大小**的缓冲区（内部实现为 8192 个字符） |
| `BufferedWriter(Writer out, int sz)` | 使用指定大小的缓冲区；`sz` 必须为正整数，否则抛出 `IllegalArgumentException` |

### 代码示例：两种构造方式

```java
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

// 方式一：默认缓冲区（8192 字符）
try (BufferedWriter writer = new BufferedWriter(new FileWriter("default.txt"))) {
    writer.write("使用默认缓冲区写入");
}

// 方式二：自定义缓冲区大小（例如 16384 字符，即 16KB）
try (BufferedWriter writer = new BufferedWriter(new FileWriter("custom.txt"), 16384)) {
    writer.write("使用自定义缓冲区写入");
}
```

也可以配合 `Files.newBufferedWriter(Path)` 使用（本质是工厂方法，返回 `BufferedWriter`，默认缓冲区大小）：

```java
import java.nio.file.Files;
import java.nio.file.Paths;

try (BufferedWriter writer = Files.newBufferedWriter(Paths.get("output.txt"))) {
    writer.write("通过 Files.newBufferedWriter 创建");
}
```

## 核心 API 及使用方法

`BufferedWriter` 的方法继承自 `Writer`，并新增了 `newLine()`。以下按用途逐一说明。

### 1. `write` 系列方法

`BufferedWriter` 重写了 `Writer` 的 `write` 方法，使写入先进入缓冲区。共有三个重载版本：

| 方法签名 | 说明 |
|---|---|
| `void write(int c)` | 写入**单个字符**（`int` 的低 16 位） |
| `void write(char[] cbuf, int off, int len)` | 写入字符数组的**一部分**；若 `len` 大于等于缓冲区大小，会跳过缓冲直接写入底层流，避免冗余拷贝 |
| `void write(String s, int off, int len)` | 写入字符串的**一部分** |

```java
try (BufferedWriter writer = new BufferedWriter(new FileWriter("data.txt"))) {
    writer.write('A');                          // 写入单个字符
    writer.write(new char[]{'B', 'C', 'D'});    // 写入整个字符数组（off=0, len=3）
    writer.write("Hello, BufferedWriter!");     // 写入完整字符串
    writer.write("Java Programming", 0, 4);     // 只写入 "Java"
}
```

### 2. `newLine()`：写入平台相关的换行符

`write()` 方法**不会自动添加换行**（不同于 `System.out.println`）。`newLine()` 会写入当前操作系统的行分隔符：Windows 为 `\r\n`，Unix/Linux 为 `\n`。官方文档建议**用 `newLine()` 代替直接写入 `'\n'`**，以保证跨平台正确性。

```java
try (BufferedWriter writer = new BufferedWriter(new FileWriter("lines.txt"))) {
    writer.write("第一行");
    writer.newLine();                // 写入平台相关换行符
    writer.write("第二行");
    writer.newLine();
}
```

### 3. `flush()`：强制将缓冲区内容写入底层流

`flush()` 会立即将缓冲区中尚未写入的数据推送到目标 `Writer`。在需要**保证数据及时可见**的场景（如实时日志、网络通信）中必须显式调用。

```java
try (BufferedWriter writer = new BufferedWriter(new FileWriter("log.txt"))) {
    writer.write("应用启动");
    writer.newLine();
    writer.flush();                  // 立即写入磁盘，不等待缓冲区填满
    // ... 执行耗时操作 ...
    writer.write("操作完成");
    writer.newLine();
}   // try-with-resources 结束时自动 close()，close() 内部会先 flush
```

### 4. `close()`：关闭流（先刷新，再关闭）

`close()` 的语义是**先 `flush()`，然后关闭底层流**。调用 `BufferedWriter.close()` 会连带关闭被包装的底层 `Writer`（如 `FileWriter`）。推荐使用 **try-with-resources**，由编译器保证 `close()` 一定被调用，避免数据丢失。

## 性能说明与最佳实践

**缓冲区大小的意义**：`BufferedWriter` 的默认缓冲区为 **8192 个字符**（注意是字符数，不是字节数；具体字节数取决于字符编码）。缓冲区越大，系统调用次数越少，但占用内存也越多。

**与 `FileWriter` 的关系**：现代 JDK 中 `FileWriter` 自身也有内部缓冲区（通常也是 8192 字节），因此在简单的小规模写入场景下，两者性能差距可能不明显。`BufferedWriter` 的优势在于：**你可以显式控制缓冲区大小**，并且它能与任意 `Writer` 组合，而不仅限于文件。

**何时需要自定义缓冲区大小**：如果每次写入的数据块较大（例如单行超过 4KB），默认的 8192 字符缓冲区可能导致频繁的“缓冲—刷新”循环；此时可以适当增大缓冲区（如 16384 或 32768）。对于绝大多数常规文本写入，默认值已经足够。

**与 `PrintWriter` 的组合**：`BufferedWriter` 专注缓冲，`PrintWriter` 提供 `print`/`println`/`printf` 等便捷格式化方法。典型的高效写入组合是：

```java
PrintWriter out = new PrintWriter(
    new BufferedWriter(new FileWriter("foo.out"))
);
```

## 完整示例：综合运用

```java
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

public class BufferedWriterDemo {
    public static void main(String[] args) {
        String filePath = "demo.txt";

        try (BufferedWriter writer = new BufferedWriter(new FileWriter(filePath))) {
            // 写入单字符
            writer.write('J');

            // 写入字符数组片段
            char[] suffix = {'a', 'v', 'a'};
            writer.write(suffix, 0, suffix.length);

            // 写入字符串
            writer.write(" BufferedWriter 示例");

            // 换行
            writer.newLine();

            // 再次写入并换行
            writer.write("第二行内容");
            writer.newLine();

            // 需要立即落盘时手动 flush
            writer.flush();

        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

**关键点**：`try-with-resources` 确保 `close()` 被调用；`close()` 内部会自动 `flush()`，因此即使不手动 `flush()`，正常结束块时缓冲区数据也不会丢失。但在块**尚未结束**时就需要让数据可见的情况下，必须显式调用 `flush()`。

---

**总结**：`BufferedWriter` 是一个轻量的装饰器，核心价值在于**缓冲**——通过合并小的写操作来减少底层 I/O 次数。使用要点：优先用 `newLine()` 处理换行，用 try-with-resources 管理生命周期，在需要即时可见的场景下手动 `flush()`，缓冲区大小通常无需调整，特殊大批量场景可按写入块大小适度增大。
