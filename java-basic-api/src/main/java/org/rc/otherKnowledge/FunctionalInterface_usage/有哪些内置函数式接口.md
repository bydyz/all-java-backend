# Java 内置函数式接口

Java 的内置函数式接口主要集中在 `java.util.function` 包下。它们是 Lambda 表达式和方法引用的“目标类型”。其中，**`Function`、`Consumer`、`Supplier`、`Predicate` 被称为四大核心函数式接口**，是日常开发中使用频率最高的。

## 🎯 四大核心函数式接口

### 1. `Function<T, R>`：函数型接口

**作用**：接受一个类型为 `T` 的参数，返回一个类型为 `R` 的结果。即“输入 A，输出 B”的转换操作。

**核心方法**：`R apply(T t)`。

**代码示例**：

```java
import java.util.function.Function;

public class FunctionDemo {
    public static void main(String[] args) {
        // 定义一个函数：输入字符串，返回其长度
        Function<String, Integer> lengthFunction = s -> s.length();

        Integer length = lengthFunction.apply("Hello, Function!");
        System.out.println("字符串长度: " + length); // 输出: 16

        // 使用 andThen 组合函数：先计算长度，再将长度转换为描述字符串
        Function<Integer, String> intToString = i -> "长度是: " + i;
        String result = lengthFunction.andThen(intToString).apply("Hello");
        System.out.println(result); // 输出: 长度是: 5
    }
}
```

### 2. `Consumer<T>`：消费型接口

**作用**：接受一个类型为 `T` 的参数，但不返回任何结果。常用于对传入的对象执行某种操作，如打印、修改状态等。

**核心方法**：`void accept(T t)`。

**代码示例**：

```java
import java.util.Arrays;
import java.util.List;
import java.util.function.Consumer;

public class ConsumerDemo {
    public static void main(String[] args) {
        // 定义一个 Consumer：打印传入的字符串
        Consumer<String> printConsumer = s -> System.out.println("打印: " + s);
        printConsumer.accept("Hello, Consumer!"); // 输出: 打印: Hello, Consumer!

        // 在集合的 forEach 方法中使用 Consumer
        List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
        names.forEach(printConsumer);
        // 输出:
        // 打印: Alice
        // 打印: Bob
        // 打印: Charlie
    }
}
```

### 3. `Supplier<T>`：供给型接口

**作用**：不接收任何参数，但会返回一个类型为 `T` 的结果。常用于延迟创建对象或提供默认值。

**核心方法**：`T get()`。

**代码示例**：

```java
import java.time.LocalDateTime;
import java.util.function.Supplier;

public class SupplierDemo {
    public static void main(String[] args) {
        // 定义一个 Supplier：提供当前时间
        Supplier<LocalDateTime> timeSupplier = () -> LocalDateTime.now();

        LocalDateTime now = timeSupplier.get();
        System.out.println("当前时间: " + now);

        // 经典应用：与 Optional 配合，提供默认值
        // String result = optional.orElseGet(() -> "默认值");
    }
}
```

### 4. `Predicate<T>`：断言型接口

**作用**：接受一个类型为 `T` 的参数，并返回一个 `boolean` 值。主要用于条件判断和过滤。

**核心方法**：`boolean test(T t)`。

**代码示例**：

```java
import java.util.function.Predicate;

public class PredicateDemo {
    public static void main(String[] args) {
        // 定义一个 Predicate：判断整数是否大于 0
        Predicate<Integer> isPositive = n -> n > 0;

        System.out.println(isPositive.test(10));  // 输出: true
        System.out.println(isPositive.test(-5)); // 输出: false

        // 使用 and / or / negate 进行逻辑组合
        Predicate<Integer> isEven = n -> n % 2 == 0;
        Predicate<Integer> isPositiveEven = isPositive.and(isEven);
        System.out.println(isPositiveEven.test(4)); // 输出: true
        System.out.println(isPositiveEven.test(3)); // 输出: false
    }
}
```

## 🔄 重要的衍生接口

基于四大核心接口，Java 还提供了针对特定场景的衍生接口。

### 1. `UnaryOperator<T>`：一元运算符

**作用**：它是 `Function<T, T>` 的特化形式，要求**输入和返回的类型相同**。常用于对值进行同类型修改。

**核心方法**：`T apply(T t)`。

**代码示例**：

```java
import java.util.function.UnaryOperator;

public class UnaryOperatorDemo {
    public static void main(String[] args) {
        UnaryOperator<String> toUpper = String::toUpperCase;
        UnaryOperator<Integer> square = n -> n * n;

        System.out.println(toUpper.apply("hello")); // 输出: HELLO
        System.out.println(square.apply(5));        // 输出: 25
    }
}
```

*示例参考自*

### 2. `BinaryOperator<T>`：二元运算符

**作用**：它是 `BiFunction<T, T, T>` 的特化形式，接受**两个相同类型**的参数，返回**同类型**的结果。常用于合并或运算。

**核心方法**：`T apply(T t1, T t2)`。

**代码示例**：

```java
import java.util.function.BinaryOperator;

public class BinaryOperatorDemo {
    public static void main(String[] args) {
        BinaryOperator<Integer> add = (a, b) -> a + b;
        BinaryOperator<String> concat = (s1, s2) -> s1 + " " + s2;

        System.out.println(add.apply(10, 20));              // 输出: 30
        System.out.println(concat.apply("Hello", "World")); // 输出: Hello World
    }
}
```

### 3. 双参数变体：`BiFunction`、`BiConsumer`、`BiPredicate`

这些接口将核心接口的参数扩展为两个。

- **`BiFunction<T, U, R>`**：`R apply(T t, U u)`，接受两个不同类型的参数，返回一个结果。
- **`BiConsumer<T, U>`**：`void accept(T t, U u)`，接受两个参数，无返回值。
- **`BiPredicate<T, U>`**：`boolean test(T t, U u)`，接受两个参数，返回布尔值。

### 4. 基本类型特化接口

为了避免自动装箱/拆箱带来的性能开销，Java 为 `int`、`long`、`double` 提供了特化接口，例如：

- **`IntPredicate`**：`boolean test(int value)`
- **`IntFunction<R>`**：`R apply(int value)`
- **`ToIntFunction<T>`**：`int applyAsInt(T value)`
- **`IntSupplier`**：`int getAsInt()`

## 💎 总结

四大核心接口构成了函数式编程的基石：

- `Function` 负责**转换**
- `Consumer` 负责**消费**
- `Supplier` 负责**提供**
- `Predicate` 负责**判断**

`UnaryOperator` 和 `BinaryOperator` 是 `Function` 在参数和返回类型一致时的便捷特化。此外，`Bi*` 系列接口支持双参数，基本类型特化接口则用于优化性能。
