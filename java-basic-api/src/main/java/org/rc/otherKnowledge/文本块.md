# Java 文本块（Text Block）列举

文本块是 Java 15 正式引入（JEP 378，Java 13/14 预览）的多行字符串字面量，用 `"""` 作为定界符。下面逐一列举其特性并附代码。

## 1. 基本语法

以 `"""` 开头，**开头定界符后必须跟换行**（不能同行写内容），以 `"""` 结尾。

```java
String text = """
        Hello,
        World!
        """;
System.out.println(text);
// Hello,
// World!
```

```java
// 编译错误：开头定界符后必须换行
// String s = """Hello""";
```

## 2. 隐式缩进剥离（incidental whitespace）

自动移除每行**共同的最小缩进**，保留相对缩进（essential whitespace）：

```java
String html = """
        <html>
            <body>
                <p>Hello</p>
            </body>
        </html>
        """;
```

结果（每行去掉 8 个空格，`<body>` 保留 4 个空格的相对缩进）：

```html
<html>
    <body>
        <p>Hello</p>
    </body>
</html>
```

## 3. 结尾定界符位置决定末尾换行

```java
String a = """
        line1
        line2
        """;        // "line1\nline2\n"

String b = """
        line1
        line2""";   // "line1\nline2"
```

## 4. 转义序列

文本块支持普通字符串的全部转义序列：`\n`、`\t`、`\"`、`\\`、`\'`、`\b`、`\f`、`\r`、`\uXXXX`。

```java
String s = """
        Name:\tAlice
        Path: C:\\temp
        Quote: \"
        """;
```

## 5. `\s` 保留行尾空格

用于显式保留行尾空格，避免被 IDE/格式化工具删除：

```java
String colors = """
        red  \s
        green\s
        blue \s
        """;
```

## 6. `\` 续行（抑制换行）

行尾反斜杠会**抑制该处换行**，注意反斜杠后不能有空格：

```java
String s = """
        Lorem ipsum dolor sit amet, \
        consectetur adipiscing elit.
        """;
// "Lorem ipsum dolor sit amet, consectetur adipiscing elit.\n"
```

## 7. 引号处理

单个、两个双引号无需转义；出现三个连续双引号时需转义至少一个：

```java
String quote = """
        He said "Hello" to me.
        """;

String triple = """
        Here is \"""
        """;
```

## 8. 换行规范化

文本块中的 `\r\n`、`\r` 在编译期统一规范化为 `\n`。

## 9. 相关 String 方法

| 方法 | 说明 |
|---|---|
| `stripIndent()` | 去除每行共同前导空白 |
| `translateEscapes()` | 转译转义序列（普通字符串用） |
| `formatted(Object...)` | 格式化（Java 15 引入） |

```java
String s = """
        Name: %s
        Age:  %d
        """.formatted("Alice", 30);

// 普通字符串的 stripIndent
String t = "  Hello\n  World".stripIndent();  // "Hello\nWorld"

// 普通字符串的 translateEscapes
String e = "\\n".translateEscapes();          // "\n"
```

## 10. 常见实际用例

**JSON：**

```java
String json = """
        {
            "name": "Alice",
            "age": 30,
            "tags": ["java", "text-block"]
        }
        """;
```

**SQL：**

```java
String sql = """
        SELECT id, name, age
        FROM users
        WHERE age > %d
        ORDER BY name
        """.formatted(18);
```

**HTML：**

```java
String page = """
        <!DOCTYPE html>
        <html>
            <body>
                <h1>Hello, %s</h1>
            </body>
        </html>
        """.formatted("World");
```

## 11. 注意事项

- 文本块是**编译期常量**，可用于常量表达式场景。
- 开头 `"""` 后**必须换行**（可有尾随空白但通常不写）。
- 结尾换行由结尾定界符位置决定（见第 3 点）。
- 行尾空格默认保留，但建议用 `\s` 显式表达，防止工具误删。
- `\` 续行后必须紧跟换行，不能有空格。
- 文本块内容不能为 `null`（它是字面量，本身非 null）。

## 小结

| 特性 | 示例 |
|---|---|
| 基本语法 | `"""` + 换行 + 内容 + `"""` |
| 缩进剥离 | 去掉共同缩进，保留相对缩进 |
| 末尾换行 | 由结尾 `"""` 位置决定 |
| 转义 | `\n` `\t` `\"` `\\` `\uXXXX` |
| 特殊转义 | `\s`（空格）、`\`（续行） |
| 方法 | `formatted()`、`stripIndent()`、`translateEscapes()` |
