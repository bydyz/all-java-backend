# Java 成员方法声明的完整语法说明

完整的声明框架如下：

```java
[注解] [访问修饰符] [其他修饰符] [类型参数] 返回值类型 方法名([形参列表]) [throws 异常列表] {

}
```

```text
[注解] [访问修饰符] [其他修饰符] [类型参数] 返回值类型 方法名([形参列表]) [throws 异常列表]

又称 方法头、方法签名
```

---

### 逐部分详解

#### 1. 注解

- **作用**：为方法附加元数据，不影响方法签名，但可被编译器或运行时读取。
- **常见示例**：`@Override`、`@Deprecated`、`@SuppressWarnings`、`@Transactional`、`@Test`。
- **位置**：可出现在修饰符之前，也可出现在类型参数或返回类型之前（类型注解）。

#### 2. 修饰符

修饰符分为两类，**均可选**，且顺序通常遵循惯例：访问修饰符在前，其他修饰符在后。

| 类别        | 具体修饰符                                      | 说明                              |
|-----------|--------------------------------------------|---------------------------------|
| **访问修饰符** | `public`、`protected`、`private`、**默认（包私有）** | 控制方法的可见范围；不写即默认访问。              |
| **其他修饰符** | `static`                                   | 静态方法，属于类而非实例。                   |
|           | `final`                                    | 方法不可被子类重写。                      |
|           | `abstract`                                 | 抽象方法，无方法体，必须在抽象类或接口中。           |
|           | `synchronized`                             | 同步方法，保证线程安全。                    |
|           | `native`                                   | 由本地代码（如 C/C++）实现，无 Java 方法体。    |
|           | `strictfp`                                 | 浮点运算严格遵循 IEEE 754 规范。           |
|           | `default`                                  | **仅用于接口**，表示带方法体的默认方法（Java 8+）。 |

#### 3. 类型参数（泛型方法特有）

- **语法**：`<T, U extends Bound>`，置于返回值类型之前。
- **作用**：声明该方法独有的类型变量，使其成为泛型方法，作用域仅限该方法。
- **示例**：`public <T> T getFirst(List<T> list)`。

#### 4. 返回值类型

- **必需**。若方法不返回任何值，使用 `void`。
- **类型范围**：基本类型（`int`、`boolean` 等）、引用类型（类、接口、数组）。
- **与方法体的关系**：若返回值类型不是 `void`，方法体**必须**包含 `return 表达式;`，且表达式类型与声明类型兼容。`void`
  方法可省略 `return`，或仅写 `return;`。

#### 5. 方法名

- **必需**。遵循 Java 标识符规则，惯例使用**小驼峰命名法**（如 `getSum`、`isValid`）。

#### 6. 形参列表

- **必需**（可以为空 `()`）。多个参数用逗号分隔。
- **每个形参**：`[final] 类型 参数名`。
- **可变参数**：若最后一个形参的类型后加 `...`（如 `String... args`），则该参数可接收零个或多个该类型的实参；**只能用于最后一个位置
  **。

> **附：方法签名**
> Java 的 **方法签名**仅由 **方法名 + 形参类型列表** 构成，**不包括**返回值类型、修饰符、`throws`
> 子句、参数名、注解或类型参数。方法签名是重载解析和区分不同方法的唯一依据。

#### 7. throws 异常列表

- **可选**。声明该方法可能抛出的**受检异常**。
- **语法**：`throws ExceptionType1, ExceptionType2`。
- **注意**：非受检异常（`RuntimeException` 及其子类、`Error`）不强制声明。

#### 8. 方法体

- **必需**，除非方法被声明为 `abstract` 或 `native`（这两种情况以分号 `;` 结尾，无 `{}`）。
- **方法体内可包含的内容**：
  - **局部变量声明**（包括 `final` 局部变量）。
  - **语句**：表达式语句、赋值、方法调用。
  - **控制流语句**：`if`/`else`、`switch`、`for`、`while`、`do-while`、`break`、`continue`。
  - **异常处理**：`try`-`catch`-`finally`，或 `try`-with-resources。
  - **返回语句**：`return 表达式;`（有返回值方法必须保证所有路径有返回值）或 `return;`（`void` 方法）。
  - **嵌套块**：`{ ... }`。
  - **局部类**与**Lambda 表达式**（作为语句或表达式的一部分）。
